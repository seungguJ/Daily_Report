[AI Morning Brief - 2026-07-07]

1. On-device AI 논문

* 제목: R-KV: Redundancy-aware KV Cache Compression for Reasoning Models
* 학회/게재시점: NeurIPS 2025
* 다루는 문제: 추론(reasoning) 모델이 긴 사고 과정(long chain-of-thought)을 생성하면서 KV 캐시가 급격히 커져 메모리 사용량과 지연시간이 크게 늘어나는 문제
* 핵심 Contribution: 추론 과정에서 중복된 토큰을 식별해 제거하는 R-KV 기법을 제안, 캐시를 10%만 사용하고도 거의 원본과 동일한 성능을 유지
* 인사이트:
  1. 기존 압축 기법은 동일 압축률에서 성능이 60% 수준으로 떨어지지만, R-KV는 거의 100% 성능을 유지함
  2. 캐시를 38%만 사용해도 원본보다 높은 성능이 나옴 - 중복 제거가 오히려 추론 품질을 높일 수 있음을 시사
  3. 메모리 사용량 약 절반, 추론 속도 약 2배 향상 - reasoning 모델의 실질적 메모리 병목을 직접 해결
* 왜 볼만한가: reasoning 모델을 온디바이스/엣지에서 돌리려는 시도가 늘고 있는데, KV 캐시 메모리가 가장 큰 걸림돌 중 하나임. 이 논문은 그 병목을 정면으로 공략해 향후 모바일용 reasoning 모델 최적화의 참고점이 될 만함
* 링크: https://neurips.cc/virtual/2025/poster/120110

2. AI Agent 활용 아이템

* 이름: Claude Code Plugins
* 공개/출시시점: 2025-10-09 (퍼블릭 베타)
* 핵심 기능: 슬래시 명령어, 서브에이전트, MCP 서버, 훅(hook)을 하나의 패키지로 묶어 `/plugin` 명령 한 번으로 설치·공유할 수 있는 기능. Git 저장소 기반 마켓플레이스도 지원
* 활용 아이디어:
  1. 팀의 코드 리뷰 규칙, 보안 가이드라인 등을 플러그인으로 묶어 팀 전체에 배포
  2. 사내 MCP 서버 연결이나 내부 도구를 표준화된 방식으로 공유
  3. 필요 없을 땐 플러그인을 꺼서 시스템 프롬프트 복잡도를 낮추고, 필요할 때만 켜서 사용
* 왜 볼만한가: 개인 워크플로우 수준을 넘어 팀·조직 단위로 에이전트 커스터마이징을 표준화하고 배포하는 공식적인 방법이 생김 - Claude Code를 팀 단위로 쓴다면 지금 바로 도입할 가치가 있음
* 링크: https://claude.com/blog/claude-code-plugins
