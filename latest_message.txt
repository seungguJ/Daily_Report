[AI Morning Brief - 2026-07-02]

1. On-device AI 논문

* 제목: SlimLM: An Efficient Small Language Model for On-Device Document Assistance
* 학회/게재시점: ACL 2025 (System Demonstrations, 2025-07-27~08-01, Vienna)
* 다루는 문제: 스마트폰 같은 온디바이스 환경에서 문서 요약·질의응답·제안 작업을 수행할 소형 언어모델(SLM)에 대한 체계적 연구와 실기기 검증이 부족했음.
* 핵심 Contribution: 125M~8B 파라미터 SLM 계열을 SlimPajama-627B로 사전학습하고, 요약·QA·제안 태스크로 구성한 자체 데이터셋 DocAssist로 파인튜닝. Samsung Galaxy S24에서 직접 배포·테스트해 크기-속도-품질의 최적 지점을 실증하고, 실사용 가능한 안드로이드 앱까지 공개.
* 인사이트:
  1. 125M~8B 사이 다양한 크기 모델을 동일 기기에서 직접 벤치마크해 "이 태스크엔 이 정도 크기면 충분하다"는 실측 가이드라인을 제시.
  2. 문서 요약/QA/제안이라는 실사용 워크플로우에 맞춘 파인튜닝 데이터셋(DocAssist) 설계로, 범용 SLM보다 실무 적합도를 높임.
  3. 실제 안드로이드 앱으로 공개해 클라우드 의존 없이 문서 작업을 처리할 수 있음을 실증, 프라이버시 중시 환경에 바로 적용 가능한 사례를 제공.
* 왜 볼만한가: ACL 데모 트랙 논문으로 이론에 그치지 않고 실제 폰에서 동작하는 앱까지 공개해, 온디바이스 SLM을 검토하는 실무자에게 바로 참고할 수 있는 벤치마크와 결과물을 제공.
* 링크: https://aclanthology.org/2025.acl-demo.42/

2. AI Agent 활용 아이템

* 이름: Tool Search Tool (Claude Developer Platform)
* 공개/출시시점: 2025-11-24 (Anthropic 공식 발표)
* 핵심 기능: 에이전트가 시작 시 모든 도구 정의를 한꺼번에 로드하는 대신, 필요할 때만 검색해서 불러오는 온디맨드 도구 탐색 기능. 도구에 defer_loading:true를 설정하면 평소엔 컨텍스트에서 숨겨져 있다가 검색으로 매칭될 때만 전체 정의가 펼쳐짐.
* 활용 아이디어:
  1. GitHub·Slack·Sentry 등 여러 MCP 서버를 동시에 연결해도 시작 토큰을 최대 85%까지 절감할 수 있어, 대규모 툴 라이브러리를 가진 에이전트 설계 시 바로 적용 가능.
  2. 이름이 비슷한 도구(notification-send-user vs -channel) 간 오선택 문제를 완화해, 도구가 많아질수록 정확도가 떨어지는 문제를 구조적으로 해결.
  3. 내장된 정규식/BM25 검색 외에 임베딩 기반 커스텀 검색도 지원해, 자체 에이전트 프레임워크에 맞춤 구현이 가능.
* 왜 볼만한가: Opus 4.5 기준 MCP 평가 정확도가 79.5%→88.1%로 오른 벤치마크가 공개돼, 도구가 많은 실무 에이전트를 만들 때 성능과 비용 절감을 동시에 잡을 수 있는 근거가 명확함.
* 링크: https://www.anthropic.com/engineering/advanced-tool-use
