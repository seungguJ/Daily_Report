1. On-device AI 논문

* 제목: Neodragon: Mobile Video Generation Using Diffusion Transformer
* 학회/게재시점: ICLR 2026 (Poster) / 2026-01-26
* 다루는 문제: 비디오 DiT는 메모리·연산 부담이 커서 폰·노트북의 저전력 NPU에서 돌리기 어렵다는 문제.
* 핵심 Contribution: 텍스트 인코더 축소, 디코더 증류, 블록 프루닝, DMD 확장 증류를 묶어 NPU용 비디오 생성 파이프라인을 만들었다. Qualcomm Hexagon NPU에서 640×1024, 49프레임을 6.7초에 생성하고 VBench 81.61점을 기록했다.
* 인사이트:
  1. 큰 텍스트 인코더를 작은 모델로 바꾸되 이미지·비디오 데이터 없이 증류해 품질 손실을 최소화했다.
  2. 블록 중요도 기반 프루닝 후 2단계 증류로 성능을 복구했다.
  3. 샘플링 단계를 줄이는 증류까지 합쳐 모바일 비디오 생성 SOTA를 주장한다.
* 왜 볼만한가: 생성형 비디오가 클라우드 없이 기기 안에서 가능하다는 걸 NPU 실측으로 보여준다. 프라이버시·비용 측면에서 온디바이스 멀티모달의 현실적 레퍼런스다.
* 링크: https://iclr.cc/virtual/2026/poster/10008995

2. AI Agent 활용 아이템

* 이름: text-to-cad
* 공개/출시시점: v0.7.21 릴리스 2026-10-11 (활발히 주 단위 이상 릴리스 중)
* 핵심 기능: 코딩 에이전트(Claude Code, Codex 등)에 CAD 능력을 붙여 주는 SKILL.md 기반 스킬 모음이다. 텍스트·이미지 요청을 STEP로 만들고 STL/3MF/GLB 내보내기, 제조 전 검사, 도면 생성을 지원한다. MIT 라이선스.
* 활용 아이디어:
  1. 3D 프린팅용 부품(브래킷, 케이스)을 프롬프트로 만들고 STL로 바로 뽑기.
  2. 제작 서비스에 넘기기 전 설계 검사를 에이전트에 맡기기.
  3. 프로토타입 도면(DXF)과 3D 뷰어 확인까지 한 번에 돌리기.
* 왜 볼만한가: GitHub 스타 약 1.96만, 포크 약 1.9k로 이번 주 트렌딩이고 열린 이슈는 2건이다. 최근 며칠간 릴리스가 매일 나올 만큼 유지보수가 빠르다. 다만 데모는 정성 평가 위주이고 생성 STEP가 검사를 사람 손 없이 통과하는 비율은 공개되지 않았으며, 기본 텔레메트리가 켜져 있다(끄기 가능). 같은 시기 후보인 OpenRig(약 7.2k 스타)나 Cursor 플러그인 모음보다 채택 규모와 활동성이 앞서 선정했다.
* 링크: https://github.com/earthtojake/text-to-cad
