[AI Morning Brief - 2026-08-09]

1. On-device AI 논문

* 제목: SpecEdge: Scalable Edge-Assisted Serving Framework for Interactive LLMs
* 학회/게재시점: NeurIPS 2025 (Spotlight Poster, 2025년 12월 2일~7일 샌디에이고 개최, 수락 통보 2025년 9월 18일)
* 다루는 문제: LLM 서빙이 전적으로 서버·클라우드 중심으로 이루어지면서, 사용자들이 보유한 대량의 유휴 소비자용 GPU(엣지)를 전혀 활용하지 못하는 구조적 비효율
* 핵심 Contribution: 엣지 GPU(드래프팅)와 서버 GPU(검증)를 스펙큘레이티브 디코딩으로 결합해 토큰만 네트워크로 주고받는 SpecEdge 프레임워크 제안. "선제적 엣지 드래프팅"(엣지 드래프트 생성과 서버 검증을 오버랩)과 "파이프라인 인식 스케줄링"(여러 사용자 요청을 인터리빙해 서버 처리량 유지)으로 서버 전용 대비 비용 효율 1.91배, 서버 처리량 2.22배, 토큰 간 지연 11.24% 감소를 달성
* 인사이트:
  1. 사용자 기기의 유휴 GPU를 "드래프트 모델" 역할로 활용해 클라우드 서빙 비용을 실질적으로 절감할 수 있음을 실증
  2. 스펙큘레이티브 디코딩이 단일 기기 최적화를 넘어 엣지-클라우드 하이브리드 아키텍처로 확장되는 방향성을 제시
  3. 네트워크로는 토큰만 오가므로 원본 컨텍스트가 로컬에 남는 구조 — 온디바이스식 프라이버시 이점과 클라우드급 성능을 동시에 노림
* 왜 볼만한가: 온디바이스 vs 클라우드라는 이분법 대신 엣지 기기를 서버의 파트너로 삼는 하이브리드 서빙 패러다임을 제시해, 향후 온디바이스 AI 아키텍처 설계 시 참고할 만함
* 링크: https://neurips.cc/virtual/2025/poster/119940

2. AI Agent 활용 아이템

* 이름: Letta Code
* 공개/출시시점: 2025년 12월 16일 공식 출시(Letta 블로그 발표), 2026년 4월 6일 데스크톱 앱(Letta Code App) 추가 발표
* 핵심 기능: MemGPT 연구에서 파생된 "메모리 우선(memory-first)" 오픈소스 CLI 코딩 에이전트. 세션이 끝나도 메모리가 사라지지 않고 Git으로 버전 관리되는 컨텍스트(MemFS)에 누적되며, /init으로 코드베이스를 깊이 학습하고 /remember로 사용자가 직접 지식을 교정 가능. Claude·GPT·Gemini 등 특정 벤더에 종속되지 않는 모델 아그노스틱 구조이며, 스킬을 마크다운 파일로 공유·버전관리하는 시스템 제공
* 활용 아이디어:
  1. 같은 코드베이스를 반복적으로 다루는 팀에서 세션마다 컨텍스트를 새로 설명할 필요 없이 누적 학습되는 개인·팀 코딩 에이전트로 도입
  2. /remember로 특정 컨벤션·버그 이력을 명시적으로 교정해 팀 고유의 개발 규칙을 에이전트에 학습시킴
  3. 마크다운 기반 스킬을 팀 내 공유·버전관리해 코드 리뷰 체크리스트, 배포 절차 등 반복 작업을 표준화
* 왜 볼만한가: Terminal-Bench에서 오픈소스·모델 아그노스틱 코딩 하네스 중 상위권으로 평가받았고, Hacker News 출시 스레드에서 메모리 우선 설계의 참신함에 대한 긍정적 반응과 메모리 유지 비용·컨텍스트 오염 위험에 대한 건설적 비판이 함께 오가며 실질적 논의가 이루어짐. 스타 수는 3천 개로 아직 초기 단계지만, CVE나 사용자 동의 없는 자율 행동 같은 중대한 보안 사고 없이 상대적으로 깨끗한 트랙 레코드를 보유함(다만 메모리 포이즈닝 관련 이슈는 아직 미해결 상태로 공개 트래킹 중이므로 참고 필요)
* 링크: https://www.letta.com/blog/letta-code/
