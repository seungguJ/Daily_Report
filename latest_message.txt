[AI Morning Brief - 2026-07-06]

1. On-device AI 논문

* 제목: On-Device Collaborative Language Modeling via a Mixture of Generalists and Specialists (CoMiGS)
* 학회/게재시점: ICML 2025 (PMLR 267, 2025년 7월)
* 다루는 문제: 온디바이스 연합학습(federated learning) 환경에서는 사용자마다 디바이스 연산 능력과 로컬 데이터 분포가 제각각이라, 하나의 모델로는 자원 이질성과 데이터 이질성을 동시에 만족시키기 어려움.
* 핵심 Contribution: 모두가 공유하는 "제너럴리스트" 전문가와 사용자별 로컬 "스페셜리스트" 전문가로 구성된 Mixture-of-Experts를 이중 레벨(bi-level) 최적화로 학습. 라우터를 별도 검증셋으로 학습시켜 오버피팅을 억제하면서 사용자별 전문가 수를 자유롭게 조절.
* 인사이트:
  1. 디바이스 성능 차이에 맞춰 로컬 스페셜리스트 개수를 유연하게 늘리거나 줄일 수 있음
  2. 제너럴리스트를 공유해도 개인화 과정에서 일반화 성능이 무너지지 않음
  3. 원본 데이터를 서버로 전송하지 않고 협업 학습이 가능해 프라이버시 보존과 온디바이스 개인화를 동시에 달성
* 왜 볼만한가: 온디바이스 LLM 개인화와 연합학습을 실제로 결합해 자원 이질성 문제를 실험적으로 검증한 몇 안 되는 사례로, 엣지 디바이스용 개인화 모델 설계에 바로 참고할 수 있음.
* 링크: https://openreview.net/forum?id=rf0ZoDASnS

2. AI Agent 활용 아이템

* 이름: Claude Code Dynamic Workflows
* 공개/출시시점: 2026년 5월 25일~29일 리서치 프리뷰 공개 (Claude Code v2.1.150 이상)
* 핵심 기능: 사용자가 작업을 설명하면 Claude가 직접 오케스트레이션 스크립트(자바스크립트)를 작성하고, 이 스크립트가 백그라운드에서 수십~수백 개의 서브에이전트를 동시에 실행. `/workflows` 명령으로 진행 상황을 실시간 확인 가능.
* 활용 아이디어:
  1. "코드베이스 전체에서 인증 누락 라우트 감사해줘"처럼 한 번의 대화로 조율하기 어려운 대규모 작업을 자동화
  2. 여러 소스를 교차 검증해야 하는 리서치 질문에 에이전트를 병렬 투입해 신뢰도 높은 결과 도출(`/deep-research` 내장 워크플로우)
  3. 반복되는 작업(브랜치마다 리뷰, 대규모 마이그레이션)은 워크플로우를 저장해 커맨드처럼 재사용
* 왜 볼만한가: 사람이 오케스트레이션 코드를 직접 짜지 않아도 대규모 멀티에이전트 작업을 코드로 관리할 수 있게 해주는 신기능으로, 반복 업무 자동화에 바로 적용 가능.
* 링크: https://code.claude.com/docs/en/workflows
