1. On-device AI 논문

* 제목: KV Cache Transform Coding for Compact Storage in LLM Inference (KVTC)
* 학회/게재시점: ICLR 2026 (포스터, 2026-04-25 발표)
* 다루는 문제: 긴 컨텍스트를 처리하는 LLM 서빙에서 KV 캐시가 시퀀스 길이·동시 사용자 수에 비례해 선형으로 커지면서, 메모리가 제한된 환경(로컬·엣지 추론 포함)에서 서빙을 제약하는 문제.
* 핵심 Contribution: 모델 가중치 변경이나 재학습 없이, PCA 기반 특징 비상관화 + 적응형 양자화 + 엔트로피 코딩(고전 미디어 코덱에서 착안)을 결합한 경량 KV 캐시 압축 기법(KVTC)을 제안. 짧은 보정(calibration) 과정만으로 기존 파이프라인에 적용 가능.
* 인사이트:
  1. Llama 3, Mistral NeMo, R1-Qwen2.5 등에서 최대 20배, 일부 설정에서는 40배 이상 KV 캐시 압축을 달성하면서도 AIME25·GSM8K·LongBench·RULER에서 정확도를 크게 유지.
  2. 학습이 필요 없는(training-free) 방식이라 기존 서빙 스택에 빠르게 적용 가능해, 온디바이스·메모리 제약 환경에서 실용성이 높음.
  3. 양자화 위주였던 기존 KV 캐시 연구와 달리 신호 처리·코덱 관점을 LLM 추론에 접목한 접근이라는 점이 차별점.
* 왜 볼만한가: 긴 컨텍스트 추론을 온디바이스·저메모리 환경에서 돌리려는 팀이 재학습 없이 바로 시도해볼 수 있는 압축 기법이라 실무 적용 문턱이 낮음.
* 링크: https://iclr.cc/virtual/2026/poster/10008708

2. AI Agent 활용 아이템

* 이름: BrowserSkill (Tencent)
* 공개/출시시점: 저장소 공개 2026-06-22, 최신 릴리스(v0.3.1) 2026-09-23
* 핵심 기능: CLI(`bsk`) + 로컬 데몬 + 브라우저 확장으로 구성되어, Claude Code·Cursor·Codex 등 셸 기반 AI 에이전트가 사용자가 이미 로그인해 둔 실제 Chrome/Edge 브라우저를 그대로 조작하게 해주는 도구. 페이지 읽기, 클릭, 폼 입력, 파일 업/다운로드, 스크린샷, 네트워크 요청 확인이 가능하고, 캡차·로그인처럼 사람 개입이 필요한 순간에는 제어권을 사람에게 넘겼다가 다시 에이전트로 돌려받음.
* 활용 아이디어:
  1. 별도 테스트 계정이나 쿠키 export 없이, 이미 로그인된 사내 시스템·SaaS 화면을 에이전트가 그대로 조작하는 업무 자동화에 활용.
  2. 실제 로그인 세션 위에서 웹 UI를 디버깅·QA하는 에이전트 워크플로에 연결.
  3. 캡차·2단계 인증 구간만 사람이 처리하고 나머지는 에이전트가 진행하는 반자동 브라우징 파이프라인 구성.
* 왜 볼만한가: 공개 이틀 만에 스타 4,000개를 넘기고 현재 약 6,900개(GitHub 직접 확인)를 기록할 만큼 빠르게 확산 중이며, "에이전트가 실제 로그인 세션을 그대로 쓸 수 있는가"라는 실질적 문제를 짚었다는 반응이 많음. 다만 인증된 세션 접근에 따른 프롬프트 인젝션 악용 우려도 함께 제기되고 있어, Playwright·browser-use 계열 도구 대비 차별점과 보안 트레이드오프를 함께 살펴볼 가치가 있음.
* 링크: https://github.com/Tencent/BrowserSkill
