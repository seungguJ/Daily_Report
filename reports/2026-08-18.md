[AI Morning Brief - 2026-08-18]

1. On-device AI 논문

* 제목: DP-LLM: Runtime Model Adaptation with Dynamic Layer-wise Precision Assignment
* 학회/게재시점: NeurIPS 2025 (2025년 12월, Poster)
* 다루는 문제: 온디바이스에서 LLM을 서빙할 때 상황마다 달라지는 지연시간·메모리 제약에 맞춰 정확도와 속도의 균형을 잡아야 하는데, 기존 양자화는 모델 전체에 고정된 비트폭을 적용해 유연성이 떨어지는 문제
* 핵심 Contribution: 여러 비트폭 버전을 겹쳐 저장하는 멀티스케일 양자화를 기반으로, 디코딩 스텝마다 레이어별 양자화 오차 민감도가 달라진다는 점에 착안해 레이어 단위로 고정밀/저정밀 가중치를 실시간 전환하는 경량 프리시전 셀렉터를 제안. 여러 모델·벤치마크에서 기존 정적/거친 단위 정밀도 전환 기법보다 나은 지연-정확도 트레이드오프를 달성
* 인사이트:
  1. 양자화를 "한 번 정해서 고정"하는 게 아니라 디코딩 도중 레이어 단위로 실시간 조절하는 방향으로 접근을 바꾸면 같은 메모리 예산에서 더 나은 품질을 뽑아낼 수 있음
  2. 레이어마다 오차 민감도가 시점에 따라 달라진다는 관찰 자체가 향후 온디바이스 추론 최적화 연구의 새로운 축이 될 수 있음
  3. 서울대 ARC랩이 코드까지 공개해 재현성과 실제 적용 가능성을 높임
* 왜 볼만한가: 스마트폰처럼 배터리·메모리·발열 제약이 시시각각 바뀌는 환경에서 "상황에 맞게 정밀도를 실시간으로 조절하는 추론"이라는 실용적 방향을 제시해, 온디바이스 LLM 서빙 엔진 설계에 바로 참고할 만함
* 링크: https://neurips.cc/virtual/2025/poster/115920

2. AI Agent 활용 아이템

* 이름: Agent Plugins (스펙 v1.0.0)
* 공개/출시시점: 2026년 8월 6일, Vercel 주도로 AWS·Anysphere(Cursor)·GitHub·Microsoft·OpenAI 등이 공동 참여해 v1.0.0 최초 공개(같은 날 Google도 합류)
* 핵심 기능: 에이전트 확장 기능(Skill, MCP 서버)을 한 번만 패키징하면 VS Code·Cursor·GitHub Copilot·ChatGPT/Codex·Kiro 등 여러 클라이언트에서 그대로 쓸 수 있게 하는 벤더 중립 패키징 표준. plugin.json 매니페스트 하나로 skills/ 폴더와 mcp.json을 함께 배포하는 최소한의 폴더 규격을 정의
* 활용 아이디어:
  1. 사내에서 만든 Skill·MCP 서버를 이 표준 폴더 구조로 패키징해, 팀원들이 어떤 코딩 에이전트를 쓰든 동일하게 배포·재사용
  2. 여러 클라이언트별로 따로 만들던 확장 기능을 하나로 통합해 유지보수 비용 절감
  3. 스펙 저장소의 예제·마이그레이션 가이드를 참고해 기존 Agent Skills/MCP 자산을 이 표준으로 전환
* 왜 볼만한가: 평소 경쟁 관계인 AWS·Cursor·GitHub·Microsoft·OpenAI·Vercel·Google이 하나의 패키징 표준에 동시에 합의한 것 자체가 이례적인 사건으로, 출시 당일부터 5개 이상 주요 클라이언트가 지원을 발표했음. 공개 12일 만에 GitHub 스타 1.1k·포크 60을 기록했고 Vercel 공식 블로그와 Hacker News 등에서 다뤄졌으나, 아직 서명 검증·배포자 신원·권한 샌드박싱 같은 신뢰/보안 모델은 스펙 범위 밖으로 남겨둔 초기 단계라는 점은 유의할 필요가 있음. 최근 며칠 사이 공개된 항목이라 스타 수 자체는 다른 성숙한 프레임워크보다 적지만, 빅테크 다자 합의라는 신호와 실질적 상호운용성 효과가 더 크다고 판단해 선정
* 링크: https://github.com/agentplugins/agent-plugins-spec
