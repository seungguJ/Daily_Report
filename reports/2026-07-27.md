[AI Morning Brief - 2026-07-27]

1. On-device AI 논문

* 제목: SlimLM: An Efficient Small Language Model for On-Device Document Assistance
* 학회/게재시점: ACL 2025 (2025년 7월, Vienna, System Demonstrations)
* 다루는 문제: 소형 언어모델(SLM)이 스마트폰에서 실제로 얼마나 잘 동작하는지 검증이 부족한 상태에서, 문서 요약·질의응답·작성 제안 같은 온디바이스 문서 어시스턴트를 어떻게 설계해야 하는지의 문제
* 핵심 Contribution: Samsung Galaxy S24 실기기에서 125M~7B 파라미터 SLM을 광범위하게 실험해 모델 크기·컨텍스트 길이·추론 시간 사이의 최적 균형점을 규명. SlimPajama-627B로 사전학습하고 자체 구축한 DocAssist 데이터셋(요약/QA/제안)으로 파인튜닝한 SlimLM 모델군을 제시하고, 실제 동작하는 안드로이드 앱까지 함께 공개
* 인사이트:
  1. 시뮬레이션이 아닌 실기기(S24) 벤치마크 기반이라 이론상 효율이 아니라 실제 지연시간·메모리 제약에서 검증된 결과
  2. 최소 모델도 실사용 가능한 성능을 보이고 더 큰 변형은 모바일 제약 안에서 추가 기능을 제공해, 기기 스펙별 모델 선택 가이드로 바로 활용 가능
  3. 기존 SLM 대비 동등하거나 우수한 성능을 보이며, 온디바이스 언어모델 후속 연구를 위한 공개 벤치마크와 데이터셋을 제공
* 왜 볼만한가: 온디바이스 문서 어시스턴트를 만들 때 "어느 크기 모델을, 어떤 컨텍스트 길이로, 얼마나 빠르게" 돌릴지에 대한 실측 기반 설계 가이드를 제공해 실무 적용성이 높음
* 링크: https://aclanthology.org/2025.acl-demo.42/

2. AI Agent 활용 아이템

* 이름: Superpowers (Jesse Vincent / Prime Radiant)
* 공개/출시시점: 2025년 10월 9일 최초 공개, 2026년 초 Anthropic 공식 플러그인 마켓플레이스에도 등재
* 핵심 기능: 코딩 에이전트를 위한 마크다운 기반 스킬 프레임워크. 브레인스토밍 → 계획 수립 → 격리된 워크트리 생성 → TDD 기반 서브에이전트 실행 → 2단계 코드 리뷰 → 머지로 이어지는 소프트웨어 개발 방법론 전체를 SKILL.md 파일들로 패키징해 에이전트가 이를 강제로 따르게 함
* 활용 아이디어:
  1. Claude Code, Cursor, Codex CLI, Gemini CLI, GitHub Copilot CLI 등 8개 이상의 에이전트 하네스에 동일한 스킬 폴더를 그대로 설치해 일관된 개발 프로세스를 적용
  2. 팀의 암묵적 개발 관행(설계 논의 방식, 태스크 분해 단위, 리뷰 기준)을 마크다운 스킬 파일로 문서화해 여러 에이전트·개발자가 공유
  3. MIT 라이선스 오픈소스라 자체 스킬을 추가·수정해 팀 전용 워크플로우로 손쉽게 커스터마이징 가능
* 왜 볼만한가: 공개 7개월 만에 스타 수가 20만 개를 넘어서며 "가장 널리 쓰이는 에이전틱 스킬 프레임워크"로 자리잡았고, Anthropic 공식 플러그인 마켓플레이스에 등재될 만큼 검증됨. 같은 기간 화제였던 OpenClaw는 스타 수는 더 크지만 CVE·프롬프트 인젝션·토큰 탈취 등 반복적인 보안 취약점이 다수 보고돼 실무 도입엔 주의가 필요해 이번엔 제외했고, 스킬/마크다운 기반으로 안전하고 실용적인 Superpowers를 선정
* 링크: https://github.com/obra/superpowers
