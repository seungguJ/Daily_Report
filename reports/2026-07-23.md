[AI Morning Brief - 2026-07-23]

1. On-device AI 논문

* 제목: K-Merge: Online Continual Merging of Adapters for On-device Large Language Models
* 학회/게재시점: ACL 2026 (2026년 7월, 샌디에이고, Main Conference Oral)
* 다루는 문제: 온디바이스 LLM은 앱·기능 업데이트마다 새로운 LoRA 어댑터가 순차적으로 배포되는데, 기기가 저장할 수 있는 어댑터 개수(K개)는 한정돼 있어 새 태스크를 계속 편입하면서도 기존 태스크 성능을 잃지 않는 "온라인 지속적 병합"이 필요한 문제
* 핵심 Contribution: 원본 학습 데이터에 다시 접근하지 않고도(data-free) 새 LoRA가 도착할 때마다 가장 유사한 기존 어댑터를 골라 병합할지·새로 저장할지를 가볍게 결정하는 알고리즘 K-Merge 제안. 저장 예산 K개를 넘지 않으면서 기존 병합·교체 전략 대비 우수한 성능을 실증
* 인사이트:
  1. 개인정보 보호 규제와 저장 제약상 원본 학습 데이터를 재사용할 수 없다는, 실제 온디바이스 배포에 부합하는 전제를 그대로 반영한 설계
  2. 계산량이 가벼워 클라우드 재훈련 없이 기기 안에서 실시간으로 실행 가능 — LoRA 배포가 잦은 온디바이스 어시스턴트/코파일럿 제품에 바로 적용 가능
  3. "몇 개까지 저장할지"가 아니라 "언제 합치고 언제 새로 저장할지"를 데이터 없이 판단하는 문제를 처음으로 체계화해, 향후 온디바이스 지속학습 연구의 기준점이 될 만함
* 왜 볼만한가: 온디바이스 LLM이 여러 LoRA로 기능을 계속 늘려가는 흐름에서, 저장공간 제약 속 지속적 어댑터 관리 문제를 실용적으로 풀어낸 삼성 리서치발 ACL 오랄 논문
* 링크: https://2026.aclweb.org/program/accepted_papers/

2. AI Agent 활용 아이템

* 이름: NVIDIA SkillSpector
* 공개/출시시점: 2026년 5월 19일 NVIDIA 공식 발표 및 오픈소스 공개
* 핵심 기능: Claude Code, Codex CLI, Gemini CLI 등에서 쓰이는 Agent Skill을 설치 전에 스캔하는 보안 도구. 취약한 의존성·위험한 코드 패턴 같은 전통적 소프트웨어 위험뿐 아니라, 프롬프트 인젝션·숨겨진 지시문·트리거 남용·과도한 권한 요청 등 에이전트 특화 위험까지 17개 카테고리·68개 패턴으로 탐지하며, 선언된 목적과 실제 동작이 다른지 보는 의도 계층 분석도 지원
* 활용 아이디어:
  1. `skillspector scan` 명령으로 깃허브 저장소·zip·로컬 폴더 형태의 Skill을 설치 전에 검사해 사내 Skill 배포 파이프라인의 사전 검증 게이트로 활용
  2. NVIDIA가 실제 조사에서 스킬의 26.1%에서 취약점, 5.2%에서 악성 의심 패턴을 발견했다고 밝힌 만큼, 사내/사외에서 가져온 커뮤니티 Skill을 그대로 신뢰하지 말고 CI에 통합해 자동 스캔
  3. 정적 검사(빠른 정규식/AST 기반)와 선택적 LLM 시맨틱 분석을 조합해, Skill 마켓플레이스 운영자가 게시 전 리스크 리포트를 자동 생성하는 데 활용
* 왜 볼만한가: Agent Skills 생태계가 Claude Code·Codex·Gemini CLI 등으로 빠르게 확산되면서 "출처 불명 Skill을 그대로 실행해도 되는가"라는 공급망 보안 문제가 커지고 있는데, NVIDIA가 공식 릴리스 후 3개월 만에 GitHub 스타 1만 3천 개대로 빠르게 채택되며 이 문제에 대한 실질적 답을 제시. 여러 신규 Skill 라이브러리(예: UI 생성용 stitch-skills)도 후보였지만, 이들은 특정 도메인 생산성 확장에 그치는 반면 SkillSpector는 에이전트 생태계 전체의 신뢰·보안 기반을 다룬다는 점에서 지금 시점에 더 볼만하다고 판단해 선정
* 링크: https://github.com/NVIDIA/SkillSpector
