[AI Morning Brief - 2026-10-01]

1. On-device AI 논문

* 제목: Long-Context Modeling with Dynamic Hierarchical Sparse Attention for Memory-Constrained LLM Inference
* 학회/게재시점: ICML 2026 (포스터, 2026-07-08)
* 다루는 문제: 긴 컨텍스트 추론은 어텐션 연산과 메모리 비용이 커서 메모리가 제한된 기기에서는 실행 자체가 어렵다. 기존 sparse attention은 정확도 손실이 크다는 점이 문제다.
* 핵심 Contribution: LLM 백본은 고정한 채, 어텐션 희소성을 온라인으로 예측하는 DHSA 프레임워크를 제안한다. 청크 단위 중요도를 먼저 추정하고 토큰 단위 상호작용으로 전파해 중요한 의존성을 보존한다.
* 인사이트:
  1. 재학습 없이 기존 오픈 가중치 모델에 붙일 수 있고, 여러 모델 계열에서 동작한다.
  2. Block Sparse Attention 대비 상대 정확도가 12~20% 높고, 128K 컨텍스트에서 prefill이 최대 10배 빨라진다.
  3. LLaMA-3.1-8B(4-bit)로 24GB GPU 한 장에서 100K 컨텍스트를 처리한다. 일반 dense attention은 여기서 실패한다.
* 왜 볼만한가: 로컬 기기에서 긴 문서를 다루는 온디바이스 LLM의 메모리 한계를 직접 겨냥한다. 양자화 모델과 함께 쓰는 실전 구성이라 참고할 만하다.
* 링크: https://icml.cc/virtual/2026/poster/61654

2. AI Agent 활용 아이템

* 이름: Paperclip (paperclipai/paperclip)
* 공개/출시시점: 릴리스 페이지 기준 2026-07-07 첫 릴리스, 최신 v2026.916.1 릴리스 2026-09-21
* 핵심 기능: 여러 AI 에이전트를 한 팀처럼 관리하는 오픈소스 오케스트레이션 앱이다. 조직도, 역할·권한, 작업 티켓, 예산 한도, 승인 워크플로를 제공하고 Claude, Codex, OpenClaw 등 다양한 에이전트를 작업자로 연결한다. MIT 라이선스이고 MCP 서버 연동을 지원한다.
* 활용 아이디어:
  1. 코딩 에이전트 여러 개에 작업을 나눠 주고, 월 예산 한도로 비용이 넘치지 않게 통제한다.
  2. 승인 단계와 감사 기록을 두어 에이전트 결정 과정을 추적한다.
  3. Slack, Discord, Telegram 등 채팅 커넥터로 작업을 받고 결과를 확인한다. 설치는 `npx paperclipai@latest onboard --yes` 한 줄이다.
* 왜 볼만한가: GitHub 약 9.5만 stars, forks 약 1.6만으로 이번 주 트렌딩 상위권이고 커밋과 릴리스가 활발하다. 다만 열린 이슈가 약 2.6k개이고 인증·Git 작업 관련 버그 보고가 있어 운영 환경 도입은 신중해야 한다. 채택 규모와 거버넌스 기능이 강점이라 이번 후보 중 선정했다.
* 링크: https://github.com/paperclipai/paperclip
