[AI Morning Brief - 2026-07-19]

1. On-device AI 논문

* 제목: KV Cache Transform Coding for Compact Storage in LLM Inference (KVTC)
* 학회/게재시점: ICLR 2026 (2026년 4월, Poster)
* 다루는 문제: 멀티턴 대화나 코드 편집처럼 프롬프트를 재사용하는 상황에서 KV 캐시가 계속 쌓여 GPU/로컬 메모리를 잠식하고, 결국 오프로딩이나 재계산을 강제하는 문제. 메모리가 빠듯한 온디바이스·엣지 추론 환경일수록 병목이 더 크게 나타남
* 핵심 Contribution: PCA 기반 특징 비상관화, 적응형 양자화, 엔트로피 코딩을 결합한 경량 KV 캐시 트랜스폼 코더(KVTC). 모델 파라미터는 그대로 두고 짧은 캘리브레이션만으로 기존 파이프라인에 바로 적용 가능
* 인사이트:
  1. Llama 3, Mistral NeMo, R1-Qwen2.5 등에서 최대 20배(특정 케이스는 40배 이상) 캐시 압축을 달성하면서도 추론·장문맥 정확도를 거의 그대로 유지
  2. 재학습 없이 캐시 저장 방식만 바꾸는 방식이라 서버는 물론 메모리 제약이 큰 로컬 추론 파이프라인에도 이식이 쉬움
  3. GPU 상주뿐 아니라 오프-GPU(디스크·호스트 메모리) 저장까지 고려해 설계돼, 캐시 재사용이 잦은 코딩 어시스턴트류 온디바이스 앱에 실질적 이득
* 왜 볼만한가: KV 캐시는 온디바이스 LLM에서 메모리를 가장 빨리 잡아먹는 요소인데, 재학습 없이 20~40배 압축을 실현해 로컬·엣지 배포의 메모리 병목을 크게 낮출 수 있는 실용적 해법
* 링크: https://iclr.cc/virtual/2026/poster/10008708

2. AI Agent 활용 아이템

* 이름: Agent Skills (addyosmani/agent-skills)
* 공개/출시시점: 2026년 2월 첫 공개, 현재 v0.6.4(2026년 7월)까지 활발히 업데이트 중
* 핵심 기능: 구글 크롬팀 출신 Addy Osmani가 만든 24개의 SKILL.md 기반 엔지니어링 워크플로우 모음. 스펙 작성 → 계획 → 구현(TDD) → 검증 → 코드리뷰 → 배포까지 개발 전 주기를 다루며, /spec, /plan, /build, /test, /review, /ship 등 슬래시 커맨드로 바로 실행됨
* 활용 아이디어:
  1. `npx skills add addyosmani/agent-skills`로 Claude Code, Cursor, Codex, Gemini CLI 등 70여 개 에이전트에 바로 설치해 팀 전체 코딩 표준을 일괄 적용
  2. 코드 리뷰어·테스트 엔지니어·보안 감사·성능 감사 4개 전문 페르소나로 에이전트가 스펙 생략·테스트 부족·보안 미검토 같은 지름길로 가지 않도록 단계별 검증 게이트 삽입
  3. 사내 온보딩 문서 대신 SKILL.md를 버전관리하며 "시니어 엔지니어링 판단 기준"을 코드베이스와 함께 배포·공유
* 왜 볼만한가: OpenClaw 같은 초대형 화제작이 RCE 취약점과 악성 스킬 마켓플레이스 이슈로 몸살을 앓는 사이, agent-skills는 큰 보안 이슈 없이 공개 5개월 만에 7.9만+ 스타(포크 8.5천)를 모으며 실용성으로 검증됐고 MIT 라이선스로 꾸준히 유지보수되고 있어 지금 도입하기에 안심되는 선택
* 링크: https://github.com/addyosmani/agent-skills
