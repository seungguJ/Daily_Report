[AI Morning Brief - 2026-09-01]

1. On-device AI 논문

* 제목: LEAP: Zone-Aware MCTS for LLM Self-Speculative Decoding
* 학회/게재시점: ICML 2026 (Poster, 2026년 7월 8일)
* 다루는 문제: Self-speculative decoding은 별도의 draft 모델 없이 타깃 모델 자체의 레이어 일부만 뽑아 draft처럼 쓰는 방식으로 추론을 가속하는데, 어떤 레이어 조합을 남길지 정하는 layer configuration 탐색 공간이 깊은 LLM일수록 조합적으로 폭발해 최적 설정을 찾기 어려움
* 핵심 Contribution: 레이어 구성 선택 문제를 순차적 의사결정 문제로 재정의하고 Monte Carlo Tree Search(MCTS)로 최적화하는 LEAP을 제안. prefilling 단계에서 계산한 redundancy 정보가 디코딩 내내 유효하다는 점과 레이어 중복도가 "zone" 단위로 뭉쳐 나타난다는 두 관찰을 활용해 zone 분할·레이어 그룹핑으로 탐색 공간을 구조화, MCTS를 실용적인 수준으로 축소. 학습 없이 바로 적용 가능한 plug-and-play 방식으로 1.7~2.0배 추론 속도 향상을 보고
* 인사이트:
  1. 별도 draft 모델을 학습·저장할 필요 없이 타깃 모델 자체에서 draft를 뽑아내는 방식이라 메모리 여유가 없는 온디바이스 환경에 특히 잘 맞음
  2. "레이어 선정"이라는 조합 최적화 문제를 탐색 알고리즘(MCTS) 문제로 치환한 접근이라 다른 구조적 압축·서빙 최적화 문제에도 적용 가능한 일반적 프레임을 제시
  3. 학습이 전혀 필요 없는 plug-and-play 방식이라, 이미 배포된 온디바이스 LLM에 재학습 없이 바로 적용해 지연시간을 줄일 수 있다는 실전성이 강점
* 왜 볼만한가: 별도 모델 없이 "자기 자신을 깎아 만든 draft"로 속도를 내는 self-speculative decoding에서, 레이어 선택이라는 핵심 난제를 탐색 알고리즘으로 정면 돌파했다는 점에서 온디바이스 추론 가속 연구의 실용적 다음 단계를 보여줌
* 링크: https://icml.cc/virtual/2026/poster/63577

2. AI Agent 활용 아이템

* 이름: Pydantic AI V2 (Harness)
* 공개/출시시점: 2026년 6월 23일 정식 출시(v2.0.0), 이후 8월 31일까지 v2.37.0 수준까지 거의 매일 패치가 이어지는 등 활발히 유지보수 중
* 핵심 기능: 타입 안전성을 앞세운 Python 에이전트 SDK로, v2의 핵심은 "Capability"라는 새 단위 — 지시문·툴·라이프사이클 훅·모델 설정을 하나로 묶어 에이전트에 끼워 넣을 수 있는 컴포저블 모듈. 이를 확장한 별도 라이브러리 "Harness"가 메모리 관리, 가드레일, 컨텍스트 관리, 파일시스템 접근, 샌드박스 코드 실행(CodeMode) 등을 즉시 장착 가능한 기능으로 제공
* 활용 아이디어:
  1. 메모리·가드레일·컨텍스트 압축 같은 반복 구현 요소를 직접 짜지 않고 Harness의 기성 capability를 붙여 프로덕션 에이전트를 빠르게 구성
  2. 필요할 때만 로드되는 deferred tool loading으로 프롬프트에 안 쓰는 툴 정의를 올리지 않아 장시간 에이전트 세션의 토큰 비용과 컨텍스트 부담을 절감
  3. 타입이 프로바이더 간 그대로 유지되는 구조를 활용해 Claude·GPT 등 모델을 최소한의 코드 변경으로 교체하며 실험
* 왜 볼만한가: GitHub 스타 1만 9,600개·포크 2,600개로 채택 규모가 크고, v2 출시 후 두 달여 만에 30여 차례 패치가 나올 만큼 유지보수 속도가 빠름. Hacker News에서는 신규 기능 "Code Mode"(LLM이 라이브러리 전체 접근 없이 파이썬 코드를 작성하게 하는 방식)를 두고 기술적 찬반 토론이 이어졌고 Pydantic AI 리드 엔지니어가 직접 댓글로 설계 의도를 해명하는 등 실제 개발자 커뮤니티의 진지한 관심을 받고 있음. LangGraph·Mastra 같은 기존 프레임워크형 아이템과 달리 "capability"라는 새로운 조립 단위를 프레임워크 코어에 도입했다는 점에서 이번에 선정
* 링크: https://pydantic.dev/articles/pydantic-ai-v2
