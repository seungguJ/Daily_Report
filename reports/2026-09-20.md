1. On-device AI 논문

* 제목: PARD: Accelerating LLM Inference with Low-Cost PARallel Draft Model Adaptation
* 학회/게재시점: ICLR 2026 (accept 통보 2026-01-22, 포스터 세션 2026-04-25)
* 다루는 문제: LLM의 autoregressive decoding은 한 스텝에 토큰 하나만 생성해 느리다. Speculative decoding이 이를 완화하지만, 보통 타깃 모델마다 별도의 draft 모델을 새로 학습해야 해서 비용이 크다.
* 핵심 Contribution: 타깃 모델에 종속되지 않는 병렬 draft 모델을 "Conditional Drop-token(COD)" 방식으로 단 한 번만 학습해, 여러 타깃 모델 계열에 재사용 가능하게 만들었다. LLaMA3.1-8B + vLLM 기준 최대 3.67배 가속(264.88 tokens/sec)으로 EAGLE-3보다 1.15배 빠르다.
* 인사이트:
  1. draft 모델을 모델별로 새로 학습하지 않고 재사용할 수 있어, 로컬/엣지 서빙에 speculative decoding을 도입하는 엔지니어링·비용 장벽이 크게 낮아진다.
  2. COD 학습 방식이 기존 masked-prediction 학습보다 3배 효율적이라, 리소스가 적은 팀도 자체 draft 모델을 학습해 온디바이스 추론을 가속할 수 있다.
  3. 널리 쓰이는 speculative decoding 베이스라인인 EAGLE-3보다 빠른 실측 성능을 보여, 실제 배포 단계까지 성숙도가 높다는 신호다.
* 왜 볼만한가: speculative decoding은 온디바이스 LLM 지연시간을 줄이는 가장 실용적인 방법 중 하나인데, PARD는 "타깃 모델마다 draft 모델을 새로 학습해야 하는" 가장 큰 도입 장벽을 없앴다는 점에서 모바일/엣지 배포에 바로 의미가 있다.
* 링크: https://iclr.cc/virtual/2026/poster/10008956

2. AI Agent 활용 아이템

* 이름: gh skill (GitHub CLI의 Agent Skills 관리 명령어)
* 공개/출시시점: 2026-04-16 (GitHub 공식 Changelog 발표)
* 핵심 기능: SKILL.md 형태의 에이전트 스킬을 GitHub CLI로 검색·설치·미리보기·업데이트·배포할 수 있게 해주는 기능이다. Copilot, Claude Code, Cursor, Codex, Gemini CLI 등 여러 에이전트 호스트를 지원하며 공개 스펙인 agentskills.io를 기반으로 한다. 태그/커밋 SHA로 버전을 고정해 설치할 수 있고, 설치 전 내용을 확인하는 `gh skill preview`도 제공한다.
* 활용 아이디어:
  1. 팀 표준 스킬을 커밋 SHA/태그로 버전 고정해 배포하면, 여러 에이전트 툴에서 동일한 동작을 보장할 수 있다.
  2. 설치 전 `gh skill preview`로 스킬 내용을 검사해 프롬프트 인젝션이나 악성 스크립트 유입을 사전에 차단할 수 있다.
  3. Copilot·Claude Code·Cursor 등 여러 호스트에서 같은 스킬을 재사용할 수 있어, 스킬을 도구별로 따로 관리하는 유지보수 비용을 줄일 수 있다.
* 왜 볼만한가: 우후죽순 늘어나는 "에이전트 스킬" 생태계에 GitHub이 npm과 유사한 배포·버전 관리 체계를 제공했다는 점이 크다. 이미 4.6만 개 이상의 스타를 보유한 GitHub CLI(cli/cli)에 내장된 기능이라 도입 장벽이 낮고, 출시 직후 여러 개발자 블로그(dev.to, azukiazusa.dev 등)에서 소개될 만큼 실사용 관심도도 확인된다. 다만 GitHub 스스로도 "스킬은 검증되지 않았을 수 있다"고 명시하며 `gh skill preview` 사용을 권장하는 만큼, 출처가 불분명한 스킬은 반드시 내용을 확인한 뒤 설치하는 것이 좋다.
* 링크: https://github.blog/changelog/2026-04-16-manage-agent-skills-with-github-cli/
