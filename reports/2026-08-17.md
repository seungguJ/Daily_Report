[AI Morning Brief - 2026-08-17]

1. On-device AI 논문

* 제목: Distilling LLM Agent into Small Models with Retrieval and Code Tools
* 학회/게재시점: NeurIPS 2025 (2025년 12월, Spotlight)
* 다루는 문제: 검색·코드 실행 같은 도구를 쓰는 LLM 에이전트를 그대로 작은 모델로 증류하면, 소형 모델이 도구 사용법 자체를 제대로 배우지 못해 환각이 심해지는 문제
* 핵심 Contribution: 교사 모델의 추론 궤적 품질을 높이는 "First-thought prefix prompting"과, 소형 모델의 추론 안정성을 높이는 "Self-consistent action generation"을 제안. 단순 CoT 증류가 아니라 도구 호출을 포함한 에이전트의 전체 행동을 보존하는 방식으로, 0.5B·1.5B·3B 모델이 훨씬 큰 파인튜닝 베이스라인과 경쟁 가능한 성능을 냄
* 인사이트:
  1. 온디바이스급 초소형 모델도 내재 지식이 아니라 "검색·코드 실행 도구를 언제 어떻게 쓸지"를 학습시키면 훨씬 실용적인 에이전트가 될 수 있음을 보여줌
  2. 기존 방식은 교사의 답변만 증류했다면, 이 논문은 도구 사용 행동 자체를 보존해 소형 모델의 고질적 문제인 환각을 줄이는 구체적 레시피를 제시
  3. NeurIPS Spotlight로 선정될 만큼 학계에서도 소형 에이전트 증류 방향성을 주목하고 있음
* 왜 볼만한가: 스마트폰·로컬 환경에서 돌아가는 에이전트가 "지식이 많은 모델"이 아니라 "도구를 잘 쓰는 작은 모델"이어도 충분할 수 있다는 근거를 제시해, 온디바이스 에이전트 설계 방향에 실질적 시사점을 줌
* 링크: https://neurips.cc/virtual/2025/poster/117657

2. AI Agent 활용 아이템

* 이름: OpenClaw (구 Clawdbot/Moltbot)
* 공개/출시시점: 2025년 11월 오픈소스 최초 공개(당시 이름 Clawdbot), 2026년 1월 Anthropic 상표 이의로 Moltbot을 거쳐 OpenClaw로 최종 리브랜딩, 현재 비영리 OpenClaw 재단이 운영
* 핵심 기능: 로컬에서 구동되는 개인 AI 비서. WhatsApp·Telegram·Slack·Discord·Signal 등 메신저를 인터페이스 삼아 여러 LLM·툴을 연결하는 게이트웨이 아키텍처를 갖췄고, Skill 시스템으로 기능을 확장하며 음성·Canvas·기기 로컬 액션도 지원
* 활용 아이디어:
  1. 메신저로 지시만 내리면 파일 정리·일정 관리·리서치 같은 반복 작업을 로컬에서 자율 수행하는 개인 비서로 활용
  2. Skill 마켓플레이스의 기능을 조합해 나만의 자동화 워크플로 구성
  3. 클라우드 종속 없이 로컬 제어권을 유지하고 싶은 개발자의 자체 호스팅 에이전트 인프라로 검토
* 왜 볼만한가: 공개 8개월 만에 스타 9천 개에서 38만 개(포크 8만 개)로 폭증하며 2026년 가장 화제가 된 오픈소스 에이전트로, CNBC·Fortune 등 주요 매체가 다뤘고 Anthropic 상표 이의로 두 차례 리브랜딩된 사연도 화제성을 키움. 다만 Skill 마켓플레이스에 등록된 스킬 중 상당수가 악성으로 확인됐고 Microsoft가 "일반 업무용 PC에는 부적합"이라 공개 경고했으며 중국 당국도 보안 위험을 공지하는 등 우려도 상당함 — 격리된 환경에서 신뢰할 수 있는 스킬만 설치하는 등 각별한 주의가 필요함
* 링크: https://github.com/openclaw/openclaw
