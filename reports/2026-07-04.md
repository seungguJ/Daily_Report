1. On-device AI 논문

* 제목: KV Cache Transform Coding for Compact Storage in LLM Inference (KVTC)
* 학회/게재시점: ICLR 2026 (포스터, 2026-04-25)
* 다루는 문제: LLM 추론 시 KV 캐시가 문맥 길이와 레이어 수에 비례해 선형으로 커지면서 메모리 병목이 되고, 특히 온디바이스·엣지 환경처럼 메모리가 제한된 곳에서는 긴 문맥 처리가 어려움.
* 핵심 Contribution: PCA 기반 특징 비상관화, 적응형 양자화, 엔트로피 코딩을 결합한 경량 트랜스폼 코더 KVTC를 제안. 재학습이나 전용 커널 없이 기존 추론 엔진과 호환되며, Llama 3·Mistral NeMo·R1-Qwen 2.5 등에서 최대 20배, 특정 상황에서 40배 이상 압축을 정확도 손실 없이 달성.
* 인사이트:
  1. 단순 토큰 제거(eviction)가 아니라 신호 압축(변환+양자화+엔트로피 코딩) 방식으로 접근해 압축률과 정확도 두 마리 토끼를 잡음.
  2. 기존 추론 스택 변경이 거의 없어 온디바이스 런타임에 바로 적용 가능성이 높음.
  3. GPU/오프-GPU 저장 모두를 겨냥해 장문 대화나 문서 처리 시 메모리 여유를 실질적으로 늘려줌.
* 왜 볼만한가: 온디바이스 LLM의 최대 약점인 "긴 문맥 = 메모리 폭증" 문제를 커널 교체 없이 완화할 수 있는 실전형 기법이라 도입 장벽이 낮음.
* 링크: https://iclr.cc/virtual/2026/poster/10008708

2. AI Agent 활용 아이템

* 이름: Microsoft Agent Framework 1.0 (GA)
* 공개/출시시점: 2026-04-03 (정식 GA)
* 핵심 기능: AutoGen과 Semantic Kernel을 통합한 오픈소스 에이전트 SDK. 단일/다중 에이전트 오케스트레이션(순차, 동시, handoff, group chat, Magentic-One), MCP 기반 동적 도구 탐색, A2A 프로토콜, YAML 선언형 정의, 체크포인트·휴먼인더루프 승인을 지원하며 Claude를 포함한 여러 모델 벡엔드와 연동 가능.
* 활용 아이디어:
  1. MCP로 사내 API·DB·파일 시스템을 즉시 도구화해 에이전트에 연결.
  2. handoff/group chat 패턴으로 여러 전문 에이전트가 협업하는 업무 자동화 프로토타입 제작.
  3. YAML 정의 + 체크포인트로 승인 단계를 넣은 프로덕션 배포 파이프라인 설계.
* 왜 볼만한가: 두 개로 나뉘어 있던 MS의 에이전트 프레임워크가 하나의 정식(1.0) SDK로 통합되어 프로덕션 안정성을 표방하고, 멀티 모델·MCP 생태계와 바로 호환돼 실무 도입 장벽이 낮음.
* 링크: https://devblogs.microsoft.com/agent-framework/microsoft-agent-framework-version-1-0/
