1. On-device AI 논문

* 제목: PT²-LLM: Post-Training Ternarization for Large Language Models
* 학회/게재시점: ICLR 2026 (2026년 4월, Poster)
* 다루는 문제: LLM을 온디바이스·엣지 환경에 올리려면 메모리·연산 부담이 큰데, 재학습(fine-tuning) 없이도 가중치를 극단적으로 2비트급(ternary, {-1,0,1})까지 양자화하면서 정확도 손실을 최소화하는 방법이 필요
* 핵심 Contribution: 비대칭 Ternary Quantizer를 제안하고, 최적 ternary 격자와 유연한 반올림을 번갈아 최적화하는 Iterative Ternary Fitting과 양자화 격자를 실제 활성값 분포에 맞춰 정렬하는 Activation-aware Grid Alignment라는 2단계 정제 기법, 그리고 열 간 유사도를 활용해 이상치발 오차를 줄이는 plug-and-play 재정렬(Reordering) 전략을 결합. 재학습 없이도 최신 2비트급 PTQ 기법과 경쟁하는 성능을 달성
* 인사이트:
  1. 순수 post-training 방식만으로도 극저비트(ternary) 양자화를 실용 수준까지 끌어올릴 수 있어, 학습 인프라 없이도 온디바이스용 모델 경량화가 가능함을 보여줌
  2. 활성값 분포를 고려한 격자 정렬이 단순 가중치 최적화보다 실제 추론 성능에 더 큰 영향을 준다는 점을 실증
  3. 재정렬 전략이 다른 양자화 기법과도 plug-and-play로 결합 가능해, 온디바이스 압축 파이프라인의 범용 컴포넌트로 확장될 여지가 큼
* 왜 볼만한가: 2비트급 ternary 양자화는 4비트·8비트 대비 메모리 사용량을 훨씬 줄여 스마트폰·IoT 등 극단적 자원 제약 환경에서 LLM을 구동할 가능성을 넓히는 핵심 기술 축으로, 온디바이스 LLM 경량화 로드맵을 가늠하는 데 유용함
* 링크: https://iclr.cc/virtual/2026/poster/10011302

2. AI Agent 활용 아이템

* 이름: OpenAI Codex CLI — Subagents (정식 출시)
* 공개/출시시점: 2026년 3월 14일 Subagents 기능 정식 출시(GA), 이후에도 지속 업데이트 중(2026년 8월 릴리스에도 관련 버그 수정 반영)
* 핵심 기능: 터미널에서 동작하는 OpenAI의 오픈소스 코딩 에이전트 Codex CLI에 매니저 에이전트가 작업을 쪼개 최대 6개의 서브에이전트(Explorer로 코드베이스 탐색, Worker로 실제 코드 수정, 기본형은 단순 작업 처리)에 병렬로 위임하는 멀티에이전트 아키텍처가 추가됨. 각 서브에이전트는 독립된 샌드박스에서 실행됨
* 활용 아이디어:
  1. 모노레포 전반의 린트 오류 수정처럼 범위가 넓은 작업을 매니저-서브에이전트 구조로 나눠 병렬 처리해 메인 컨텍스트 창을 깨끗하게 유지
  2. ~/.codex/agents/ 아래 TOML로 커스텀 에이전트를 정의해, 탐색 전담·수정 전담 등 역할별 에이전트 조합을 자신의 워크플로에 맞게 구성
  3. CI/PR 리뷰 연동과 결합해 서브에이전트가 만든 변경사항을 자동으로 병합·리뷰하는 반자동 개발 파이프라인 구축
* 왜 볼만한가: 공식 GitHub 저장소 기준 스타 11만 7천 개, 포크 1만 7천 개 이상으로 코딩 에이전트 중 최상위권 채택률을 보이고 거의 매일 커밋·릴리스가 이어질 만큼 활발히 유지보수됨. 다만 2026년 2월 브랜치명에 숨긴 유니코드로 GitHub 토큰을 탈취하는 커맨드 인젝션 취약점이 발견·패치된 바 있고 비공식 서드파티 패키지가 Codex OAuth 토큰을 탈취한 사례도 있어, 공식 채널만 신뢰하고 권한 범위를 제한해 사용하는 주의가 필요
* 링크: https://github.com/openai/codex
