[AI Morning Brief - 2026-09-03]

1. On-device AI 논문

* 제목: MobileLLM-R1: Exploring the Limits of Sub-Billion Language Model Reasoners with Open Training Recipes
* 학회/게재시점: ICLR 2026 (arXiv 공개 2025-09-29)
* 다루는 문제: "강한 추론 능력은 초대형 모델과 10T 토큰 이상의 방대한 학습 데이터가 있어야만 나타난다"는 통념을 검증하며, 10억 파라미터 미만의 온디바이스급 모델에서도 진짜 추론 능력을 만들 수 있는지를 다룸
* 핵심 Contribution: 공개 데이터셋을 품질 지표로 선별·리샘플링해 약 2T 토큰만으로도 강한 추론 능력이 나타남을 보이고, 이를 4.2T 토큰까지 확장 학습한 MobileLLM-R1(140M~950M) 모델 계열과 전체 학습 레시피·데이터 소스·믹싱 비율을 공개
* 인사이트:
  1. MobileLLM-R1-950M은 Qwen3-0.6B(36T 토큰 학습)의 11.7% 토큰만으로 AIME 15.5점을 기록해 OLMo-2-1.48B(0.6점), SmolLM2-1.7B(0.3점)를 크게 앞섬
  2. "더 큰 모델·더 많은 데이터"가 아니라 "더 잘 고른 데이터"가 온디바이스 추론 모델 성능의 핵심 레버임을 실증
  3. 모델·코드·데이터 구성비를 전부 공개해, 스마트폰·엣지용 자체 추론 모델을 만들려는 팀이 바로 재현 가능
* 왜 볼만한가: Meta의 온디바이스 LLM 계보(MobileLLM, ICML 2024)를 잇는 후속작으로, "작은 모델은 추론이 약하다"는 가정을 정면으로 반박한 오픈 레시피라 실전 활용도가 높음
* 링크: https://proceedings.iclr.cc/paper_files/paper/2026/hash/c62fb98c25c2318bf3aca24d3b0fc85e-Abstract-Conference.html

2. AI Agent 활용 아이템

* 이름: Google Agent Skills (google/skills)
* 공개/출시시점: 2026-04-22 (Google Cloud Next 2026 공식 발표)
* 핵심 기능: Google Cloud·Workspace·Gemini API 등 100개 이상 제품을 다루는 마크다운 기반 공식 "Skill" 모음. 필요할 때만 문서를 로드해 MCP 서버 과다 사용으로 인한 컨텍스트 낭비와 토큰 비용을 줄이는 오픈 포맷
* 활용 아이디어:
  1. `npx skills install github.com/google/skills` 한 줄로 Gemini CLI·Antigravity·Claude Code 등 주요 에이전트에 GCP·Workspace 지식을 즉시 장착
  2. Apache 2.0 라이선스라 사내 GCP 운영 가이드나 팀 표준 문서를 스킬 형태로 포크해 커스터마이징 가능
  3. 보안·안정성·비용 최적화 등 아키텍처 원칙 스킬을 그대로 설계 리뷰 체크리스트로 활용
* 왜 볼만한가: 공개 후 GitHub 스타 1.9만 개를 넘기며 GitHub 트렌딩 4위에 오르는 등 채택 속도가 빠르고, Google이 매주 스킬을 추가하겠다고 공식화해 지속 확장 중 — 벤더 종속 없이 여러 에이전트 CLI에서 바로 쓸 수 있어, 앞서 소개한 DeepSeek Harness(8/28)보다 실무 적용 범위가 넓어 이번 회차에 선정
* 링크: https://github.com/google/skills
