[AI Morning Brief - 2026-09-07]

1. On-device AI 논문

* 제목: GSRQ: Gain-Shape Residual Quantization for Sub-1-bit KV Cache
* 학회/게재시점: ICML 2026 (2026-07-09 포스터)
* 다루는 문제: 긴 컨텍스트 LLM 추론에서 KV 캐시 메모리가 선형으로 증가해 메모리 제약 환경(온디바이스·엣지)의 컨텍스트 길이를 제한하는 문제.
* 핵심 Contribution: 벡터를 크기(gain)와 방향(shape)으로 분리해 클러스터링하는 Gain-Shape K-means(GSKM)를 제안하고, 이를 잔차 양자화(Residual Quantization)에 결합한 GSRQ 파이프라인으로 KV 캐시를 1비트 미만까지 압축하면서 기존 VQ/RQ 기법보다 재구성 품질과 다운스트림 정확도를 모두 개선.
* 인사이트:
  1. 일반 K-means는 벡터 방향 정보를 잃기 쉬운데, GSKM은 방향 보존을 목표로 설계돼 어텐션 동작에 민감한 KV 벡터 압축에 특히 유리하다.
  2. LLaMA-2-7B, LLaMA-3-8B, Mistral-7B 전반에서 저비트 구간일수록 perplexity 개선폭이 커져, 압축률을 극한까지 밀어붙일수록 이득이 커지는 구조다.
  3. 기존 K-means의 drop-in 대체 형태라 재학습 없이 기존 서빙 스택에 끼워 넣기 쉬워, 온디바이스 추론 엔진에 실질적으로 도입하는 문턱이 낮다.
* 왜 볼만한가: KV 캐시 메모리는 긴 컨텍스트를 모바일·엣지 기기에서 돌릴 때 가장 먼저 막히는 병목인데, 정확도 손실 없이 1비트 미만 압축을 달성했다는 점에서 온디바이스 롱컨텍스트 추론의 실용성을 한 단계 끌어올린다.
* 링크: https://openreview.net/forum?id=HoRGEhSUdN

2. AI Agent 활용 아이템

* 이름: Langflow (langflow-ai/langflow)
* 공개/출시시점: v1.12.0 (2026-09-01, 최신), 직전 v1.11.0(2026-07-23)에서 Human-in-the-Loop·A2A·AG-UI 지원 추가
* 핵심 기능: 드래그 앤 드롭 캔버스로 LLM 에이전트·RAG 파이프라인을 구성해 API 또는 MCP 서버로 바로 배포하는 오픈소스 비주얼 빌더. v1.11부터 툴 호출 시점에 사람 승인을 끼워넣는 Human-in-the-Loop 체크포인트, 에이전트끼리 서로를 발견하는 Agent2Agent(A2A) 프로토콜, AG-UI 스트리밍 포맷을 지원.
* 활용 아이디어:
  1. 코드 없이 도구 호출 에이전트 초안을 만들고, 민감한 액션 앞에 HITL 체크포인트를 넣어 사람이 승인·수정 후 진행하게 한다.
  2. 완성된 Langflow 플로우를 MCP 서버로 컴파일해 Claude Code 등 다른 에이전트 런타임에서 툴로 재사용한다.
  3. A2A 프로토콜로 여러 Langflow 플로우를 서로 발견 가능한 에이전트로 묶어 멀티 에이전트 파이프라인을 구성한다.
* 왜 볼만한가: GitHub 스타 15만 개 이상으로 온보딩 자료가 검증된 오픈소스 시각화 빌더 중 최상위권이며, 8월~9월 초까지 이어진 잦은 마이너 릴리스로 MCP·A2A·AG-UI 같은 최신 에이전트 상호운용 표준을 가장 빠르게 흡수하고 있다. 실무자 리뷰에서도 RAG 프로토타이핑 시간을 시간 단위에서 분 단위로 줄여준다는 평가가 반복적으로 나와, 코드 없이 에이전트를 빠르게 검증하려는 팀에게 지금 볼 가치가 있다. 유사 사례(LangGraph, Goose 등 코드 중심 프레임워크)와 달리 비주얼 빌더 축에서 가장 활발하고 채택 규모가 큰 프로젝트라는 점에서 이번에 선정했다.
* 링크: https://github.com/langflow-ai/langflow
