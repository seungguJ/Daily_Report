[AI Morning Brief - 2026-07-11]

1. On-device AI 논문

* 제목: Demystifying Small Language Models for Edge Deployment
* 학회/게재시점: ACL 2025 (Main Conference, Long Paper) — 2025년 7월, 오스트리아 빈
* 다루는 문제: 스마트폰·IoT 같은 자원 제약 디바이스에 sLM(Small Language Model)을 배포할 때, 실제로 어떤 모델이 얼마나 쓸만한지에 대한 체계적 데이터가 부족한 문제
* 핵심 Contribution: Phi, Gemma 등 공개 sLM 60여 개를 대규모로 실증 분석해, 최신 sLM이 과거 7B급 모델을 일반 태스크에서 능가하는 지점과 함께 in-context learning 한계, vocabulary/KV-cache 압축 필요성, 모델-하드웨어 co-design 등 구체적 병목을 정리
* 인사이트:
  1. sLM 성능이 빠르게 향상되어 이제 구형 7B 모델을 일반 태스크에서 앞서는 경우가 많음
  2. 병목은 단일 요인이 아니라 in-context learning, vocabulary 크기, KV 캐시가 복합적으로 작용
  3. 소프트웨어 최적화만으로는 한계가 있어 모델-하드웨어 공동 설계가 필요
* 왜 볼만한가: 특정 기법 하나가 아니라 60여 개 모델을 가로지르는 실증 데이터로 온디바이스 sLM의 현재 위치와 다음 과제를 한눈에 보여주는 로드맵 성격의 논문
* 링크: https://aclanthology.org/2025.acl-long.718/

2. AI Agent 활용 아이템

* 이름: Claude Code Plugins
* 공개/출시시점: 2025년 10월 9일 (Anthropic 공식 발표)
* 핵심 기능: 슬래시 커맨드, 서브에이전트, MCP 서버, 훅(hook)을 하나의 패키지로 묶어 `/plugin` 명령 한 번으로 설치·공유할 수 있는 Claude Code 확장 기능
* 활용 아이디어:
  1. 팀의 코드 리뷰 훅, 배포용 서브에이전트, 사내 MCP 서버를 플러그인 하나로 묶어 전원에게 동일 환경 배포
  2. 오픈소스 프로젝트가 "컨트리뷰터 온보딩 플러그인"을 배포해 셋업 과정을 자동화
  3. 마켓플레이스는 marketplace.json이 있는 git 저장소일 뿐이라, 팀 전용 프라이빗 마켓플레이스도 손쉽게 구축 가능
* 왜 볼만한가: Agent Skills, MCP Apps 등 개별 확장 기능들을 하나로 묶어 배포하는 상위 유통 계층으로, 출시 몇 달 만에 수천 개 플러그인이 등록될 만큼 빠르게 커지는 생태계라 지금 살펴볼 가치가 있음
* 링크: https://claude.com/blog/claude-code-plugins
