[AI Morning Brief - 2026-08-01]

1. On-device AI 논문

* 제목: ReplaceMe: Network Simplification via Depth Pruning and Transformer Block Linearization
* 학회/게재시점: NeurIPS 2025 (2025년 11월 30일~12월 7일, San Diego, Main Conference Poster)
* 다루는 문제: LLM을 온디바이스·엣지 환경에 배포하려면 크기를 줄여야 하는데, 기존 깊이 프루닝(depth pruning) 기법은 성능 회복을 위해 추가 파인튜닝(healing)이 필요해 비용이 크다는 문제
* 핵심 Contribution: 연속된 트랜스포머 블록 여러 개를 소규모 캘리브레이션 데이터로 추정한 단일 선형 변환으로 대체하는 학습-프리(training-free) 프루닝 기법 ReplaceMe를 제안. 파인튜닝 없이 최대 약 25% 블록을 제거하면서도 원래 성능의 약 90%를 유지
* 인사이트:
  1. 파인튜닝·헬링 과정이 전혀 없어 프루닝 후 재학습 비용이 사실상 0에 가까움 → 리소스가 제한된 팀도 즉시 적용 가능
  2. 블록을 통째로 제거하는 구조적 프루닝이라 실제 추론 시 레이턴시·메모리 절감이 곧바로 하드웨어 이득으로 이어짐(비구조적 프루닝과 달리 특수 커널 불필요)
  3. 25% 압축에도 성능 90% 유지라는 수치는 온디바이스 배포 시 "얼마나 잘라도 쓸만한가"에 대한 실측 기준점을 제공
* 왜 볼만한가: 재학습 없이 모델을 가볍게 만드는 방법은 온디바이스 LLM을 자주 업데이트해야 하는 실무 환경에서 특히 매력적이며, 압축-성능 트레이드오프를 구체적 수치로 제시해 바로 참고할 수 있음
* 링크: https://proceedings.neurips.cc/paper_files/paper/2025/hash/1c10d0c087c14689628124bbc8fa69f6-Abstract-Conference.html

2. AI Agent 활용 아이템

* 이름: Mastra 1.0
* 공개/출시시점: 2026년 1월 20일 정식 1.0 출시 (2025년 11월 베타 이후 정식화)
* 핵심 기능: TypeScript 기반 오픈소스 AI 에이전트 프레임워크. 40개 이상의 모델 제공자를 하나의 API로 라우팅하고, 에이전트·그래프 기반 워크플로우·RAG·MCP 서버 연동·휴먼인더루프·평가(eval)·관측성(observability)까지 프로덕션에 필요한 요소를 한 프레임워크 안에서 제공
* 활용 아이디어:
  1. Express, Hono, Fastify, Koa 등 기존 Node.js 서버에 어댑터 패키지로 손쉽게 얹어 사내 백엔드에 에이전트 기능을 빠르게 추가
  2. 그래프 기반 워크플로우로 여러 에이전트·툴 호출 단계를 시각적으로 설계해 고객 지원, 문서 생성, 웹 스크래핑 등 업무 자동화 구축
  3. 내장 eval·observability 기능으로 에이전트가 툴을 왜 호출했는지, 왜 실패했는지 디버깅하며 안정적으로 프로덕션에 배포
* 왜 볼만한가: Y Combinator 출신 팀(Gatsby 개발진)이 만든 프로젝트로 깃허브 스타 26.8k, 1.0 정식 출시 이전 베타 단계부터 Replit·PayPal·Sanity·Marsh McLennan 등이 프로덕션에 도입했고 Replit의 Agent 3도 Mastra 기반으로 동작할 만큼 실사용 검증이 탄탄함. 같은 기간 화제였던 OpenClaw는 스타 수는 훨씬 크지만(약 38만) 스킬 마켓플레이스 악성코드·프롬프트 인젝션·정부 보안 경고 등 반복적 보안 이슈로 지난 주에도 실무 도입 주의 대상으로 제외했던 만큼 이번에도 배제하고, 프로덕션 검증과 안정성이 뒷받침되는 Mastra를 선정
* 링크: https://github.com/mastra-ai/mastra
