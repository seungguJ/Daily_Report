1. On-device AI 논문

* 제목: CoreGuard: Safeguarding Foundational Capabilities of LLMs Against Model Stealing in Edge Deployment
* 학회/게재시점: NeurIPS 2025 Main Track Poster (2025년 12월 학회)
* 다루는 문제: 프라이버시와 효율 때문에 상용 LLM을 엣지 기기에 올리는 일이 늘고 있습니다. 하지만 기기에 모델이 있으면 가중치·구조 추출이나 파인튜닝을 통한 악용 위험이 생깁니다. 기존 방어는 연산·통신 비용이 커서 엣지에서 쓰기 어렵습니다.
* 핵심 Contribution: 연산과 통신 오버헤드를 줄인 보호 프로토콜을 만들고, propagation protocol로 통신량을 최소화하는 CoreGuard를 제안했습니다.
* 인사이트:
  1. 초록 기준으로 "상한 수준의 보안 보호"를 거의 무시할 만한 오버헤드로 달성한다고 보고합니다.
  2. 단순 추출 방지에 그치지 않고, 추출 이후 파인튜닝 같은 고급 공격까지 위협 모델에 넣었습니다.
  3. 효율을 핵심 제약으로 삼아 실제 엣지 배포 가능성을 기준으로 설계했습니다.
* 왜 볼만한가: 온디바이스 AI는 속도와 메모리 이야기가 많지만, 모델 도난 방지는 상용 배포의 현실적인 걸림돌입니다. 로컬 추론을 제품에 넣을 때 보안 쪽 설계 기준을 잡는 데 참고가 됩니다. 수치는 초록에 나온 정성적 표현만 확인했고 세부 실험 수치는 확인하지 못했습니다.
* 링크: https://neurips.cc/virtual/2025/loc/san-diego/poster/119656

2. AI Agent 활용 아이템

* 이름: CrewAI
* 공개/출시시점: 1.0.0 (2025-10-20), 최신 v1.15.23 (2026-09-28, 태그 커밋 기준)
* 핵심 기능: 역할을 가진 여러 에이전트(Crew)를 팀으로 묶어 협업시키는 Python 멀티에이전트 오케스트레이션 프레임워크입니다. MIT 라이선스이며 최근에는 Gemini 모델 지원, 대화형 Flow 정식화 등이 이어지고 있습니다.
* 활용 아이디어:
  1. 리서치 담당, 작성 담당, 검수 담당 에이전트를 나눠 주간 시장 조사 리포트 자동화 파이프라인을 만듭니다.
  2. Flow로 단계별 흐름을 고정하고 단계 안에서만 Crew를 쓰는 방식으로 예측 가능한 업무 자동화를 만듭니다.
  3. 에이전트 역할 분담과 출력 형식을 먼저 CrewAI로 프로토타이핑한 뒤 필요하면 다른 프레임워크로 옮깁니다.
* 왜 볼만한가: GitHub 스타 약 59.4k, 포크 약 8.7k로 에이전트 프레임워크 중 채택 규모가 큽니다. 2026-10-06에도 커밋이 올라올 만큼 유지보수가 활발하고, 1.15.x 릴리스가 몇 주 간격으로 이어집니다. 커뮤니티 평가는 프로토타입을 가장 빨리 만들 수 있다는 의견이 많은 반면, 디버깅이 불투명하고 대규모에서 토큰 비용이 커지며 2026년 보안 이슈 공개가 있었다는 지적도 있습니다. Agno(스타 약 42.6k), agent-native(약 7.1k)보다 채택 규모가 커서 골랐고, 이미 소개한 LangGraph, Microsoft Agent Framework와는 다른 프로젝트입니다.
* 링크: https://github.com/crewAIInc/crewAI
