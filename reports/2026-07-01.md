[AI Morning Brief - 2026-07-01]

1. On-device AI 논문

* 제목: Accurate KV Cache Quantization with Outlier Tokens Tracing
* 학회/게재시점: ACL 2025 (2025년 7월 28일, Vienna)
* 다루는 문제: LLM 추론 시 KV 캐시가 메모리 병목이 되는데, 기존 채널/토큰 단위 양자화는 소수의 이상치(outlier) 토큰 특성을 반영하지 못해 초저비트에서 정확도가 크게 떨어짐
* 핵심 Contribution: 디코딩 과정에서 이상치 토큰을 실시간으로 추적해 양자화 대상에서 제외하는 기법을 제안, 2비트 양자화에서도 정확도 손실을 최소화
* 인사이트:
  1. 2비트 초저비트 양자화에서도 정확도를 유지하며 메모리 사용량 6.4배 절감
  2. 처리량(throughput) 2.3배 향상으로 온디바이스 실시간 추론에 직접적 이득
  3. 이상치 토큰만 선별 추적해 연산 오버헤드가 적어 실제 배포에 적합한 실용적 설계
* 왜 볼만한가: 긴 컨텍스트를 다루는 온디바이스 LLM에서 메모리가 가장 큰 제약인데, 정확도 손실 없이 메모리·속도를 동시에 개선하는 실용적 방법을 제시함
* 링크: https://aclanthology.org/2025.acl-long.631/

2. AI Agent 활용 아이템

* 이름: Claude Code Dynamic Workflows
* 공개/출시시점: 2026년 5월 28일 (Anthropic 공식 블로그, 정식 출시)
* 핵심 기능: 하나의 세션에서 수십~수백 개의 서브에이전트를 병렬로 오케스트레이션하는 JavaScript 기반 워크플로우 스크립트. 결과를 자동 검증하고, 중단돼도 이어서 재개 가능
* 활용 아이디어:
  1. 대규모 코드베이스 전수 조사·리팩터링처럼 단일 세션으로 처리 불가능한 작업을 자동 분할해 병렬 처리
  2. 정확성·보안·성능 등 여러 관점에서 독립적으로 교차 검증하는 리뷰 파이프라인 구성
  3. Claude Code CLI·Desktop·VS Code·API 어디서든 동일 워크플로우 재사용 가능
* 왜 볼만한가: 단일 서브에이전트 호출과 풀 멀티에이전트 팀 구축 사이의 공백을 메워, 몇 달 걸리던 대규모 작업을 며칠로 단축한 실사례(Bun을 Zig에서 Rust로 75만 줄 포팅, 11일 소요)가 이미 존재
* 링크: https://claude.com/blog/introducing-dynamic-workflows-in-claude-code
