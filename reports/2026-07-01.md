1. On-device AI 논문

* 제목: MiniKV: Pushing the Limits of 2-Bit KV Cache via Compression and System Co-Design for Efficient Long Context Inference
* 학회/게재시점: ACL 2025 (Findings), 2025년 7월
* 다루는 문제: 긴 컨텍스트 추론 시 KV 캐시가 메모리를 과도하게 차지해, 메모리가 제한된 온디바이스·엣지 환경에서 롱컨텍스트 LLM을 서빙하기 어려운 문제
* 핵심 Contribution: 레이어별 적응형 KV 선택 정책과 2비트 양자화를 결합하고, FlashAttention과 호환되는 하드웨어 최적화 커널을 함께 설계해 알고리즘 성능과 실제 시스템 속도 향상 간의 격차를 해소
* 인사이트:
  1. KV 캐시를 80% 이상 압축하면서도 정확도 손실은 거의 없음
  2. 모든 레이어를 균일하게 압축하는 대신, 레이어마다 다른 KV 보존 정책을 쓰는 "적응형" 접근이 더 효율적
  3. 압축 알고리즘만으로는 부족하고, 커널 레벨 co-design이 있어야 실제 지연시간·처리량 개선으로 이어짐
* 왜 볼만한가: 메모리가 제한된 모바일·엣지 기기에서 긴 컨텍스트를 다루는 LLM을 실제로 구동 가능하게 만드는 실전형 압축 기법이기 때문
* 링크: https://aclanthology.org/2025.findings-acl.952/

2. AI Agent 활용 아이템

* 이름: Microsoft Agent Framework 1.0 (정식 출시/GA)
* 공개/출시시점: 2026년 4월 3일
* 핵심 기능: Semantic Kernel과 AutoGen을 하나로 통합한 프로덕션급 오픈소스 에이전트 SDK(.NET/Python)로, MCP 기반 외부 툴 자동 탐색, 재사용 가능한 스킬 패키지(지침+스크립트+리소스), 순차/동시/handoff/그룹챗 등 멀티에이전트 오케스트레이션 패턴을 제공
* 활용 아이디어:
  1. YAML 선언형 설정으로 에이전트 정의를 버전관리하며 팀 단위로 재사용
  2. MCP 서버만 연결하면 별도 코드 없이 외부 툴을 동적으로 탐색·호출
  3. Claude를 포함한 다양한 모델 프로바이더를 그대로 붙여 프로토타입을 프로덕션 워크플로로 전환
* 왜 볼만한가: AutoGen·Semantic Kernel이 합쳐진 첫 정식(GA) 버전이라 API가 안정화되어 실제 서비스에 바로 적용할 수 있기 때문
* 링크: https://devblogs.microsoft.com/agent-framework/microsoft-agent-framework-version-1-0/
