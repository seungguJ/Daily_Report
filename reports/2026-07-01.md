[AI Morning Brief - 2026-07-01]

1. On-device AI 논문

* 제목: Prima.cpp: Fast 30-70B LLM Inference on Heterogeneous and Low-Resource Home Clusters
* 학회/게재시점: ICLR 2026 (2026년 4월 포스터 발표)
* 다루는 문제: 30B~70B급 대형 LLM은 스마트폰·노트북·PC 등 소비자 기기 한 대의 메모리와 연산력으로는 로컬 구동이 사실상 불가능했던 문제
* 핵심 Contribution: 이기종(CPU/GPU 혼재, 부족한 RAM/VRAM, 저속 디스크, Wi-Fi)의 여러 가정용 기기를 하나의 클러스터로 묶어 대형 모델을 로컬 구동하는 분산 추론 시스템 Prima.cpp 제안. 디스크 I/O와 연산·통신을 겹쳐 처리하는 Pipelined-Ring Parallelism(PRP)과, 기기별 메모리 제약 하 레이어 배치를 최적화하는 NP-hard 스케줄러 Halda 설계
* 인사이트:
  1. 70B 모델을 메모리 여유 6% 미만 환경에서도 토큰당 674ms로 로컬 구동해 클라우드 없이 거대 모델 실행 가능성 입증
  2. 스펙큘레이티브 디코딩과 결합 시 32B 모델에서 초당 26토큰 달성, 가정용 에이전트 응용에 실용적인 속도 확보
  3. 온디바이스 AI의 병목이 '모델을 기기 하나에 우겨넣기'가 아니라 '여러 기기를 지능적으로 함께 쓰기'로 전환될 수 있음을 시사
* 왜 볼만한가: 온디바이스 AI의 범위를 '단일 기기'에서 '개인 소유 기기들의 연합'으로 확장하며, 클라우드 의존 없이 대형 모델을 프라이빗하게 쓸 수 있는 실질적 경로 제시
* 링크: https://iclr.cc/virtual/2026/poster/10008093

2. AI Agent 활용 아이템

* 이름: Claude Code Routines
* 공개/출시시점: 2026년 4월 (Claude Code v2.1.105+, 리서치 프리뷰)
* 핵심 기능: 프롬프트·저장소·커넥터를 하나의 "루틴"으로 저장해 스케줄, GitHub 이벤트, API 웹훅 트리거로 Anthropic 클라우드에서 완전 자동 실행되는 Claude Code 세션. 로컬 PC가 꺼져 있어도 동작
* 활용 아이디어:
  1. 매일 밤 이슈 트래커를 스캔해 라벨링·담당자 지정 후 Slack에 요약을 보내 백로그 자동 정리
  2. 모니터링 툴 알림을 API 트리거로 받아 스택트레이스를 분석하고 수정 PR 초안을 자동 생성
  3. PR opened 이벤트에 반응해 팀 체크리스트 기반 자동 리뷰 코멘트 작성
* 왜 볼만한가: 코드 작성 없이 UI·CLI만으로 '한 번 설정하면 계속 도는' 에이전트 자동화를 구성할 수 있어, 반복적인 운영·리뷰·모니터링 업무를 사람 개입 없이 위임 가능
* 링크: https://code.claude.com/docs/en/routines
