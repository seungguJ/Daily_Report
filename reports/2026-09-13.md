[AI Morning Brief - 2026-09-13]

1. On-device AI 논문

* 제목: DP-LLM: Runtime Model Adaptation with Dynamic Layer-wise Precision Assignment
* 학회/게재시점: NeurIPS 2025 (accept 통보 2025-09-18)
* 다루는 문제: 온디바이스에 LLM을 배포할 때 지연시간·정확도 요구가 상황마다 달라지는데, 기존에는 이를 맞추려면 양자화 비트폭이 다른 모델을 여러 개 따로 배포해야 했다.
* 핵심 Contribution: 하나의 배포 모델만으로, 디코딩 스텝마다 입력에 따라 레이어별 비트 정밀도를 동적으로 재배정하는 DP-LLM을 제안. 가벼운 민감도 추정기로 각 레이어의 정밀도를 실시간 조절해 다중 정밀도 모델을 겹쳐 쌓은 효과를 낸다.
* 인사이트:
  1. 정적 양자화 대신 "런타임에 정밀도를 바꾸는" 접근이라 디바이스 자원 상황(배터리, 발열, 배치 크기)에 맞춰 즉시 트레이드오프를 조정할 수 있다.
  2. 모델 여러 벌을 따로 만들고 배포할 필요가 없어 온디바이스 앱의 스토리지·배포 복잡도를 줄인다.
  3. 레이어 단위의 세밀한 정밀도 제어는 향후 스펙큘레이티브 디코딩·KV 캐시 압축 기법과도 결합 여지가 크다.
* 왜 볼만한가: "모델을 어떻게 더 작게 만들까"가 아니라 "이미 배포된 모델을 어떻게 상황별로 유연하게 굴릴까"라는, 온디바이스 서빙의 실전 운영 문제를 다뤄 최근 압축 위주 연구들과 결이 다르다.
* 링크: https://neurips.cc/virtual/2025/poster/115920

2. AI Agent 활용 아이템

* 이름: Juggler (juggler-ai/juggler)
* 공개/출시시점: Show HN 공개 2026-07-12 (저장소 생성 2026-06-19), 최신 릴리스 v0.6.3 (2026-09-12)
* 핵심 기능: 채팅 로그를 한 줄로 쌓는 기존 코딩 에이전트 UI 대신, 대화를 브랜치·편집 가능한 트리 구조(Miller-column 탐색, CRDT 기반)로 다루는 GUI 코딩 에이전트. Go+Wails로 만든 로컬 서버라 Electron 없이 가볍고, 툴 호출을 직접 열람·수정할 수 있으며 Claude Code·OpenAI·Gemini·Ollama·OpenRouter 등 여러 백엔드를 지원.
* 활용 아이디어:
  1. 여러 접근을 동시에 실험할 때 대화를 브랜치로 나눠 비교하고, 잘못된 경로만 되돌려 재시도할 수 있다.
  2. 에이전트가 실행한 툴 호출과 근거를 눈으로 검사·수정할 수 있어, 신뢰도가 중요한 작업(리뷰, 감사)에 적합하다.
  3. JS 플러그인으로 컨텍스트 아이템·LLM 전략·슬래시 커맨드를 직접 확장 가능해 팀 워크플로에 맞춘 커스터마이징이 쉽다.
* 왜 볼만한가: Show HN에서 280점·100건 이상의 댓글로 활발한 반응을 얻었고(제작자가 JUCE/Tracktion 창시자라는 신뢰도도 한몫), 출시 이후 3~5일 간격으로 근 2개월째 꾸준히 릴리스가 이어지는 등 실제로 유지보수되는 프로젝트라는 점이 다른 후보(공개 배경에 데이터 유출 논란이 있던 xai-org/grok-build 등)보다 신뢰할 만하다.
* 링크: https://github.com/juggler-ai/juggler
