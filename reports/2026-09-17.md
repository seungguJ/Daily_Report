[AI Morning Brief - 2026-09-17]

1. On-device AI 논문

* 제목: AegisGuard: RL-Guided Adapter Tuning for TEE-Based Efficient & Secure On-Device Inference
* 학회/게재시점: NeurIPS 2025 (Poster) · 2025-09-18 accept 통보
* 다루는 문제: 온디바이스 LLM 배포에서 LoRA 어댑터의 일부를 TEE(신뢰 실행 환경)에, 나머지를 일반 GPU에 나눠 올리는 하이브리드 방식은 효율적이지만, GPU에 노출된 부분을 반복 질의해 모델을 통째로 복제하는 모델 탈취(model stealing) 공격에 취약함
* 핵심 Contribution: RL 기반 민감도 측정(RSM)으로 각 어댑터가 유출됐을 때의 탈취 위험을 자동 랭킹하고, 위험도가 높은 어댑터만 구조적으로 압축(SAC)해 좁은 TEE 안에서 돌리는 2단계 프레임워크 AegisGuard를 제안. 전체를 TEE에 넣는 기존 방식 대비 지연시간 2~3배, TEE 메모리 사용량 4배를 줄이면서도 블랙박스 수준의 탈취 방어력(대체 모델 정확도 약 39%)을 유지
* 인사이트:
  1. "전부 보호"가 아니라 "위험한 부분만 선택적으로 보호"하는 전략으로 온디바이스 보안-효율 트레이드오프를 정면 돌파
  2. 어댑터 민감도 측정을 수작업이 아닌 RL로 자동화해 배포 정책 결정 비용을 줄임
  3. 모바일·엣지 기기의 제한된 TEE 자원 안에서도 실전 지연시간을 확보하는 구조적 압축을 결합
* 왜 볼만한가: 온디바이스 LLM이 실제 폰·엣지 기기에 나갈 때 모델 IP·프라이버시 보호와 추론 성능을 동시에 만족시키는 구체적 엔지니어링 해법이라 실무 적용 가치가 큼
* 링크: https://neurips.cc/virtual/2025/poster/116589

2. AI Agent 활용 아이템

* 이름: Vercel Skills (`npx skills`)
* 공개/출시시점: 2026-01-20 최초 공개 · v1.1.1 오픈소스 전환·인터랙티브 검색 추가 (2026-01-26)
* 핵심 기능: `npx skills add <package>` 한 줄로 Claude Code, Cursor, GitHub Copilot, Codex, Gemini CLI, Windsurf, Goose, OpenCode 등 27개 이상의 코딩 에이전트에 재사용 가능한 "스킬"(에이전트 지침 패키지)을 설치·검색·업데이트해주는 CLI이자, 60만 개 이상의 스킬을 색인한 레지스트리 skills.sh
* 활용 아이디어:
  1. 팀의 코딩 컨벤션·프레임워크 베스트프랙티스를 버전관리되는 패키지로 만들어 여러 에이전트 툴에서 공통 재사용
  2. `npx skills find`로 필요한 순간에 스킬을 인터랙티브하게 탐색·설치
  3. 신규 입사자나 새 에이전트 세션 온보딩을 스킬 설치 한 줄로 표준화
* 왜 볼만한가: 공개 6시간 만에 설치 2만 건을 넘기고 8개월여 만에 GitHub 스타 3만 개를 돌파했으며, Stripe 등 기업이 당일 자체 스킬 패키지를 출시할 만큼 빠르게 "AI 에이전트용 npm" 포지션을 굳히는 중
* 링크: https://github.com/vercel-labs/skills
