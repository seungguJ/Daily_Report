[AI Morning Brief - 2026-08-13]

1. On-device AI 논문

* 제목: MixKVQ: Query-Aware Mixed-Precision KV Cache Quantization for Long-Context Reasoning
* 학회/게재시점: ACL 2026 (2026년 7월, Main Conference, Long Paper, 화남이공대·베이항대·파저우연구소)
* 다루는 문제: 긴 사고사슬(long Chain-of-Thought) 추론을 할수록 KV 캐시가 커져 메모리·지연시간 부담이 급증하는데, 기존 저비트 양자화는 key 캐시의 이상치(outlier) 채널 때문에 복잡한 추론 과제에서 성능이 크게 떨어지는 문제
* 핵심 Contribution: 각 key 채널의 "양자화 난이도"와 "현재 쿼리와의 연관성"을 함께 보는 경량 query-aware 알고리즘으로 고정밀도가 필요한 채널만 선별 보존하고, value 캐시는 토큰 단위로 양자화하는 plug-and-play 혼합정밀도 기법을 제안. 재학습 없이 적용 가능하며 메모리 사용량을 크게 줄이면서 풀정밀도에 준하는 추론 성능 유지
* 인사이트:
  1. plug-and-play 설계라 기존 로컬/엣지 추론 파이프라인에 별도 재학습 없이 바로 얹을 수 있음
  2. 긴 reasoning chain을 다루는 온디바이스 에이전트·로컬 챗봇에서 메모리 병목을 직접 완화하는 실용적 해법
  3. "채널별 난이도 + 쿼리 연관성"이라는 이중 기준은 다른 캐시·활성값 압축 연구에도 응용 가능한 일반 설계 원리
* 왜 볼만한가: 긴 추론(reasoning) 시대에 메모리를 가장 많이 잡아먹는 KV 캐시를, 정확도 손실을 최소화하면서 압축해 온디바이스·엣지 장기추론 배포의 핵심 병목을 정면으로 다룸
* 링크: https://aclanthology.org/2026.acl-long.326/

2. AI Agent 활용 아이템

* 이름: Agent Skills (addyosmani/agent-skills)
* 공개/출시시점: 2026년 5월 3일 공식 공개(Google 엔지니어링 리드 출신 Addy Osmani), 이후 빠르게 성장해 현재 약 8만7천 GitHub 스타 확보
* 핵심 기능: Claude Code, Codex, Cursor 등 70개 이상의 코딩 에이전트가 공통으로 쓰는 SKILL.md 표준을 바탕으로, 정의-계획-구현-검증-리뷰-배포(Define~Ship) 전 단계에 걸쳐 시니어 엔지니어의 워크플로우·품질 게이트를 24개 스킬로 인코딩한 오픈소스 패키지
* 활용 아이디어:
  1. `npx skills add addyosmani/agent-skills`로 설치해 Claude Code 등 에이전트가 스펙 작성·TDD·코드 리뷰·보안 점검 절차를 자동으로 따르게 강제
  2. 배포 전 체크리스트(보안·성능·접근성·옵저버빌리티)를 팀 표준으로 삼아, 에이전트가 테스트 통과·빌드 로그 같은 검증 근거를 스스로 남기도록 설정
  3. 프로젝트 성격에 맞는 스킬만 선택 설치해 팀 컨벤션에 맞는 "시니어 엔지니어 페르소나" 에이전트 구성
* 왜 볼만한가: 공개 3개월여 만에 Claude Code용 "가장 많이 설치되는 스킬 마켓플레이스"로 자리잡을 만큼 빠르게 확산됐고(5월 2.7만 → 현재 8.7만 스타), MIT 라이선스로 설치·적용이 쉬우며 코드 diff에는 드러나지 않는 스펙·테스트·리뷰 단계까지 강제한다는 명확한 차별점이 있음. 같은 시기 후보였던 OpenClaw(38만+ 스타)는 인기는 압도적이지만 4개월 새 100건 이상의 CVE와 악성 스킬(스캔된 스킬의 약 12%) 등 심각한 보안 이슈가 다수 보고돼 이번 회차에서는 제외
* 링크: https://github.com/addyosmani/agent-skills
