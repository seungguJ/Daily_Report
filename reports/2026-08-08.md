[AI Morning Brief - 2026-08-08]

1. On-device AI 논문

* 제목: ParetoQ: Improving Scaling Laws in Extremely Low-bit LLM Quantization
* 학회/게재시점: NeurIPS 2025 (2025년 12월, San Diego, Poster)
* 다루는 문제: 1비트~4비트 초저비트 LLM 양자화 기법들이 각각 다른 조건에서 평가되어 온 탓에, "어떤 비트폭이 실제로 최선인가"를 공정하게 비교할 표준이 없었던 문제
* 핵심 Contribution: 1, 1.58, 2, 3, 4비트를 동일한 학습·양자화 파이프라인에서 비교하는 ParetoQ 프레임워크를 제시. 2비트와 3비트 사이에 뚜렷한 "학습 전이" 지점이 있음을 규명(3비트 이상은 사전학습 분포를 유지하지만 2비트 이하는 표현이 크게 재구성됨)했고, 6억 파라미터 3진(ternary) 모델이 기존 30억 파라미터 3진 SOTA보다 5분의 1 크기로 더 높은 정확도를 달성
* 인사이트:
  1. "몇 비트가 최적인가"는 모델 크기별로 임의로 정할 문제가 아니라, 2~3비트 사이의 학습 전이라는 구조적 경계에 따라 갈리는 문제임을 실험으로 입증
  2. 최적화된 2비트 CPU 커널이 4비트보다 속도·메모리 효율에서 앞서, "4비트가 무조건 안전한 선택"이라는 통념에 반례를 제시
  3. 통일된 파이프라인으로 1~4비트 전 구간을 한 번에 비교할 수 있어, 타깃 디바이스 메모리 예산에 맞춰 비트폭을 고를 때 실험 비용을 크게 줄여줌
* 왜 볼만한가: Meta가 온디바이스 배포를 염두에 두고 내놓은 초저비트 양자화 벤치마크로, "얼마나 압축할 수 있는가"뿐 아니라 "어느 비트에서 무엇이 근본적으로 달라지는가"까지 규명해 모바일 LLM 양자화 전략에 실질적 기준을 제공
* 링크: https://neurips.cc/virtual/2025/poster/118224

2. AI Agent 활용 아이템

* 이름: AGENTS.md
* 공개/출시시점: 2025년 8월 OpenAI 주도로 공개, 2025년 12월 9일 Linux Foundation 산하 Agentic AI Foundation(AAIF)에 공식 이관되어 표준 프로젝트로 자리매김
* 핵심 기능: AI 코딩 에이전트를 위한 "에이전트용 README" 역할을 하는 단순한 마크다운 표준 파일. 빌드 방법, 테스트 절차, 코드 컨벤션, PR 규칙 등 사람이 읽는 README에 넣기엔 번잡한 에이전트 전용 지침을 리포지토리 루트에 명시
* 활용 아이디어:
  1. 프로젝트 루트에 AGENTS.md 파일 하나만 추가하면 Codex, Cursor, GitHub Copilot, Jules, Gemini CLI 등 20여 개 이상의 도구가 동일한 지침을 공유해, 도구마다 별도 설정 파일을 만들 필요가 없음
  2. 테스트 실행 명령, 빌드 절차, 건드리면 안 되는 디렉터리 등을 명문화해 에이전트가 반복적으로 잘못된 명령을 시도하거나 민감한 경로를 건드리는 실수를 줄임
  3. 모노레포에서는 하위 디렉터리별로 AGENTS.md를 중첩 배치해, 서브프로젝트마다 다른 빌드·테스트 규칙을 에이전트에 전달 가능
* 왜 볼만한가: 출시 1년 만에 6만 개 이상의 오픈소스 프로젝트가 채택했고, OpenAI·Anthropic·Google 등이 함께 Linux Foundation AAIF(MCP, Goose와 함께 3대 창립 프로젝트)로 이관하며 사실상 업계 표준으로 자리잡음. 특정 벤더에 종속되지 않고 대부분의 주요 코딩 에이전트가 네이티브로 인식하는 몇 안 되는 공통 규격이라, 지금 리포지토리에 도입해두면 앞으로 어떤 에이전트를 쓰더라도 그대로 재사용 가능. 공식 저장소 기준 스타 2.35만 개·포크 1.8천 개로 활발히 유지보수되고 있음
* 링크: https://github.com/agentsmd/agents.md
