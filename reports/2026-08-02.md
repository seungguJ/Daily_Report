[AI Morning Brief - 2026-08-02]

1. On-device AI 논문

* 제목: Demystifying Small Language Models for Edge Deployment
* 학회/게재시점: ACL 2025 (Main Conference, Long Papers), 2025년 7월, Vienna
* 다루는 문제: 스마트폰 등 온디바이스 배포를 노리는 소형 언어모델(SLM)들이 실제로 얼마나 좋은지, 어디서 한계를 보이는지에 대한 체계적 이해가 부족한 문제
* 핵심 Contribution: Microsoft Phi, Google Gemma 등 공개 SLM 60여 개를 대규모로 벤치마킹해 역량·학습 방식·온디바이스 실행 효율을 정량 분석. 상위권 SLM이 범용 과제에서 7B급 모델을 능가할 수 있음을 보이는 동시에 in-context learning과 실기기 효율 측면의 한계를 밝히고, 동적 태스크 라우팅·모델-하드웨어 co-design·vocabulary/KV cache 압축 등 구체적 개선 방향을 제시
* 인사이트:
  1. 60여 개 공개 SLM을 아우르는 대규모 실측 벤치마크라 특정 모델 홍보가 아닌 온디바이스 SLM 생태계 전반의 객관적 기준점을 제공
  2. 작은 모델이 이미 7B급을 능가하는 사례가 많다는 결과는 "클수록 좋다"는 통념을 반박하며, 온디바이스 제품 설계 시 모델 크기 결정에 실질적 근거를 제공
  3. Vocabulary/KV cache 압축, 모델-하드웨어 co-design 같은 구체적 개선 방향은 다음 세대 온디바이스 SLM 연구·엔지니어링에 바로 참고 가능
* 왜 볼만한가: 온디바이스 SLM을 고를 때 "어떤 모델이 실제로 더 낫고 왜 그런가"를 실측 데이터로 보여주는 몇 안 되는 대규모 서베이형 논문이라 모델 선정과 최적화 우선순위 결정에 실무적으로 유용
* 링크: https://aclanthology.org/2025.acl-long.718/

2. AI Agent 활용 아이템

* 이름: AgentMemory (rohitg00/agentmemory)
* 공개/출시시점: 2026년 2월 공개, 이후 매주 단위 릴리즈 지속(최신 v0.9.28, 2026년 7월 19일), 2026년 5월 GitHub 트렌딩 1위
* 핵심 기능: Claude Code, Cursor, GitHub Copilot, Codex 등 20개 이상 코딩 에이전트용 영속 메모리 MCP 서버. 세션 활동을 자동 캡처·압축해 다음 세션에 다시 주입하고, BM25+벡터+지식그래프 하이브리드 검색으로 매번 프로젝트 맥락을 재설명할 필요를 없앰
* 활용 아이디어:
  1. `npm install -g @agentmemory/agentmemory` 후 `agentmemory connect <agent>` 한 줄로 기존 코딩 에이전트에 영속 기억 계층을 추가
  2. remember/recall/handoff/forget 등 액션 스킬로 여러 세션·여러 에이전트 간 설계 결정과 작업 이력을 이어받아 컨텍스트 재설명 비용을 절감
  3. 로컬 MCP 서버와 대시보드(3113 포트)를 통해 팀 내 여러 에이전트가 같은 프로젝트 메모리를 공유하는 구조로 확장 가능
* 왜 볼만한가: 공개 수개월 만에 스타 2.6만 개·포크 2,200개를 넘기며 GitHub 트렌딩 1위에 올랐고, 이후에도 매주 릴리즈가 이어질 만큼 활발히 유지보수되어 "에이전트 세션 간 기억 단절" 문제에 대한 실질적 수요를 확인할 수 있음. 같은 시기 화제였던 일부 초대형 스타 수 저장소 소문은 GitHub API로 실체를 확인할 수 없어 검증 실패로 제외했고, 공식 저장소·릴리즈 이력으로 직접 검증되는 AgentMemory를 선정
* 링크: https://github.com/rohitg00/agentmemory
