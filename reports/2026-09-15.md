[AI Morning Brief - 2026-09-15]

1. On-device AI 논문

* 제목: KVzip: Query-Agnostic KV Cache Compression with Context Reconstruction
* 학회/게재시점: NeurIPS 2025 (Oral) · 저자 통보일 2025-09-18
* 다루는 문제: 긴 문맥을 다루는 LLM 추론에서 KV 캐시가 메모리와 지연시간을 지배적으로 차지해, 자원이 제한된 온디바이스·엣지 환경에서 긴 문맥 추론을 어렵게 만드는 문제
* 핵심 Contribution: 특정 질의(query)에 의존하지 않고, LLM이 압축된 캐시만으로 원본 문맥을 얼마나 잘 복원해내는지를 기준으로 각 KV 쌍의 중요도를 매겨 축출(eviction)하는 재구성 기반 압축 기법을 제안. 한 번 압축한 캐시를 이후 여러 질의에 재사용 가능
* 인사이트:
  1. KV 캐시를 약 3~4배 줄이면서도 QA·검색·추론·코드 태스크 전반에서 성능 저하가 거의 없음을 실험적으로 입증
  2. FlashAttention 디코딩 속도를 약 2배 향상시켜, 메모리뿐 아니라 지연시간 측면에서도 온디바이스 배포에 실질적 이득
  3. 질의 비의존적 설계 덕분에 압축 캐시를 매 질문마다 새로 만들 필요 없이 재사용할 수 있어, 온디바이스 다중 턴 대화 시나리오에 특히 유리
* 왜 볼만한가: 긴 문맥 LLM을 로컬 기기에서 구동할 때 가장 큰 걸림돌인 KV 캐시 메모리 문제를 정면으로 다루면서도, NeurIPS 2025 Oral로 선정될 만큼 검증된 방법론이라 실제 적용 가능성이 높음
* 링크: https://neurips.cc/virtual/2025/poster/118741

2. AI Agent 활용 아이템

* 이름: Claude Agent SDK
* 공개/출시시점: 2025-09-29 (Claude Code SDK에서 리브랜딩되며 공식 출시)
* 핵심 기능: Claude Code를 구동하던 에이전트 하네스(파일·시맨틱 검색을 통한 컨텍스트 수집, bash·커스텀 툴·MCP를 통한 액션 실행, 린트·스크린샷·LLM 채점을 통한 결과 검증)를 코딩 외 범용 에이전트 개발에도 쓸 수 있도록 독립 라이브러리로 공개
* 활용 아이디어:
  1. 자체 툴셋을 가진 커스텀 코딩·데브옵스 에이전트를 직접 구축할 때 기반 프레임워크로 활용
  2. 리서치 요약, 재무 분석, 고객 지원처럼 코딩이 아닌 업무에도 컨텍스트 압축·세션 관리가 내장된 안정적인 에이전트 루프를 재사용
  3. MCP를 통해 Slack·GitHub 등 기존 서비스와 에이전트를 연결할 때 툴콜링 인프라를 새로 구현하지 않고 바로 연동
* 왜 볼만한가: 출시 직후 Hacker News에 별도 스레드가 여러 개 올라올 만큼 개발자 반응이 뜨거웠고, Python SDK는 8.1k 스타를 확보하며 실제 프로덕션 채택 논의까지 이어지고 있어 지금 살펴볼 가치가 큼. 같은 시기 후보였던 OpenAI AgentKit은 오픈소스 SDK가 아닌 호스티드 비주얼 빌더라 실전 코드 재사용성이 낮아 제외
* 링크: https://github.com/anthropics/claude-agent-sdk-python
