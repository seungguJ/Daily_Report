[AI Morning Brief - 2026-09-26]

1. On-device AI 논문

* 제목: Equilibrium Language Models (ELM)
* 학회/게재시점: ICLR 2026 (2026-04, OpenReview 게재)
* 다루는 문제: 온디바이스 LLM 배포는 연산량(FLOPs)보다 메모리, 특히 레이어마다 쌓이는 KV 캐시가 더 큰 제약인데, 기존 프루닝·양자화는 이 캐시 구조 자체는 그대로 둔 채 값만 압축하는 데 머물러 있었음.
* 핵심 Contribution: 트랜스포머 레이어 그룹을 경량 고정점(equilibrium) 네트워크로 대체해 "깊이"를 반복 계산의 고정점으로 재정의. Group Pruning Policy Optimization으로 프루닝 구간을 자동 탐색하고, One-Step KV-Cache로 레이어별이 아니라 마지막 반복 한 번의 캐시만 저장하도록 구조 자체를 바꿈. 파라미터 28% 절감, 정확도는 dense 모델의 99% 수준 유지.
* 인사이트:
  1. 최적화 축을 FLOPs가 아니라 KV 캐시 메모리로 옮긴 접근으로, 기존 양자화·프루닝 계열과는 다른 레버를 제시함.
  2. 프루닝 구간 탐색을 정책 학습으로 자동화해 디바이스별 수동 튜닝 부담을 줄임.
  3. 28% 파라미터 절감·99% 정확도 유지라는 구체적 임계값을 제시해 실배포 판단 기준으로 삼기 좋음.
* 왜 볼만한가: 기존 KV 캐시 압축 연구가 "이미 쌓인 캐시를 어떻게 줄이나"에 집중했다면, 이 논문은 "캐시 자체를 덜 만드는" 구조적 해법이라 온디바이스 메모리 예산 설계에 새로운 기준점을 제공함.
* 링크: https://openreview.net/forum?id=lqJT6xmuH3

2. AI Agent 활용 아이템

* 이름: mini-swe-agent v2.0
* 공개/출시시점: 2026-02-11 (v2.0.0 공식 릴리스), 이후 v2.4.x까지 꾸준히 업데이트 중
* 핵심 기능: Princeton·Stanford SWE-bench/SWE-agent 팀이 만든 100줄 안팎의 초경량 코딩 에이전트. 별도 툴 스키마 없이 bash 명령만으로 GitHub 이슈를 해결하며 SWE-bench Verified에서 74% 이상을 기록. v2.0부터 정규식 기반 액션 파싱을 버리고 LLM 네이티브 툴콜링을 기본값으로 전환했고, 설정 체계도 Pydantic 모델로 옮겨 Model/Environment/Agent를 서브클래싱 없이 덕타이핑으로 갈아끼울 수 있게 됨.
* 활용 아이디어:
  1. 무거운 에이전트 프레임워크 없이 로컬·Docker 환경에서 바로 이슈 해결 자동화 파이프라인을 구성.
  2. LiteLLM 호환 모델이면 어떤 LLM이든 붙일 수 있어 사내 모델 비교·실험용 경량 베이스라인으로 활용.
  3. 코드가 짧아 에이전트 동작을 그대로 읽고 커스터마이징하기 쉬워 연구·교육용 레퍼런스로도 적합.
* 왜 볼만한가: GitHub 스타 8k대의 SWE-agent 후속 경량 프로젝트로, v2.0의 네이티브 툴콜링 전환이 실제 프로덕션 파이프라인에 붙이기 쉬워진 결정적 변화임. "100줄로 SWE-bench 65%"라는 단순함 자체로 Hacker News에서 화제였고, 이후 버전에서 성능도 74%대까지 끌어올려 커뮤니티 신뢰를 이어가고 있음.
* 링크: https://github.com/SWE-agent/mini-swe-agent
