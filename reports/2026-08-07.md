[AI Morning Brief - 2026-08-07]

1. On-device AI 논문

* 제목: SpecEdge: Scalable Edge-Assisted Serving Framework for Interactive LLMs
* 학회/게재시점: NeurIPS 2025 (Spotlight Poster, 2025년 12월)
* 다루는 문제: 대화형 LLM 서비스를 서버 GPU만으로 돌리면 비용과 지연시간 부담이 크다는 문제를, 사용자 로컬(엣지) GPU와 서버 GPU를 함께 활용해 해결
* 핵심 Contribution: 엣지 기기(소비자용 GPU)가 초안 토큰을 미리 생성(proactive edge drafting)하고 서버는 검증만 수행하는 추론적 디코딩(speculative decoding) 구조를 제안. 토큰 결과만 네트워크로 주고받아 통신 비용을 최소화하고, 파이프라인 인식 스케줄링으로 여러 사용자 요청을 인터리빙해 서버 처리량을 높임
* 인사이트:
  1. 로컬 GPU를 "초안 생성기"로 쓰면 값비싼 서버 연산을 줄이면서도 응답 품질은 그대로 유지 가능
  2. 서버 전용 서빙 대비 비용 효율 1.91배, 서버 처리량 2.22배 향상, 토큰 간 지연시간 11.24% 감소라는 구체적 수치로 실용성을 입증
  3. 엣지-서버 협업 구조는 완전한 로컬 추론이 어려운 환경에서도 엣지 자원을 실질적으로 활용하는 현실적 대안을 제시
* 왜 볼만한가: 온디바이스 추론을 "기기 단독"이 아니라 "기기+서버 협업"으로 재정의해, 저사양 기기에서도 저비용·저지연 LLM 서비스를 만들 수 있는 실무적 경로를 보여줌
* 링크: https://neurips.cc/virtual/2025/poster/119940

2. AI Agent 활용 아이템

* 이름: NVIDIA-Verified Agent Skills (github.com/nvidia/skills)
* 공개/출시시점: 2026년 5월 19일 NVIDIA Developer Blog 공식 발표
* 핵심 기능: Claude Code, Codex 등 코딩 에이전트에 설치하는 NVIDIA 공식 스킬 카탈로그(300개 이상, CUDA-X·로보틱스/Physical AI·시뮬레이션·RAG 등 40여 개 제품군). 각 스킬은 SkillSpector로 프롬프트 인젝션·툴 포이즈닝 등 에이전트 특화 위험을 스캔하고, "Skill Card"로 출처·의존성·한계를 문서화하며, OpenSSF Model Signing 기반 서명으로 무결성을 검증
* 활용 아이디어:
  1. `npx skills add nvidia/skills`로 CUDA·로보틱스·시뮬레이션 개발 시 에이전트가 NVIDIA 공식 워크플로를 바로 따르도록 설정
  2. 외부 스킬 도입 전 Skill Card와 서명 검증으로 사내 보안 정책에 맞는 스킬만 선별 채택
  3. 자체 스킬 배포 시 SkillSpector 스캔·서명 방식을 참고해 사내 에이전트 스킬 거버넌스 체계 구축
* 왜 볼만한가: 스킬 생태계가 커지며 불거진 "출처 불명 스킬의 보안 리스크" 문제에 NVIDIA가 대기업 규모의 검증 인프라(스캐닝+서명+메타데이터)를 얹은 사례로, 공식 저장소 기준 스타 2.8천 개 이상을 확보하며 빠르게 채택 중. Codex CLI, AGENTS.md 등도 검토했으나 이미 이전 브리핑 대비 새로운 발전축이 약해, 스킬 자체가 아니라 "스킬을 안전하게 검증·배포하는 거버넌스 계층"이라는 새로운 각도를 제시하는 이 프로젝트를 선택
* 링크: https://github.com/nvidia/skills
