[AI Morning Brief - 2026-07-31]

1. On-device AI 논문

* 제목: Prima.cpp: Fast 30-70B LLM Inference on Heterogeneous and Low-Resource Home Clusters
* 학회/게재시점: ICLR 2026 (2026년 4월 23일 포스터 발표)
* 다루는 문제: 30B~70B급 대형 LLM을 클라우드 없이 가정 내 여러 대의 저사양 기기(부족한 RAM/VRAM, 느린 디스크, Wi-Fi 연결, 이종 OS)에 분산시켜 실행할 때 발생하는 성능·메모리 병목 문제
* 핵심 Contribution: 디스크 I/O와 연산·통신을 겹쳐 처리하는 파이프라인-링 병렬화(PRP)와, 기기별 RAM/VRAM 제약 아래 CPU/GPU 워크로드·기기 선택을 함께 최적화하는 이종 인식 스케줄러 Halda를 제안. 소비자용 기기 4대로 70B 모델을 674ms/token TPOT, 6% 미만 메모리 부담으로 구동하고, 32B 모델은 추론적 디코딩으로 26 tokens/s까지 도달, 기존 llama.cpp/exo/dllama 대비 5~17배 낮은 TPOT를 달성
* 인사이트:
  1. 단일 고성능 기기가 아니라 "집에 이미 있는 여러 대의 평범한 기기"를 묶어 대형 모델을 돌리는 현실적인 온디바이스 분산 추론 경로를 제시
  2. 디스크 오프로딩과 파이프라인 병렬화를 결합해 OOM 없이 70B급 모델을 저사양 환경에서 안정적으로 구동
  3. 클라우드 의존 없이 프라이버시를 보장하면서도 실사용 가능한 지연시간을 달성해, 온디바이스 LLM의 상한선을 개인 서버/홈랩 수준까지 확장
* 왜 볼만한가: 단일 스마트폰이 아니라 "가정 내 여러 기기 조합"으로 대형 모델을 로컬 구동하는 실용적 아키텍처를 제시해, 온디바이스 AI의 활용 범위를 소형 모델을 넘어 확장하는 방향을 보여줌
* 링크: https://iclr.cc/virtual/2026/poster/10008093

2. AI Agent 활용 아이템

* 이름: OpenCode (Anomaly)
* 공개/출시시점: 2025년 6월 최초 공개, 2025년 10월 31일 TUI 전면 재설계를 담은 v1.0.0 출시, 이후에도 주 단위로 활발히 업데이트 중(2026년 7월 기준 v1.18.x)
* 핵심 기능: 터미널·IDE·데스크톱에서 쓸 수 있는 오픈소스 AI 코딩 에이전트로, 특정 모델 제공사에 종속되지 않고 Claude·GPT·Gemini·로컬 모델 등을 세션 중에도 자유롭게 전환 가능. LSP 연동, 멀티세션, 세션 공유 링크, 빌드/플랜 모드, 클라이언트-서버 구조를 지원
* 활용 아이디어:
  1. 특정 벤더에 묶이지 않고, 상황에 맞춰 비용·성능이 다른 여러 모델을 같은 워크플로우 안에서 바꿔가며 사용
  2. 세션 공유 링크로 페어 프로그래밍이나 코드 리뷰 시 에이전트 작업 과정을 팀원과 함께 확인
  3. 클라이언트-서버 구조를 활용해 로컬 터미널, IDE 확장, 데스크톱 앱 등 여러 인터페이스에서 동일한 에이전트 세션에 접근
* 왜 볼만한가: 2026년 3월 해커뉴스 1위(1,274포인트)에 오르고 GitHub 스타 19만 개, 월 750만 개발자가 사용할 만큼 폭발적으로 채택되고 있으며, 10월 v1.0 전면 재설계 이후에도 매주 안정적으로 릴리스가 이어져 유지보수 상태가 양호함. 다만 일부 개발자는 TUI가 무겁고 기능이 많아 복잡하다는 점을 지적해, 벤더 종속 없는 유연함과 복잡성 사이의 트레이드오프를 고려해 도입할 필요
* 링크: https://github.com/anomalyco/opencode
