[AI Morning Brief - 2026-10-15]

1. On-device AI 논문

* 제목: Select to Think: Unlocking SLM Potential with Local Sufficiency
* 학회/게재시점: ICML 2026 (포스터, 2026-07-07)
* 다루는 문제: 작은 언어모델(SLM)은 배포는 쉽지만 추론력이 약합니다. 기존에는 LLM을 중간중간 호출하거나 증류하는데, 호출은 지연·비용이 늘고 증류는 SLM 용량 한계로 잘 안 됩니다.
* 핵심 Contribution: LLM이 선호하는 다음 토큰이 SLM의 top-K 후보 안에 있다는 "local sufficiency"를 관찰했습니다. LLM은 직접 생성하지 않고 SLM 후보를 고르는 selector로만 쓰고(S2T), 이 선택 능력을 SLM에 증류(S2T-Local)해 추론 시 LLM 없이 동작합니다.
* 인사이트:
  1. 1.5B SLM의 top-8 후보에 32B LLM의 선택이 95% 포함됩니다. 생성이 아니라 "선택"이면 학습 신호가 훨씬 단순해집니다.
  2. S2T-Local은 수학 벤치마크에서 greedy 대비 평균 24.1% 상대 향상을 보였고, 경로 8개짜리 self-consistency와 비슷한 성능을 단일 경로로 냅니다.
  3. 추론 시 클라우드 LLM 호출이 없어 프라이버시와 오프라인 환경에 유리합니다.
* 왜 볼만한가: 기기 안에서 작은 모델의 추론 품질을 추가 연산 없이 끌어올리는 방법이라 온디바이스 배포에 바로 의미가 있습니다.
* 링크: https://icml.cc/virtual/2026/poster/65879

2. AI Agent 활용 아이템

* 이름: REA (morluto/rea)
* 공개/출시시점: 2026-07-12 (npm 패키지 rea-agents 최초 게시일 기준, 최신 v6.5.0, 저장소 최근 커밋 2026-10-14)
* 핵심 기능: AI 에이전트가 리버스 엔지니어링을 하도록 돕는 MCP 서버 + CLI입니다. 네이티브 바이너리(Hopper/Ghidra/IDA), Electron/JS, .NET, Android APK, 펌웨어, 웹/패킷 캡처를 분석하고, 결과에 근거와 한계를 함께 남깁니다. 분석은 로컬에서 실행됩니다.
* 활용 아이디어:
  1. 출처 불명의 앱이나 바이너리가 어떤 네트워크 호출을 하는지 에이전트에게 정리시킵니다.
  2. Electron 앱의 IPC와 라우트를 맵으로 뽑아 보안 점검이나 연동 분석에 씁니다.
  3. 문서 없는 레거시 라이브러리의 동작을 APK나 .NET 어셈블리에서 파악합니다.
* 왜 볼만한가: GitHub 스타 약 23.9만, 포크 약 5.9만으로 이번 주 트렌딩 1위권이고, 오늘도 커밋이 이어지는 활발한 프로젝트입니다. `npx rea-agents setup` 한 줄로 Claude Code, Codex, Cursor 등에 붙습니다. 코드 생성 위주인 다른 에이전트 도구와 달리 "코드 이해"를 겨냥해 차별점이 큽니다. 단, 외부 도구(Ghidra 등)를 직접 설치해야 하고, 런타임 캡처는 사용자 권한으로 대상을 실행하므로 샌드박스에서 쓰는 게 좋습니다. 열린 이슈 468건, PR 328건이라 관리 부담은 있습니다. 커뮤니티 반응은 GitHub 트렌딩 외에 HN/Reddit 논의를 찾지 못했고, 스타 수치는 저장소 페이지 기준입니다.
* 링크: https://github.com/morluto/rea
