1. On-device AI 논문

* 제목: CAS-Spec: Cascade Adaptive Self-Speculative Decoding for On-the-Fly Lossless Inference Acceleration of LLMs
* 학회/게재시점: NeurIPS 2025 (Poster) · 2025년 12월
* 다루는 문제: 별도의 draft 모델을 학습시키지 않고도(training-free, on-the-fly) LLM의 무손실 추론 가속(speculative decoding)을 어떻게 달성할 것인가
* 핵심 Contribution: 타깃 LLM 자체의 가중치에 레이어 스파시티·활성화 양자화를 적용해 여러 단계의 draft 모델 "캐스케이드"를 즉석에서 만들어내고, 각 디코딩 스텝의 예상 수락률·지연시간에 따라 어떤 draft 레벨과 몇 토큰을 추측할지 동적으로 라우팅하는 Dynamic Tree Cascade(DyTC) 알고리즘을 제안. 학습 없는 self-speculative 기법 중 최고 수준(오토리그레시브 대비 1.1~2.3배, 기존 캐스케이드/트리 기법 대비 47~48% 개선)의 속도 향상을 달성
* 인사이트:
  1. 별도 draft 모델을 학습·저장할 필요가 없어 온디바이스 배포 시 메모리·스토리지 부담을 크게 줄인다
  2. 고정된 추측 전략이 아니라 런타임 신호(수락률·지연시간)에 따라 draft 레벨을 바꾸는 하드웨어 인지형 적응 방식이다
  3. 학습 기반 draft 모델 기법과의 격차를 좁혀, "훈련 없이도 실전급 가속"이 가능함을 보여준다
* 왜 볼만한가: 온디바이스 LLM 서빙에서 draft 모델 학습·배포 비용이 큰 걸림돌이었는데, 이를 없애면서도 경쟁력 있는 가속을 보여준 사례라 실용성이 높음
* 링크: https://neurips.cc/virtual/2025/poster/116243

2. AI Agent 활용 아이템

* 이름: Scientific Agent Skills (K-Dense-AI)
* 공개/출시시점: 지속 업데이트 중 · 최근 주요 릴리스 v2.69.0 (2026-09-11)
* 핵심 기능: Claude Code, Cursor, Codex 등 Agent Skills 호환 코딩 에이전트를 "AI 사이언티스트"로 바꿔주는 166개의 과학 연구용 스킬(SKILL.md) 라이브러리. PubChem, UniProt 등 100개 이상 과학 데이터베이스와 RDKit, Scanpy 등 70개 이상 Python 패키지를 감싸 유전체학·신약개발·임상연구·분자동역학 등에 바로 쓸 수 있도록 제공
* 활용 아이디어:
  1. `npx skills add K-Dense-AI/scientific-agent-skills` 한 줄 설치로 연구·데이터 분석 에이전트 워크플로에 즉시 결합
  2. 특정 도메인(PK/PD 모델링, 분자동역학 등) 스킬만 골라 붙여써서 범용 코딩 에이전트를 연구 보조원으로 전문화
  3. 거의 매주 새 DB·스킬이 추가되므로 릴리스노트를 팔로우하며 필요한 스킬만 선택적으로 업데이트
* 왜 볼만한가: MIT 라이선스 오픈소스로 GitHub 스타 4.5만 개, 포크 4.1천 개를 확보했고 7월 말부터 거의 매주 릴리스가 나올 만큼 유지보수가 활발함. 개발사 자체 소개로는 전 세계 19만 명 이상의 과학자가 사용 중이라 밝히고 있어, 범용 Agent Skills 표준이 특정 산업(과학 연구)으로 확장되는 흐름을 보여주는 사례라 지금 볼 가치가 있음
* 링크: https://github.com/K-Dense-AI/scientific-agent-skills
