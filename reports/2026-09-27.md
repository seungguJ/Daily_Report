[AI Morning Brief - 2026-09-27]

1. On-device AI 논문

* 제목: SpecBranch: Speculative Decoding via Hybrid Drafting and Rollback-Aware Branch Parallelism
* 학회/게재시점: ICLR 2026 (포스터, 2026-04-25)
* 다루는 문제: 스펙큘레이티브 디코딩에서 드래프트 모델과 타겟 모델이 어긋나 롤백이 발생하면, 검증 대기 중 파이프라인이 비는 "버블"이 생겨 병렬화 이득이 무너지는 문제
* 핵심 Contribution: CPU 분기 예측(branch prediction) 아이디어를 디코딩에 접목해 여러 추측 분기를 동시에 실행하고 드래프트 길이를 적응적으로 조정, 검증과 재드래프팅이 겹치도록 설계. 출력 분포를 정확히 보존하면서 표준 자기회귀 디코딩 대비 1.8~4.5배 속도 향상, 정렬이 나쁜 드래프트-타겟 쌍에서 롤백 낭비 토큰을 50% 줄임
* 인사이트:
  1. 스펙큘레이티브 디코딩은 로컬 LLM 추론 속도를 좌우하는 핵심 기법인데, 롤백 낭비가 크면 실제 기기에서 체감 가속이 줄어드는 게 고질적 병목이었다.
  2. CPU 아키텍처의 분기 예측 개념을 LLM 디코딩 스케줄링에 옮겨온 접근이 참신하며, 하드웨어-소프트웨어 co-design 관점에서 참고할 만하다.
  3. 무손실(출력 분포 보존)로 속도를 높인다는 점에서 품질 저하 걱정 없이 바로 적용 가능한 실용적 가속 기법이다.
* 왜 볼만한가: 온디바이스 LLM 서빙의 고질적 병목인 "드래프트 검증 대기"를 구조적으로 없애는 방식이라 로컬 추론 최적화에 실질적 힌트를 준다.
* 링크: https://iclr.cc/virtual/2026/poster/10010904

2. AI Agent 활용 아이템

* 이름: GitHub Agentic Workflows (gh-aw)
* 공개/출시시점: 2026-02-13 공식 Technical Preview 발표 (github/gh-aw, GitHub·Microsoft Research 협업)
* 핵심 기능: 마크다운 + YAML 프론트매터로 저장소 자동화를 정의하면 GitHub Actions 위에서 AI 에이전트(GitHub Copilot, Claude Code, Gemini, Codex 등)가 안전하게 실행. 기본 읽기 전용 권한, 승인된 "safe outputs"를 통해서만 쓰기 작업을 허용, 위협 탐지 등 보안 계층을 내장
* 활용 아이디어:
  1. 이슈 트리아지, PR 리뷰, CI 실패 분석 같은 반복 작업을 자연어로 워크플로로 정의해 자동화.
  2. 여러 코딩 에이전트 엔진 중 팀 상황에 맞는 것을 골라 동일한 워크플로 포맷으로 운용.
  3. 샌드박싱·권한 스코프·게이트된 출력 구조를 사내 에이전트 자동화의 보안 설계 템플릿으로 참고.
* 왜 볼만한가: GitHub 공식 프로젝트로 2026-09-23까지도 매주 릴리스가 나올 만큼 활발히 개발 중이고, Hacker News 토론 등 커뮤니티 피드백을 반영해 보안 이슈를 빠르게 패치하는 등 실사용 신호가 뚜렷하다.
* 링크: https://github.com/github/gh-aw
