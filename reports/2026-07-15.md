[AI Morning Brief - 2026-07-15]

1. On-device AI 논문

* 제목: SlimLM: An Efficient Small Language Model for On-Device Document Assistance
* 학회/게재시점: ACL 2025 (System Demonstrations), 2025년 7월, 오스트리아 빈
* 다루는 문제: 스마트폰에서 문서 요약·질의응답·작성 보조를 수행하려 할 때, 메모리와 지연시간 제약 속에서 어느 정도 크기·컨텍스트 길이의 모델이 실사용 가능한지 불명확했던 문제
* 핵심 Contribution: 125M~8B 파라미터의 SlimLM 계열 모델을 SlimPajama-627B로 사전학습하고 문서 보조 전용 데이터셋 DocAssist로 파인튜닝한 뒤, Samsung Galaxy S24 실기기 테스트로 모델 크기·컨텍스트 길이·추론 시간의 최적 균형점을 실증적으로 제시
* 인사이트:
  1. 실제 스마트폰에서 지연시간을 직접 측정해 "이론상 가능"이 아닌 "실사용 가능"한 모델 크기를 규명
  2. 요약/QA/제안이라는 실질 태스크에 맞춘 DocAssist 데이터셋 파인튜닝으로 범용 SLM 대비 동등하거나 더 나은 성능 확보
  3. Android 앱까지 공개해 클라우드 없이 프라이버시를 지키는 온디바이스 문서 어시스턴트를 바로 체험 가능
* 왜 볼만한가: 온디바이스 SLM 배포에서 "몇 B 모델을 어디까지 줄여야 실사용 가능한가"에 대한 실측 벤치마크와 재현 가능한 레시피를 제공해 모바일 개발자에게 바로 참고가 됨
* 링크: https://aclanthology.org/2025.acl-demo.42/

2. AI Agent 활용 아이템

* 이름: LangGraph 1.0 (LangChain)
* 공개/출시시점: 2025년 10월 (정식 GA 출시)
* 핵심 기능: 상태를 유지하며 장시간 실행되는 에이전트를 위한 durable execution(체크포인트 기반 재개), human-in-the-loop 승인 API, 단기/장기 메모리, LangSmith 연동 트레이싱을 갖춘 프로덕션급 에이전트 오케스트레이션 프레임워크
* 활용 아이디어:
  1. 서버 재시작이나 장애가 나도 마지막 체크포인트부터 이어지는 승인 대기형 워크플로우(예: 다일간 결재 프로세스) 구현
  2. 민감한 액션 실행 전 사람이 상태를 검토·수정할 수 있는 human-in-the-loop 단계를 API 몇 줄로 추가
  3. LangSmith로 복잡한 멀티에이전트 상태 전이를 시각화해 프로덕션 디버깅에 활용
* 왜 볼만한가: Uber·LinkedIn·Klarna 등에서 1년 넘게 실전 검증된 뒤 무중단(no breaking changes)으로 1.0 GA 전환한 첫 안정 버전으로, 프로덕션 에이전트 인프라를 검토 중이라면 지금이 적기. 3.7만 GitHub 스타에 최근까지도 릴리즈가 이어지는 등 유지보수도 활발함. (참고로 스타 수가 훨씬 많은 OpenClaw도 함께 검토했으나, CVSS 9.9 권한상승·원격코드실행 등 다수의 심각한 미해결 보안 이슈가 최근까지 보고돼 이번 회차 추천에서는 제외)
* 링크: https://github.com/langchain-ai/langgraph
