[AI Morning Brief - 2026-07-24]

1. On-device AI 논문

* 제목: ThinKV: Thought-Adaptive KV Cache Compression for Efficient Reasoning Models
* 학회/게재시점: ICLR 2026 (Oral, 2026년 4월 24일)
* 다루는 문제: 긴 사고사슬(chain-of-thought)을 생성하는 추론(reasoning) 모델은 토큰이 늘어날수록 KV 캐시가 급격히 커져, 메모리가 제한된 환경에서 감당하기 어려워지는 문제
* 핵심 Contribution: 사고(thought) 단위 어텐션 희소성 패턴으로 토큰 중요도를 판별해 정밀도를 차등 양자화하고, 덜 중요한 사고의 토큰을 점진적으로 축출하는 하이브리드 기법 제안. 축출된 토큰의 메모리 슬롯을 압축(compaction) 없이 재사용하도록 PagedAttention을 확장한 전용 커널까지 설계
* 인사이트:
  1. 사고사슬 내부에도 어텐션 패턴상 "덜 중요한 사고"와 "핵심 사고"가 뚜렷이 구분되어, 모든 추론 단계를 동일한 정밀도로 저장할 필요가 없음
  2. 양자화+점진적 축출을 결합하면 KV 캐시를 원본 대비 5% 미만으로 줄이면서도 정확도 손실이 거의 없음 (DeepSeek-R1-Distill, GPT-OSS, NVIDIA AceReason 등 수학·코딩 벤치마크에서 검증)
  3. 압축 없이 슬롯을 재사용하는 커널 설계 덕분에 기존 KV 캐시 압축 기법 대비 최대 5.8배 처리량 향상
* 왜 볼만한가: 온디바이스·엣지 환경에서 긴 추론형 모델을 돌릴 때 가장 큰 걸림돌인 KV 캐시 메모리 폭증 문제를, 알고리즘과 커널 설계를 함께 제시해 실질적으로 해결한 사례
* 링크: https://iclr.cc/virtual/2026/oral/10009981

2. AI Agent 활용 아이템

* 이름: Google Agent Development Kit (ADK) 2.0
* 공개/출시시점: ADK Python v2.0.0 GA 2026년 5월 19일 (ADK Go 2.0 GA는 6월 30일, 이후에도 v2.5.0(7월 16일)까지 꾸준히 마이너 업데이트 중)
* 핵심 기능: 기존의 계층형 "에이전트가 하위 에이전트를 호출"하는 구조에서 그래프 기반 Workflow Runtime으로 전환 — 에이전트·툴·함수가 노드가 되어 라우팅, 팬아웃/팬인, 반복, 재시도, 상태 관리, human-in-the-loop, 중첩 워크플로를 지원하고, 에이전트 간 위임을 위한 Task API를 신설
* 활용 아이디어:
  1. 코디네이터 에이전트가 여러 전문 하위 에이전트로 작업을 팬아웃하고, 재시도·HITL 체크포인트를 명시적으로 두는 결정론적 멀티에이전트 파이프라인 구축
  2. Vertex AI·Cloud Run·A2A 프로토콜과 네이티브 연동해 세션/상태를 자동 영속화하는 프로덕션급 에이전트 배포
  3. LangGraph류의 그래프 오케스트레이션이 필요하면서 이미 GCP 스택에 있는 조직이라면 전환 검토 (단, 1.x와 스토리지 포맷이 호환되지 않아 별도 환경에서 마이그레이션 필요, Python 3.11+ 요구)
* 왜 볼만한가: GitHub 스타 2만 900개·포크 3,800개로 채택 신호가 뚜렷하고, 5월 GA 이후에도 7월까지 매달 마이너 버전(v2.2~v2.5)을 출시할 만큼 개발이 활발함. 함께 검토한 OpenClaw는 스타 수는 훨씬 많지만 다수 보안 연구기관이 심각한 취약점(악성 스킬 마켓플레이스, 에이전트 탈취 익스플로잇 등)을 지적해 제외했고, browser-use·OpenAI Codex CLI는 최근 활동은 있으나 이 기간 내 "의미 있는 메이저 업데이트"로 보기 어려워 제외. Google 공식 프레임워크로서 실질적 아키텍처 전환(그래프 런타임)과 지속적 릴리스 케이던스가 뚜렷해 이번에 선정
* 링크: https://github.com/google/adk-python
