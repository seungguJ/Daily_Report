[AI Morning Brief - 2026-10-05]

1. On-device AI 논문

* 제목: From Volume to Value: Preference-Aligned Memory Construction for On-Device RAG
* 학회/게재시점: ICML 2026 Poster (2026-07-08 발표)
* 다루는 문제: 온디바이스 개인 AI 에이전트는 메모리가 빠듯해서 "무엇을 저장할지"가 병목입니다. 원본 데이터를 다 색인하면 메모리는 폭증하고, 검색은 사용자 취향과 어긋납니다.
* 핵심 Contribution: EPIC(Efficient Preference-aligned Index Construction)을 제안했습니다. 사용자 선호를 작고 안정적인 개인 컨텍스트로 보고, 저장 단계에서 선호 관련 정보만 남기고 검색도 선호에 맞춰 정렬합니다.
* 인사이트:
  1. 인덱싱 메모리를 최대 2,404배 줄였고, 선호 반영 정확도는 18.79%p 올렸습니다.
  2. 검색 지연은 32.17배 낮췄고, 세 가지 기기 플랫폼에서 메모리 1MB 미만, 쿼리당 5.21~29.35ms를 유지합니다.
  3. 선호가 바뀌어도 스트리밍 업데이트로 반영할 수 있어 개인화 메모리에 현실적입니다.
* 왜 볼만한가: 온디바이스 LLM 논의가 모델 압축에 쏠려 있는데, 이 논문은 개인 데이터 메모리 쪽 병목을 짚습니다. 프라이버시 중심 개인 에이전트를 만들 때 바로 참고할 만합니다.
* 링크: https://icml.cc/virtual/2026/poster/62548

2. AI Agent 활용 아이템

* 이름: Agent Skills (addyosmani/agent-skills)
* 공개/출시시점: 최신 릴리스 0.6.12 (2026-10-03). 7월 초 0.6.3 이후 거의 격주로 릴리스가 이어지고 있습니다.
* 핵심 기능: 스펙, 계획, 구현, 검증, 리뷰, 배포까지 개발 생애주기 전반을 다루는 코딩 에이전트용 스킬 25개 묶음입니다. 단계별 절차, 검증 게이트, 합리화 방지 표가 들어 있습니다. Claude Code, Cursor, Codex, Copilot, Cline, Gemini CLI, OpenCode 등을 지원합니다.
* 활용 아이디어:
  1. `npx skills add addyosmani/agent-skills` 한 줄로 설치하고, 쓰는 코딩 에이전트에 스펙→계획→구현→검증 흐름을 입힙니다.
  2. 전부 켜지 말고 필요한 스킬만 골라 씁니다. 예를 들어 공식 문서 인용을 강제하는 source-driven 스킬과 장시간 작업 후 회의적 리뷰를 하는 스킬이 있습니다.
  3. 팀 코드 리뷰 체크리스트와 성능 최적화 워크플로(Chrome DevTools 연동)를 에이전트 규칙으로 표준화합니다.
* 왜 볼만한가: GitHub 스타 약 10.1만, 포크 약 1.06만으로 스킬 저장소 중 채택 신호가 매우 큽니다. 커밋이 계속 올라오는 활발한 유지보수 중이고 라이선스는 MIT입니다. 개발자 커뮤니티 리뷰(dev.to 등)는 범위가 넓고 웹/프론트엔드 성능 쪽이 특히 강하다고 평가하지만, 전부 한꺼번에 쓰지 말고 골라 쓰라는 조언이 같이 나옵니다. 이미 소개한 Superpowers나 mattpocock/skills와 겹치지 않고, 설치가 쉬워서 오늘 바로 써볼 수 있어 골랐습니다. HN 반응은 확인하지 못했습니다.
* 링크: https://github.com/addyosmani/agent-skills
