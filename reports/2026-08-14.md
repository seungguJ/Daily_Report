[AI Morning Brief - 2026-08-14]

1. On-device AI 논문

* 제목: OmniDraft: A Cross-vocabulary, Online Adaptive Drafter for On-device Speculative Decoding
* 학회/게재시점: NeurIPS 2025 (2025년 12월, San Diego 포스터)
* 다루는 문제: 스펙큘레이티브 디코딩은 보통 타겟 모델마다 별도로 사전학습·증류된 draft 모델이 필요해, 기기에서 사용하는 로컬 LLM을 바꿀 때마다 새 draft 모델을 준비해야 하는 문제
* 핵심 Contribution: 온라인 n-gram 캐시로 draft 모델과 타겟 모델 간 토크나이저(vocabulary) 불일치를 실시간으로 변환하고, 하이브리드 증류 파인튜닝을 결합. Llama-68M 하나의 draft 모델로 Vicuna-7B, Qwen2-7B, Llama3-8B 등 서로 다른 타겟 모델에 그대로 붙여 쓸 수 있으며, 사용 중 온라인 적응을 통해 1.5~2배 디코딩 속도 향상을 달성
* 인사이트:
  1. 타겟 모델마다 draft 모델을 따로 증류할 필요가 없어, 저장공간과 메모리가 빠듯한 온디바이스 환경에서 모델을 자유롭게 교체해도 가속 기능을 그대로 쓸 수 있음
  2. 사용자의 실제 세션 데이터에 맞춰 온라인으로 적응하며 속도가 점점 개선되는 구조라, 개인화된 온디바이스 사용 패턴에 잘 맞음
  3. 아키텍처 변경 없이 vocabulary 변환 캐시만 추가하는 방식이라 기존 draft 모델에 가볍게 얹을 수 있는 실전형 기법
* 왜 볼만한가: 기기 위 로컬 LLM을 어떤 모델로 바꾸든 범용 draft 모델 하나로 스펙큘레이티브 디코딩 가속을 유지할 수 있게 한, 실용성 높은 온디바이스 추론 가속 연구
* 링크: https://neurips.cc/virtual/2025/loc/san-diego/poster/118052

2. AI Agent 활용 아이템

* 이름: Pi (Pi Coding Agent, pi.dev / Earendil Inc.)
* 공개/출시시점: 2025년 8월 Mario Zechner(badlogic)가 최초 공개, 2026년 4월 Earendil 합류 후에도 거의 매일 업데이트되며 최신 버전은 v0.84.2(2026년 8월 14일), 풀스크린 TUI·Mermaid·LaTeX 렌더링을 더한 v0.84.0 메이저 업데이트는 2026년 8월 6일
* 핵심 기능: read/write/edit/bash 단 4개 도구만 내장한 극도로 미니멀한 코딩 에이전트 하네스. 시스템 프롬프트가 약 1,000토큰에 불과하고, 부족한 기능은 TypeScript 확장·스킬로 직접 추가하도록 설계. Anthropic·OpenAI·Google·xAI·Groq 등 멀티 프로바이더와 로컬 llama.cpp 모델 관리, 세션 분기/재개, AGENTS.md 기반 프로젝트 설정을 지원
* 활용 아이디어:
  1. 숨겨진 컨텍스트 없이 모든 것을 투명하게 노출하는 구조를 활용해 프롬프트·컨텍스트 엔지니어링을 정밀하게 실험
  2. 필요한 기능만 TypeScript 확장/스킬로 얹어, 사내 워크플로우 전용 경량 커스텀 에이전트를 빠르게 조립
  3. 로컬 llama.cpp 모델 관리 기능을 활용해 온디바이스 모델과 결합한 가벼운 코딩 에이전트 환경 구성
* 왜 볼만한가: Hacker News 정식 런칭에서 608포인트를 기록했고, GitHub 스타 9만 개를 돌파(2026년 8월 기준)했으며 릴리스가 며칠 단위로 이어질 만큼 유지보수가 활발함. Terminal-Bench 2.0에서 Codex·Cursor·Windsurf와 견줄 성능을 기록해 미니멀 구조에도 실전 성능이 확인됨. 기존에 다룬 LangGraph·Mastra·Goose·Hermes Agent 등 기능을 계속 확장해가는 범용/멀티에이전트 프레임워크와 달리, "필요 없으면 만들지 않는다"는 반대 철학으로 실용적 시사점을 준다는 점에서 이번 아이템으로 선정
* 링크: https://github.com/earendil-works/pi
