[AI Morning Brief - 2026-09-25]

1. On-device AI 논문

* 제목: SmartAD: Capacity-Aligned Agent Distillation for Small Language Models
* 학회/게재시점: ACL 2026 Findings (2026-07, ACL Anthology 게재)
* 다루는 문제: 대형 모델의 에이전트형 추론(도구 사용, 다단계 reasoning)을 온디바이스에 맞는 소형 모델(1.5B~3B)로 옮기려 해도, 기존 distillation은 학생 모델이 배우기 어려운 교사 궤적을 그대로 학습시키고 전체 토큰을 동일하게 다뤄 성능 손실이 컸음.
* 핵심 Contribution: 여러 정답 교사 궤적 중 학생 모델 기준 negative log-likelihood가 가장 낮은, 즉 "학생이 소화하기 쉬운" 궤적을 골라 학습시키고, 도구 실행·최종 결정 구간에 손실 가중치를 집중하는 segment-weighted loss를 결합한 SmartAD 프레임워크를 제안.
* 인사이트:
  1. 정답 궤적이라도 무조건 가르치지 않고 학생 모델이 소화 가능한 궤적을 선별해 distillation 효율을 높임.
  2. reasoning 전체를 균등하게 학습시키는 대신 tool-action·최종 결정 구간에 손실 가중치를 집중.
  3. 1.5B~3B 모델로 multi-hop QA·수학 벤치마크에서 기존 agent distillation 기법 대비 일관된 성능 향상을 확인.
* 왜 볼만한가: 양자화·프루닝과는 다른 축에서, 온디바이스 배포 가능한 크기의 모델에 "에이전트형 능력"을 이식하는 실질적 학습 레시피를 제시함.
* 링크: https://aclanthology.org/2026.findings-acl.1349/

2. AI Agent 활용 아이템

* 이름: Cloudflare Security Audit Skill
* 공개/출시시점: 2026-06-18 (Cloudflare 공식 블로그 "Build your own vulnerability harness"로 오픈소스 공개), 2026년 9월 GitHub 트렌딩·HN에서 재확산
* 핵심 기능: 코딩 에이전트를 구조화된 보안 감사관으로 바꿔주는 스킬. 정찰(공격 표면 매핑) → 취약점 클래스별 헌팅 → 독립 에이전트의 적대적 검증 → 스키마 검증·재확인 → 리포트 생성까지 6단계 파이프라인으로, 단일 패스 LLM 코드 리뷰의 고질적인 오탐(false positive)을 억제하도록 설계됨.
* 활용 아이디어:
  1. "이 코드베이스 보안 감사해줘" 같은 자연어 요청 한 줄로 실행하거나, 특정 경로·PR 단위로도 사용 가능.
  2. 여러 "헌터" 에이전트가 독립적으로 취약점을 찾고, 별도 "검증" 에이전트가 반증을 시도한 뒤 살아남은 항목만 최종 리포트에 포함시키는 구조를 그대로 참고 구현으로 활용.
  3. Cloudflare가 실제 내부 취약점 발견 파이프라인에 쓰던 방식을 공개한 것이므로, 사내 보안 감사 워크플로 설계 시 레퍼런스로 삼기 좋음.
* 왜 볼만한가: 공개 후 GitHub 스타 21.3k(9/24 기준)까지 빠르게 늘었고 Hacker News 프론트페이지(212포인트, 38댓글)에 오르는 등 여러 채널에서 실질적 반응이 이어짐. 다만 중간 규모 코드베이스 감사에 15만~100만 토큰이 소모된다는 보고와, "보안 연구"로 작업을 명시하면 LLM이 거부하는 경우가 있다는 지적도 함께 나와 실사용 전 감안이 필요함.
* 링크: https://github.com/cloudflare/security-audit-skill
