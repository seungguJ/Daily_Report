[AI Morning Brief - 2026-07-13]

1. On-device AI 논문

* 제목: SlimLM: An Efficient Small Language Model for On-Device Document Assistance
* 학회/게재시점: ACL 2025 (System Demonstrations, 2025년 7월 27일~8월 1일, 비엔나)
* 다루는 문제: 스마트폰에서 문서 요약·QA·작성 제안을 처리하는 소형 언어모델을 만들 때, 모델 크기·컨텍스트 길이·추론 속도 사이의 적정 지점을 알기 어려운 문제
* 핵심 Contribution: 125M~8B 파라미터의 SlimLM 시리즈를 SlimPajama-627B로 사전학습하고 자체 구축한 DocAssist(요약/QA/제안) 데이터로 파인튜닝, Galaxy S24 실기기 실측을 통해 성능-속도 스위트 스팟을 제시하고 안드로이드 데모 앱까지 공개
* 인사이트:
  1. 이론적 FLOPs가 아니라 실제 상용 스마트폰(S24)에서 모델별 추론 시간을 실측해 배포 가능한 크기 구간을 구체적으로 제시
  2. 요약/QA/제안을 하나의 소형 모델에 멀티태스크로 결합해 별도 앱 없이 문서 어시스턴트 기능 구현
  3. 개인·사내 문서처럼 서버 전송이 부담스러운 데이터를 기기 안에서만 처리하는 프라이버시 우선 설계를 실증
* 왜 볼만한가: 시뮬레이션이 아닌 실제 기기 벤치마크와 동작하는 안드로이드 앱까지 공개돼 On-device SLM을 실무에 적용하려는 팀이 바로 참고할 수 있는 자료
* 링크: https://aclanthology.org/2025.acl-demo.42/

2. AI Agent 활용 아이템

* 이름: mcp-server-dev (MCP 서버 개발용 공식 Agent Skills 플러그인)
* 공개/출시시점: 2026년 3월 20일 최초 공개 (2026년 4월 배포/인증 가이드 업데이트)
* 핵심 기능: MCP 서버 설계를 안내하는 3종 조합형 Skill(build-mcp-server/build-mcp-app/build-mcpb) 제공. 진입 Skill이 연결 대상, 사용자 범위, 인증 방식 등을 질문으로 파악한 뒤 Remote HTTP·MCP App(UI)·MCPB 번들·로컬 stdio 중 적합한 배포 경로를 추천하고 코드까지 스캐폴딩
* 활용 아이디어:
  1. 사내 API나 로컬 툴을 MCP 서버로 만들 때 설계 단계부터 대화로 진행해 바로 실행 가능한 스캐폴드 코드 확보
  2. UI가 필요한 서버는 build-mcp-app이 자동으로 이어받아 폼/피커/대시보드까지 구현
  3. Node/Python 설치가 부담스러운 로컬 배포는 build-mcpb가 단일 .mcpb 패키지로 묶어 설치 마찰 최소화
* 왜 볼만한가: MCP 공식 문서가 서버 개발의 표준 진입점으로 안내할 만큼 검증됐고, 인증·배포 모델 같은 설계 의사결정까지 자동으로 짚어줘 MCP 서버를 처음 만드는 에이전트 개발자의 시간을 실질적으로 아껴줌
* 링크: https://modelcontextprotocol.io/docs/develop/build-with-agent-skills
