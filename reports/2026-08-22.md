[AI Morning Brief - 2026-08-22]

1. On-device AI 논문

* 제목: ZoomR: Memory Efficient Reasoning through Multi-Granularity Key Value Retrieval
* 학회/게재시점: ACL 2026 (Main, Long Paper, 2026년 7월)
* 다루는 문제: 최근 추론(reasoning) LLM은 정답 전에 긴 사고 과정을 생성하는데, 이 과정에서 KV 캐시가 출력 길이에 비례해 계속 커져 메모리 부담이 폭증하는 문제. 기존 KV 압축 연구는 대부분 "입력 컨텍스트" 압축에 집중해, 긴 출력을 생성하는 추론 작업에는 한계가 있었음
* 핵심 Contribution: 장황한 사고 과정을 요약본으로 압축해 저장하고, 디코딩 시 이 요약을 "거친 인덱스"로 활용해 정말 중요한 부분만 원본 세부 정보로 "확대(zoom in)"해서 조회하는 다단계(multi-granularity) KV 검색 기법을 제안. 수학·추론 벤치마크에서 성능 저하 없이 추론 메모리 사용량을 4배 이상 절감
* 인사이트:
  1. 입력 컨텍스트가 아닌 "출력(사고 과정) 길이"에서 오는 KV 캐시 폭증이라는, 최근 추론 모델 특유의 새로운 병목을 정면으로 다룸
  2. 전체를 다 들고 있지 않고 필요할 때만 세부 정보를 조회하는 계층적 구조는 온디바이스 메모리 제약 하에서 긴 사고형 추론을 돌리는 데 바로 응용 가능
  3. 4배 메모리 절감은 동일 하드웨어에서 더 긴 사고 과정이나 더 큰 배치를 처리할 수 있다는 의미로, 온디바이스 추론 모델 상용화에 실질적 여유를 제공
* 왜 볼만한가: on-device에서 reasoning 모델을 돌릴 때 가장 먼저 부딪히는 "긴 사고 과정 = 메모리 폭증" 문제를 구조적으로 풀어낸 연구로, 향후 경량 추론 모델 설계에 참고할 만함
* 링크: https://aclanthology.org/2026.acl-long.76/

2. AI Agent 활용 아이템

* 이름: Deep Agents (LangChain)
* 공개/출시시점: 2026년 3월 공식 발표(오픈소스), 이후 v0.5까지 활발히 업데이트되며 비동기 서브에이전트·멀티모달 파일시스템 등 기능 추가 지속
* 핵심 기능: LangGraph 위에 구축된 "배터리 포함형" 에이전트 하네스. 계획(planning) 관리, `task` 툴을 통한 서브에이전트 위임, 가상 파일시스템과 샌드박스 셸 실행, 세션 간 지속되는 메모리, Agent Skills 규격 기반 스킬 로딩, 컨텍스트 자동 요약, MCP 서버 연동을 기본 제공하며 툴콜을 지원하는 어떤 LLM과도 모델-무관하게 동작
* 활용 아이디어:
  1. `create_deep_agent()` 하나로 계획·서브에이전트·파일시스템·메모리가 갖춰진 장기 작업용 에이전트를 손쉽게 구성
  2. 특정 도메인 노하우를 스킬 파일로 만들어 로드시켜, 반복 작업(리서치·코딩·문서 정리)의 처리 품질을 지속적으로 개선
  3. Anthropic 모델에 종속되지 않고 원하는 LLM으로 Claude Code류의 에이전트 워크플로를 자체 구축하고 싶은 팀의 기반 프레임워크로 활용
* 왜 볼만한가: GitHub 스타 2.8만 개, MIT 라이선스로 활발히 개발 중이며, TerminalBench 2.0에서 Claude Sonnet 4.5 기준 약 42.65%를 기록해 Claude Code와 동급 성능을 보임. Reddit·Hacker News에서는 "모델에 종속되지 않는 Claude Code"라는 평가와 함께 비동기 서브에이전트 아키텍처에 대한 실무자들의 긍정적 반응이 이어짐(다만 비동기 서브에이전트는 별도 Agent Protocol 서버가 필요해 아직 완전한 plug-and-play는 아니라는 지적도 있음). 유사 시기 후보였던 Context7(MCP 문서 서버)은 이미 오래전부터 널리 쓰이던 프로젝트라 최근 12개월 내 의미 있는 신규성 부각이 어려워 제외하고, 하네스 자체의 새로운 설계와 커뮤니티 반응이 뚜렷한 이번 아이템을 선정
* 링크: https://github.com/langchain-ai/deepagents
