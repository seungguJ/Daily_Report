[AI Morning Brief - 2026-08-05]

1. On-device AI 논문

* 제목: Prima.cpp: Fast 30–70B LLM Inference on Heterogeneous and Low-Resource Home Clusters
* 학회/게재시점: ICLR 2026 (2026년 4월 23일, Poster)
* 다루는 문제: 30B~70B급 대형 LLM은 RAM/VRAM이 부족하고 디스크·네트워크(Wi-Fi)도 느린 일반 가정용 기기 한 대로는 로컬 구동이 사실상 불가능하다는 문제
* 핵심 Contribution: 집에 있는 이기종 기기(노트북·데스크톱·구형 PC 등) 여러 대를 하나의 분산 추론 클러스터로 묶는 prima.cpp 제안. 디스크 I/O와 연산·통신을 겹쳐 처리해 mmap 오프로딩의 prefetch-release 병목을 해소하는 파이프라인드-링 병렬화(PRP)와, 기기별 메모리 제약 아래 CPU/GPU 작업을 최적 배분하는 Halda 스케줄러를 결합
* 인사이트:
  1. 기기 4대로 70B 모델을 674ms/token, 메모리 여유 6% 이상을 유지하며 구동 — llama.cpp/exo/dllama 대비 5~17배 낮은 TPOT 달성
  2. 32B 모델은 추측 디코딩(speculative decoding)과 결합해 26 tokens/s까지 확보, 실사용 가능한 체감 속도를 제공
  3. Wi-Fi 환경에서도 안정적이며 OOM 없이 완전히 로컬에서 동작해 프라이버시를 보장하고 클라우드 비용·지연을 제거
* 왜 볼만한가: "한 대의 고성능 기기"가 아니라 "집에 이미 있는 여러 평범한 기기"를 묶어 프론티어급 모델을 로컬 구동하는 실용적 접근이라, 값비싼 GPU 없이도 온디바이스 AI를 대중화할 실마리를 제공
* 링크: https://iclr.cc/virtual/2026/poster/10008093

2. AI Agent 활용 아이템

* 이름: andrej-karpathy-skills (Karpathy-Inspired CLAUDE.md)
* 공개/출시시점: 2026년 1월 27일 공개 (Forrest Chang 제작, Karpathy 본인 저작물은 아님)
* 핵심 기능: Karpathy가 지적한 LLM 코딩 에이전트의 전형적 실패 패턴(무단 가정, 과잉 설계, 무관한 수정, 검증 누락)을 "생각 먼저", "단순함 우선", "수술적 변경", "목표 기반 실행" 4가지 규칙으로 정리한 단일 CLAUDE.md 파일. Claude Code 플러그인/스킬로 설치하거나 Cursor에도 그대로 적용 가능
* 활용 아이디어:
  1. 프로젝트 루트에 CLAUDE.md로 저장해두면 별도 설정 없이 Claude Code가 매 세션 자동으로 규칙을 준수
  2. "생각 먼저, 코드는 나중" 원칙으로 에이전트가 가정을 드러내고 트레이드오프를 먼저 설명하게 해, 방향이 틀린 대규모 수정을 사전에 예방
  3. 작업을 검증 가능한 성공 기준으로 바꾸도록 강제해, 에이전트가 스스로 결과를 확인하는 루프를 구성
* 왜 볼만한가: 공개 6개월여 만에 원본 저장소만 9만 스타 이상, 조직 미러(multica-ai) 포함 총 20만 스타·2만 포크 이상을 기록하며 GitHub 역사상 가장 빠르게 성장한 저장소 중 하나로 꼽힘. 새 툴 설치 없이 파일 하나만 추가하면 되는 낮은 도입 장벽이 이런 폭발적 채택의 핵심 이유이며, 같은 기간 화제였던 Google 공식 gws CLI(Workspace 자동화, 약 3만 스타)보다 적용 범위가 넓고 채택 규모도 훨씬 큼
* 링크: https://github.com/forrestchang/andrej-karpathy-skills
