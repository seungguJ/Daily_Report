[AI Morning Brief - 2026-08-15]

1. On-device AI 논문

* 제목: MobileLLM-Flash: Latency-Guided On-Device LLM Design for Industry Scale Deployment
* 학회/게재시점: ACL 2026 Industry Track (2026년 7월, Meta)
* 다루는 문제: 모바일 기기의 실시간 지연시간 제약을 만족하면서도 커스텀 커널 없이 다양한 하드웨어에 폭넓게 배포 가능한 온디바이스 LLM을 설계하는 문제
* 핵심 Contribution: 사전학습된 백본에서 가중치를 상속받아 pruning한 후보 모델들을 만들고, 하드웨어-인-더-루프 방식으로 지연시간 예측기를 학습해 아키텍처(레이어/차원)와 attention 패턴(특수 attention 대신 attention-skipping)을 동시에 탐색. 그 결과물이 MobileLLM-Flash 패밀리(350M/650M/1.4B, 최대 8K 컨텍스트)이며 ExecuTorch 같은 표준 모바일 런타임과 바로 호환됨
* 인사이트:
  1. Prefill 최대 1.8배, decode 최대 1.6배 속도 향상을 실측으로 검증 - 이론적 FLOPs 감소가 아니라 실제 모바일 CPU 성능 개선
  2. 커스텀 커널/특수 attention을 배제해 실제 상용 모바일 추론 스택(ExecuTorch)에 바로 이식 가능 - "연구실에서 기기로" 격차를 해소
  3. 처음부터 학습하는 대신 사전학습 백본을 pruning해 재학습 토큰을 약 35%로 줄이는 방식은 산업 규모에서 Pareto 탐색을 경제적으로 가능하게 하는 재사용 가능한 레시피
* 왜 볼만한가: Meta가 산업 트랙에서 실측 데이터로 검증한, 온디바이스 LLM의 "지연시간-정확도-배포 가능성" 삼중 트레이드오프를 동시에 해결한 실용적 연구
* 링크: https://aclanthology.org/2026.acl-industry.51/

2. AI Agent 활용 아이템

* 이름: Google Agent Development Kit (ADK) - ADK 2.0
* 공개/출시시점: 2025년 4월 최초 공개, 2026년 5월 19일 ADK 2.0 정식 출시(GA)
* 핵심 기능: 코드 우선(code-first)이며 특정 모델에 종속되지 않는 오픈소스 멀티 에이전트 구축·평가·배포 툴킷. ADK 2.0부터는 에이전트·툴·함수를 노드로 다루는 그래프 기반 워크플로우 런타임을 제공하며, MCP 연동, 메모리·세션 관리, 평가 프레임워크, 디버깅용 개발자 UI를 포함
* 활용 아이디어:
  1. API 호출 같은 결정론적 단계와 LLM 추론 단계를 신뢰성 있게 결합해야 하는 프로덕션 멀티 에이전트 업무 워크플로우 구축
  2. Vertex AI/Gemini 기반 에이전트를 빠르게 프로토타이핑 - Google 자사의 Agentspace, Customer Engagement Suite와 동일한 프레임워크
  3. Python/Java/Go/TypeScript로 언어에 관계없이 동일한 에이전트 로직을 배포해야 하는 다중 언어 백엔드 조직에 적합
* 왜 볼만한가: GitHub 스타 2만1천 개 이상에 8월 첫 2주 만에 버전 태그 3개가 나올 만큼 활발한 릴리즈 주기를 보이며, ADK 2.0은 자체 벤치마크에서 토큰 사용량 약 50%, 지연시간 약 20% 감소를 보고. 최근 공식 워크플로우 템플릿에서 발견된 프롬프트 인젝션 취약점(패치 완료) 이슈도 역설적으로 프로덕션에서 널리 쓰이고 있음을 보여줌
* 링크: https://github.com/google/adk-python
