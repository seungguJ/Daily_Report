[AI Morning Brief - 2026-07-12]

1. On-device AI 논문

* 제목: MobiLoRA: Accelerating LoRA-based LLM Inference on Mobile Devices via Context-aware KV Cache Optimization
* 학회/게재시점: ACL 2025 (2025년 7월, 비엔나)
* 다루는 문제: 모바일 기기에서 LoRA 기반 LLM을 서빙할 때 제한된 연산·메모리 자원으로 KV 캐시 부담을 감당하기 어려운 문제
* 핵심 Contribution: 프롬프트 공유 프리픽스 같은 의미적 유사성을 활용한 similarity-aware delta encoding과, 앱의 포그라운드/킬 상태 등 시스템 컨텍스트를 반영한 context-aware KV 캐시 관리를 결합해 여러 LoRA 어댑터 간 KV 캐시를 효율적으로 저장·재사용
* 인사이트:
  1. 서로 다른 LoRA 어댑터라도 KV 캐시가 토큰 단위로 유사한 경우가 많아 delta encoding으로 중복 저장을 크게 줄일 수 있음
  2. 앱 상태(포그라운드/백그라운드/킬) 같은 시스템 신호를 캐시 보존·축출 정책에 반영하면 실사용 환경에서 효율이 크게 개선됨
  3. 실제 모바일 기기 트레이스 기반 구현 비교에서 기존 LLM 서빙 프레임워크 대비 추론 속도 57.6% 향상
* 왜 볼만한가: 온디바이스 LLM 개인화(LoRA)의 실질적 병목인 KV 캐시 자원 문제를 실제 모바일 트레이스로 검증한 실용적 해법이라 배포 관점에서 바로 참고할 만함
* 링크: https://aclanthology.org/2025.acl-long.1140/

2. AI Agent 활용 아이템

* 이름: Microsoft Agent Skills for .NET
* 공개/출시시점: 2026년 7월 7일 (정식 GA)
* 핵심 기능: .NET 에이전트가 도메인 지식을 Skill 단위 패키지로 분리해 필요할 때만 탐색·로드하는 공식 API. 파일 기반/클래스 기반/코드 기반 3가지 작성 방식과 사람 승인 게이트, 실행 제어 등 거버넌스 기능을 제공
* 활용 아이디어:
  1. 에이전트 지시문에 모든 지식을 몰아넣는 대신 스킬 단위로 분리해 컨텍스트 창을 가볍게 유지
  2. 이름→설명→리소스→스크립트 순으로 단계적으로 로딩하는 progressive disclosure 패턴으로 대규모 툴/지식 카탈로그를 가진 에이전트의 토큰 낭비를 줄임
  3. NuGet 패키지로 스킬을 배포해 팀 간 도메인 전문성을 재사용 가능한 컴포넌트로 공유
* 왜 볼만한가: Claude Skills에 이어 Microsoft도 스킬 아키텍처를 정식 GA로 전환하며 스킬 기반 설계가 업계 표준 패턴으로 자리잡는 중이라, 에이전트 설계 시 지금부터 참고할 만함
* 링크: https://devblogs.microsoft.com/agent-framework/agent-skills-for-net-is-now-released/
