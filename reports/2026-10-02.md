1. On-device AI 논문

* 제목: LiftQuant: Continuous Bit-Width Control for Pareto-Optimal LLM Deployment
* 학회/게재시점: ICML 2026 (포스터, 2026-07-07)
* 다루는 문제: 기존 양자화는 2·3bit처럼 정수 비트폭만 쓸 수 있어, 기기 메모리 예산에 딱 맞는 모델 크기를 못 만든다.
* 핵심 Contribution: 1비트 격자를 D차원으로 "lift"한 뒤 projection하는 방식으로 유효 비트폭을 D/d로 연속 조절하는 양자화 프레임워크를 제안했다.
* 인사이트:
  1. 70B 모델을 2.4bit로 압축해 24GB GPU에 정확히 맞추고, 기존 2bit SOTA보다 성능이 높다.
  2. 디코딩 처리량이 FP16 대비 최대 6.7배 빠르다.
  3. 압축 수준이 정수 단위에서 연속 단위로 바뀌어, 기기 메모리 한도에 맞춘 Pareto 최적 배포가 가능해진다.
* 왜 볼만한가: 폰·노트북처럼 메모리가 제각각인 기기에서 "들어갈 수 있는 가장 큰 모델"을 고르는 문제를 직접 풀어준다.
* 링크: https://icml.cc/virtual/2026/poster/66695

2. AI Agent 활용 아이템

* 이름: Archify (tt-a1i/archify)
* 공개/출시시점: v3.0.1 릴리스 2026-09-28 (2026-08-26 GitHub Trending 1위 진입)
* 핵심 기능: 말로 설명하거나 코드를 주면 아키텍처·워크플로·시퀀스·데이터플로·라이프사이클 다이어그램을 애니메이션 포함 단일 HTML로 만들어주는 에이전트 스킬. Cursor, Claude Code, Codex CLI, OpenCode에서 쓴다.
* 활용 아이디어:
  1. `npx skills add tt-a1i/archify -g`로 설치한 뒤 PR 설명에 넣을 아키텍처 그림을 코드 기반으로 생성한다.
  2. CI/CD 파이프라인이나 요청 경로를 설명해 온보딩 문서용 인터랙티브 다이어그램을 만든다.
  3. 거친 Mermaid 초안을 정돈된 HTML/PNG/SVG로 변환해 발표 자료에 쓴다.
* 왜 볼만한가: 약 7.6만 stars, forks 5천 이상으로 9월 트렌딩 상위권이다. 3.0에서 타입 JSON 중간표현과 구조 검증(선이 박스를 가로지르거나 라벨이 겹치는 문제 차단)이 들어가 결과물이 안정적이다. 다만 입력 설명이 틀리면 그림도 틀리고, 복잡한 도식은 수작업 보정이 필요하다. 같은 달 트렌딩인 orca, deepseek-harness 등은 이미 소개했거나 성격이 달라, 지금 바로 써볼 수 있는 신규 스킬로 선정했다.
* 링크: https://github.com/tt-a1i/archify
