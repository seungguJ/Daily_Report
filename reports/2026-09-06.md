1. On-device AI 논문

* 제목: Bridging On-Device and Cloud LLMs for Collaborative Reasoning: A Unified Methodology for Local Routing and Post-Training
* 학회/게재시점: ICML 2026 (Poster) · 2026-07-08 발표
* 다루는 문제: 온디바이스-클라우드 협업 추론에서 보통 별도의 "라우터"가 어떤 질문을 로컬 소형 모델이 풀지, 어떤 질문을 클라우드 대형 모델로 넘길지 결정하는데, 이 방식은 부가 컴포넌트만 늘릴 뿐 정작 로컬 모델 자체의 실력은 그대로다.
* 핵심 Contribution: 별도 라우터 없이 온디바이스 LLM 스스로 "로컬로 풀지 vs 클라우드에 넘길지"를 판단하도록, 계층적 보상(로컬 해결을 우대하되 필요한 오프로딩은 허용) 기반 강화학습 post-training과 그룹 단위 정책 경사, 적응형 프롬프트 필터링(정책 붕괴 방지)을 결합해 학습시킴.
* 인사이트:
  1. 라우팅 로직을 별도 모듈이 아니라 모델 자체의 행동으로 내재화하면 시스템이 단순해지고 배포 비용이 줄어든다.
  2. "무조건 로컬"이 아니라 "필요하면 클라우드 호출"을 보상 설계로 유도한 점이 실용적 균형점.
  3. LLaMA·Qwen 계열 다양한 크기에서 검증돼 특정 모델에 종속되지 않는 방법론임을 보여줌.
* 왜 볼만한가: 클라우드 호출을 줄이면 비용·지연시간·프라이버시 노출이 동시에 개선되는데, 이를 별도 인프라 없이 모델 학습만으로 달성한 접근이라 온디바이스 배포 실무에 바로 참고할 만하다.
* 링크: https://icml.cc/virtual/2026/poster/61881

2. AI Agent 활용 아이템

* 이름: SkillSpector (NVIDIA)
* 공개/출시시점: 2026-03-21 저장소 생성 · 2026-05-19 NVIDIA 공식 발표 · 최신 릴리스 v2.11.0 (2026-08-28)
* 핵심 기능: 에이전트 "스킬"(SKILL.md + 번들 스크립트/의존성)을 설치하기 전에 검사하는 보안 스캐너. 정적 분석(AST 기반 exec/eval/subprocess 탐지, taint tracking, YARA 시그니처, 타이포스쿼팅 검사)과 선택적 LLM 시맨틱 분석(스킬이 "주장하는 동작"과 "실제 코드/문구"의 불일치 탐지 — 특히 SKILL.md에 자연어로 숨겨진 prompt injection 포착)을 결합한 2단계 파이프라인.
* 활용 아이디어:
  1. `skillspector scan ./my-skill/` 한 줄로 로컬 스킬 폴더나 GitHub URL을 바로 스캔.
  2. SARIF 출력 지원으로 CI 파이프라인·IDE 문제창에 바로 연동 가능.
  3. `--no-llm` 옵션으로 오프라인/무료 정적 스캔만 빠르게 돌리고, 필요할 때만 LLM 심층 분석 추가.
* 왜 볼만한가: Claude Code·Codex CLI·Gemini CLI 등에서 에이전트 스킬을 그대로 신뢰하고 실행하는 게 당연해진 지금, 스킬 공급망 보안은 아직 이 브리핑에서 다룬 적 없는 사각지대였다. NVIDIA가 직접 만들어 자사 "Verified Agent Skills" 프로그램에 내부적으로 쓰고 있고(16.3k 스타, Apache-2.0, 3주간 10회 릴리스), Hacker News·보안 전문 매체(Help Net Security, NetGuide)에서도 다뤄졌다. 다만 정적 분석 단독으로는 오탐률이 높다는 독립 리뷰(Towards Data Science)도 있어 "정적 결과는 최종 판정이 아니라 후보로 보라"는 점은 유의할 만하다.
* 링크: https://github.com/NVIDIA/SkillSpector
