[AI Morning Brief - 2026-10-06]

1. On-device AI 논문

* 제목: Prima.cpp: Fast 30-70B LLM Inference on Heterogeneous and Low-Resource Home Clusters
* 학회/게재시점: ICLR 2026 Poster (2026년 4월 학회)
* 다루는 문제: 30~70B급 LLM은 보통 고성능 GPU 서버가 필요합니다. 이 논문은 RAM/VRAM이 부족하고 디스크·Wi-Fi가 느린 집 안의 이기종 기기(CPU/GPU 혼합) 여러 대로 큰 모델을 돌리는 문제를 다룹니다.
* 핵심 Contribution: 디스크 I/O와 연산·통신을 겹쳐 처리하는 pipelined-ring parallelism(PRP)과, 기기별 CPU/GPU 작업량과 사용할 기기를 메모리 제약 아래 함께 최적화하는 스케줄러 Halda를 제안했습니다.
* 인사이트:
  1. 70B 모델을 소비자 기기 4대에서 토큰당 674ms로 돌리고, 메모리 압박은 6% 미만으로 유지합니다.
  2. llama.cpp, exo, dllama 대비 5~17배 빠르다고 보고합니다.
  3. 32B 모델에 speculative decoding을 더하면 초당 26토큰까지 나옵니다.
* 왜 볼만한가: 클라우드 없이 집에 있는 노트북·PC·폰을 묶어 대형 모델을 로컬 프라이빗 추론으로 돌리는 현실적인 경로를 보여줍니다. 단일 기기 한계를 분산으로 푸는 접근이라 홈 AI 서버 구상에 참고가 됩니다.
* 링크: https://openreview.net/forum?id=h0LjpOG1jq

2. AI Agent 활용 아이템

* 이름: Harness (revfactory/harness)
* 공개/출시시점: v2.1.0 (2026-09-26, 저장소 커밋 기록 기준). 저장소 첫 커밋은 2026-03-29입니다.
* 핵심 기능: "이 프로젝트용 하네스를 만들어줘" 한 문장으로 도메인에 맞는 에이전트 팀과 각 에이전트가 쓸 스킬을 자동 설계하는 Claude Code용 메타 스킬입니다. Pipeline, Fan-out/Fan-in, Supervisor 등 6가지 팀 구조 패턴을 지원합니다.
* 활용 아이디어:
  1. `/plugin install harness@harness-marketplace`로 설치하고 반복되는 업무(리서치, 리뷰, 콘텐츠 제작)용 에이전트 팀 초안을 만듭니다.
  2. 생성된 팀을 `/harness:evolve`로 쓰면서 계속 개선합니다.
  3. 팀 구조 패턴을 참고해 직접 만드는 서브에이전트 워크플로의 설계 기준으로 삼습니다.
* 왜 볼만한가: GitHub 스타 약 9.1k, 포크 약 1.3k, 이슈 1건으로 채택 신호가 크고 관리도 잘 되고 있습니다. 9월 말 v2로 전면 재구축되어 지금이 갈아탈 시점입니다. 다만 Claude Code 멀티에이전트 런타임에 맞춘 도구라 다른 에이전트에서는 그대로 쓰기 어렵고, 릴리스 페이지에는 정식 릴리스가 없어 버전은 커밋 기록으로만 확인했습니다. Reddit/HN 반응은 확인하지 못했습니다. 이미 소개한 Superpowers, mattpocock/skills와 달리 팀 구성 자체를 자동 설계해 주는 점이 달라서 골랐습니다.
* 링크: https://github.com/revfactory/harness
