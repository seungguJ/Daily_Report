1. On-device AI 논문

* 제목: SpecEdge: Scalable Edge-Assisted Serving Framework for Interactive LLMs
* 학회/게재시점: NeurIPS 2025 (Spotlight 포스터, 2025-12-02)
* 다루는 문제: LLM 서빙은 서버 GPU에 집중돼 비용이 크지만, 사용자 근처의 엣지 GPU는 놀고 있다. 엣지와 서버의 연산을 어떻게 나눌지가 문제다.
* 핵심 Contribution: 엣지에서 작은 draft 모델이 토큰을 미리 생성하고 서버가 검증하는 speculative decoding 기반 서빙 프레임워크. 네트워크로는 토큰만 주고받으며, 서버 검증을 기다리지 않고 엣지가 먼저 초안을 만드는 proactive edge drafting과 여러 요청을 처리하는 pipeline-aware scheduling을 함께 쓴다.
* 인사이트:
  1. 사용자 측 엣지 GPU를 서빙 자원으로 끌어들여 서버 부담을 나누는 구조다.
  2. 서버 전용 대비 비용 효율 1.91배, 서버 throughput 2.22배를 달성했다.
  3. 토큰 단위 통신만 하므로 원문 활성값을 주고받지 않고, 토큰 간 지연도 11.24% 줄었다.
* 왜 볼만한가: 온디바이스와 클라우드를 잇는 협업 추론이 실제 비용 절감으로 이어진다는 근거를 준다. 엣지 기기 활용 설계를 고민한다면 참고할 만하다.
* 링크: https://neurips.cc/virtual/2025/poster/119940

2. AI Agent 활용 아이템

* 이름: Hindsight (vectorize-io/hindsight)
* 공개/출시시점: 2025-12 논문 공개, 최신 v0.10.2 릴리스 2026-09-29 (릴리스 페이지 확인)
* 핵심 기능: 에이전트가 대화를 단순 저장하지 않고 학습하도록 돕는 오픈소스 메모리 시스템. Retain(저장), Recall(검색), Reflect(분석) 세 가지 동작으로 사실, 경험, 관찰, 멘탈 모델을 관리한다. MIT 라이선스이며 25개 이상 LLM 제공자와 Claude Code, LangChain, n8n 등 60개 이상 연동을 지원한다.
* 활용 아이디어:
  1. Claude Code나 Hermes 같은 코딩 에이전트에 연결해 프로젝트 결정 사항과 선호를 세션 간에 유지한다.
  2. 고객 지원이나 리서치 에이전트에서 과거 상호작용을 회상하고 반성해 답변 일관성을 높인다.
  3. Docker 한 줄이나 pip install로 로컬에서 바로 띄워 시험해 볼 수 있다.
* 왜 볼만한가: GitHub 약 4.3만 stars, forks 약 5.8k, 커밋 3,300여 개에 최근 몇 주간 매주 릴리스가 이어진다. LongMemEval 91.4%를 보고했고 제3자 검증을 받았다는 보도가 있으나, 벤치마크 점수는 제작사 주장이라 직접 확인이 필요하다. 이 분야 후보 중 채택 신호와 문서 품질이 좋아 선정했다.
* 링크: https://github.com/vectorize-io/hindsight
