[AI Morning Brief - 2026-07-21]

1. On-device AI 논문

* 제목: Tequila: Trapping-free Ternary Quantization for Large Language Models
* 학회/게재시점: ICLR 2026 (2026년 4월 25일, Poster)
* 다루는 문제: LLM 가중치를 {-1, 0, 1} 3진(ternary)으로 양자화하면 크기와 연산량을 크게 줄일 수 있지만, 학습 중 많은 가중치가 "데드존(deadzone)" 경계에 갇혀(deadzone trapping) 노이즈뿐인 기울기만 받다 보니 최적화가 멈추고 정확도가 크게 떨어지는 문제
* 핵심 Contribution: 데드존에 갇힌 가중치를 버리지 않고 "동적 바이어스(dynamic bias)"로 재활용하는 Tequila 기법 제안. 순전파에서는 연속적인 신호를 주고 역전파에서는 의미 있는 기울기를 받게 해, 추론 오버헤드 거의 없이 모델 표현력과 학습 안정성을 동시에 개선
* 인사이트:
  1. ARC 벤치마크에서 기존 SOTA 3진 양자화 대비 정확도 4%p 이상 향상, 풀프리시전 대비 격차를 1% 미만으로 좁힘
  2. 곱셈 없이 덧셈만으로 동작하는 3진 가중치 구조를 유지하면서도 3.0배 추론 속도 향상을 함께 달성
  3. "죽은" 가중치를 폐기하지 않고 재사용한다는 아이디어는 1-bit·INT2 등 다른 극저비트 양자화 기법에도 확장 가능한 일반적 해법
* 왜 볼만한가: 온디바이스 LLM 배포의 최대 걸림돌인 초저비트 양자화의 정확도 손실을, 하드웨어 변경 없이 학습 기법 개선만으로 해결해 곱셈기 없는 저전력 칩에서도 준수한 정확도의 LLM을 돌릴 실질적 경로를 제시함
* 링크: https://iclr.cc/virtual/2026/poster/10011135

2. AI Agent 활용 아이템

* 이름: Browser Use (browser-use/browser-use)
* 공개/출시시점: 2026년 6월 8일 Rust 기반 베타 에이전트(v0.13.0) 공개, 2026년 7월 초 CLI 3.0 정식 출시 (최신 v0.13.6, 2026년 7월 17일)
* 핵심 기능: AI 에이전트가 실제 브라우저에서 클릭·입력·스크롤·로그인 등을 사람처럼 수행하도록 만드는 오픈소스 브라우저 자동화 프레임워크. 최근 CDP 기반 경량 Rust 런타임 "Browser Harness"로 코어를 재작성해 반응 속도·안정성을 높였고, CLI 3.0부터는 `browser-use skill` 명령으로 브라우저 조작 스킬을 다른 에이전트 툴에도 바로 설치 가능
* 활용 아이디어:
  1. 로그인이 필요한 사이트의 폼 작성, 데이터 크롤링, 웹 기반 QA 테스트를 자연어 지시만으로 자동화
  2. Claude Code 등 코딩 에이전트에 `browser-use skill install`로 브라우저 조작 능력을 얹어 웹 리서치·예약·주문 같은 실사용 워크플로우 구성
  3. 오픈소스 셀프호스팅 또는 클라우드 서비스로 확장해 경쟁사 가격 모니터링, 반복 양식 제출 같은 사내 웹 업무를 무인화
* 왜 볼만한가: GitHub 스타 10만 6천 개 이상으로 웹 자동화 에이전트 중 채택 규모가 가장 크고, Odysseys 리더보드 웹 자동화 태스크에서 87.4% 성공률로 빅테크의 컴퓨터비전 기반 에이전트들을 앞섬. "고정된 액션 메뉴 대신 얇고 편집 가능한 하네스를 준다"는 이번 Rust 재작성 설계 철학이 업계 화두가 되며 Vercel의 agent-browser 같은 경쟁 프로젝트까지 등장할 만큼 이 분야 표준으로 자리잡는 중이라 지금 볼 가치가 있음. 같은 시기 후보였던 Microsoft Agent Framework(스타 약 1.2만)나 Claude Agent SDK(스타 약 5천) 대비 스타 수·실사용 사례 규모에서 앞서 이 항목을 선정
* 링크: https://github.com/browser-use/browser-use
