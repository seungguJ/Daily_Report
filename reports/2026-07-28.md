[AI Morning Brief - 2026-07-28]

1. On-device AI 논문

* 제목: STAR-KV: Low-Rank KV Cache Compression via Soft Thresholding for Adaptive Rank Control
* 학회/게재시점: ICML 2026 Spotlight (2026년 7월 6일~11일, 서울 COEX, 포스터 발표 7월 8일)
* 다루는 문제: LLM 추론에서 컨텍스트가 길어질수록 커지는 KV 캐시가 메모리 병목이 되는데, 기존 저랭크 압축 기법들은 고정·휴리스틱 방식으로 랭크를 정해 공격적인 압축과 정확도 유지를 동시에 달성하기 어려움
* 핵심 Contribution: (1) attention-head·블록 단위로 최적 랭크를 자동 결정하는 미분 가능한 소프트 임계값 메커니즘, (2) Key와 Value의 민감도 차이에 맞춰 다른 저랭크 분해를 적용하는 하이브리드 전략, (3) 데이터 통계 기반의 저랭크 인지 혼합정밀도 양자화. 세 가지를 결합해 KV 캐시를 최대 75% 압축(양자화 결합 시 최대 20배 감소)하고, 커스텀 GPU 커널로 어텐션 연산 최대 6.9배, 전체 처리량 최대 3.1배를 가속
* 인사이트:
  1. 고정 랭크 대신 head/block 단위로 압축 강도를 자동 조절해 다양한 모델·태스크에 재튜닝 없이 적용 가능
  2. Key와 Value의 민감도를 구분해 압축 전략을 달리해, 무작정 줄이는 게 아니라 정확도 손실을 최소화하는 방향으로 설계
  3. 저랭크 압축과 양자화를 함께 적용해 메모리 절감과 속도 향상을 동시에 확보, 실제 GPU 커널로 배포까지 검증
* 왜 볼만한가: 긴 컨텍스트를 다루는 로컬·엣지 LLM 서빙에서 KV 캐시는 메모리 제약의 핵심 병목인데, 이를 자동화된 적응형 방식으로 크게 줄이면서 속도까지 높여 온디바이스 장문 추론의 실용성을 끌어올림. ICML 2026 스포트라이트(전체 리뷰 논문의 약 2.2%, 채택 논문의 약 8.4%)로 선정될 만큼 검증된 결과
* 링크: https://icml.cc/virtual/2026/poster/61958

2. AI Agent 활용 아이템

* 이름: mattpocock/skills (Skills for Real Engineers)
* 공개/출시시점: 2026년 2월 최초 공개, 2026년 6월 17일 v1.0 정식 출시, 2026년 7월 8일 v1.1.0 업데이트
* 핵심 기능: Matt Pocock이 자신의 .agents 디렉토리를 공개한 마크다운 기반 에이전트 스킬 모음. 개발자-에이전트 간 오해, 장황한 결과물, 코드 품질 저하, 아키텍처 붕괴라는 4가지 실패 유형에 대응하는 스킬(TDD, 도메인 모델링, 코드 리뷰, 버그 진단, 세션 handoff, 요구사항을 캐묻는 grill-me 등)을 model-invoked/user-invoked로 나눠 제공
* 활용 아이디어:
  1. handoff 스킬로 긴 작업 세션을 구조화된 마크다운 문서로 압축해 새 세션이나 다른 에이전트가 맥락 손실 없이 이어받게 함
  2. grill-me 스킬로 구현 전에 에이전트가 모호한 요구사항을 먼저 되묻게 해, 매직 프롬프트 없이도 요구사항을 명확히 함
  3. to-tickets·wayfinder 같은 계획 스킬로 큰 작업을 티켓 단위로 쪼개 진행 상황을 추적하고 팀 워크플로우에 맞게 커스터마이징
* 왜 볼만한가: 공개 24시간 만에 스타 2.19만 개를 얻고 현재 19만 개 이상으로 성장해 GitHub 트렌딩 1위를 기록했으며, "vibe coding이 아닌 엔지니어링 원칙"이라는 프레이밍으로 Hacker News·Reddit에서 활발히 논의됨. 이전에 소개한 Superpowers가 개발 프로세스 전체를 오케스트레이션하는 프레임워크라면, 이 저장소는 개별 스킬을 가볍게 마크다운으로 encoding해 부분 적용이 쉽다는 점에서 차별화되어 선정
* 링크: https://github.com/mattpocock/skills
