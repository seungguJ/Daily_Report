[AI Morning Brief - 2026-07-26]

1. On-device AI 논문

* 제목: K-Merge: Online Continual Merging of Adapters for On-device Large Language Models
* 학회/게재시점: ACL 2026 Main Conference (Oral, Long Paper) - 2026년 7월 2~7일 미국 샌디에이고
* 다루는 문제: 온디바이스 LLM은 태스크별 LoRA 어댑터를 계속 추가하며 기능을 넓혀가는데, 기기 저장공간은 제한적이라 무한정 쌓을 수 없고, 새 어댑터가 들어올 때마다 원본 학습 데이터 없이도 기존 태스크 성능을 지키면서 병합·유지 여부를 즉시 판단해야 하는 문제
* 핵심 Contribution: 저장 가능한 어댑터 개수(k)가 제한된 환경에서, 학습 데이터 없이(data-free) 새 LoRA가 들어올 때마다 기존 어댑터와 병합할지 새로 저장할지를 계산 효율적으로 결정하는 온라인 지속 병합(online continual merging) 프레임워크 K-Merge 제안. Samsung R&D Institute UK와의 공동 연구
* 인사이트:
  1. 온디바이스 개인화의 진짜 병목은 추론 속도보다 "제한된 저장공간 안에서 태스크별 어댑터를 어떻게 계속 관리하느냐"라는 지속학습(continual learning) 문제
  2. 원본 학습 데이터 없이도 병합 여부를 판단할 수 있는 data-free 설계라 프라이버시 제약이 강한 온디바이스 환경에 그대로 적용 가능
  3. 상용 온디바이스 어시스턴트를 만드는 삼성과의 공동 연구라 논문 단계를 넘어 실제 제품 적용 가능성이 높음
* 왜 볼만한가: LLM 경량화 논의 대부분이 "모델 자체를 어떻게 줄이나"에 쏠려 있는 반면, 이 논문은 "여러 기능을 계속 추가하는 온디바이스 어시스턴트를 저장공간 안에서 어떻게 오래 운영하나"라는 현실적인 롱텀 운영 문제를 다룸
* 링크: https://arxiv.org/abs/2510.13537

2. AI Agent 활용 아이템

* 이름: Goose (Linux Foundation Agentic AI Foundation)
* 공개/출시시점: 2025년 초 Block(구 Square)이 오픈소스로 공개, 2026년 4월 7일 Linux Foundation 산하 Agentic AI Foundation(AAIF)으로 이관되며 중립 거버넌스 확보. 이후에도 매주 릴리스가 이어지는 중(최신 v1.44.0, 2026년 7월 23일)
* 핵심 기능: 터미널·데스크톱 앱·CLI로 실행되는 범용 AI 에이전트로, 파일 읽기·쓰기, 셸 명령 실행, 웹 검색, MCP 기반 70개 이상 확장 도구 연동을 자연어 지시만으로 수행. Anthropic·OpenAI·Google·Ollama·Bedrock 등 15개 이상 모델 제공자를 자유롭게 교체 가능하며 Rust 기반으로 로컬에서도 가볍게 구동
* 활용 아이디어:
  1. YAML "레시피" 파일로 코드 리뷰·리서치·데이터 분석 같은 반복 업무를 절차화해 팀 내 재사용 가능한 자동화 워크플로로 배포
  2. Ollama 등 로컬 모델과 연결하면 코드·문서가 외부 서버로 나가지 않는 완전 로컬 에이전트 환경 구성 가능
  3. MCP 확장을 붙여 사내 시스템·DB·SaaS 도구와 연동한 맞춤형 업무 자동화 에이전트로 확장
* 왜 볼만한가: Block 사내 업무의 60%에 활용될 만큼 실전 검증됐고, AWS·Anthropic·Bloomberg·Cloudflare·Google·Microsoft·OpenAI가 참여하는 AAIF로 이관되며 특정 기업 종속 없는 중립 오픈소스로 자리잡음. GitHub 스타 5만 개 이상에 매주 릴리스가 이어질 만큼 관리가 활발하고, 2026년 1월엔 자체 레드팀 훈련(Operation Pale Fire) 결과를 투명하게 공개하는 등 보안에도 선제적으로 대응함. 같은 기간 폭발적으로 성장했지만 CVE 100건 이상, 공급망 공격, 정부 사용 제한 이슈까지 불거진 OpenClaw 같은 후보 대비 신뢰도 높은 선택
* 링크: https://github.com/aaif-goose/goose
