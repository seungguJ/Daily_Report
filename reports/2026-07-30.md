[AI Morning Brief - 2026-07-30]

1. On-device AI 논문

* 제목: QuantSpec: Self-Speculative Decoding with Hierarchical Quantized KV Cache
* 학회/게재시점: ICML 2025 (2025년 7월 Vancouver 발표, PMLR Volume 267 공식 게재 2025년 10월 6일)
* 다루는 문제: 롱컨텍스트 LLM 디코딩에서 매 스텝 전체 KV 캐시를 GPU에 올려야 해 메모리·지연시간 병목이 생기고, 기존 자기추측(self-speculative) 디코딩은 드래프트 모델의 정확도와 속도를 동시에 잡기 어려운 문제
* 핵심 Contribution: 타깃 모델과 아키텍처를 공유하되 계층적 4비트 양자화 KV 캐시와 4비트 양자화 가중치를 쓰는 드래프트 모델을 제안. 90% 이상의 높은 수락률을 유지하면서 기존 sparse KV 캐시 기반 자기추측 디코딩 대비 최대 2.5배 종단 속도 향상과 약 1.3배 메모리 절감을 달성
* 인사이트:
  1. 드래프트 모델을 별도로 새로 학습하지 않고 타깃 모델과 구조를 공유시켜 구현 부담과 추가 학습 비용을 최소화
  2. 캐시 정밀도를 층별로 차등화하는 계층적 양자화 설계라 정확도 손실 없이 메모리를 크게 줄여 온디바이스 메모리 제약 환경에 바로 적용 가능
  3. 90%대 높은 수락률을 유지해 추측 디코딩 특유의 "드래프트 리젝트로 인한 속도 손실" 리스크를 최소화
* 왜 볼만한가: 긴 문맥을 다루는 온디바이스·엣지 LLM 추론에서 메모리와 속도를 동시에 잡는 실전형 기법이라 로컬 추론 파이프라인에 바로 적용해볼 만함
* 링크: https://icml.cc/virtual/2025/poster/46326

2. AI Agent 활용 아이템

* 이름: Hermes Agent (Nous Research)
* 공개/출시시점: 2026년 2월 25일 최초 공개, 2026년 7월 20일 최신 메이저 업데이트(v0.19.0 "Quicksilver Release")
* 핵심 기능: 대화·작업 경험에서 스스로 마크다운 스킬 파일을 만들고 다듬는 학습 루프를 내장한 오픈소스 에이전트. 세션 간 지속되는 절차적 메모리, MCP 연동, 서브에이전트 병렬 위임, Telegram/Discord/Slack/WhatsApp/Signal/CLI 등 멀티 채널 구동을 지원
* 활용 아이디어:
  1. 반복 업무(서버 점검, 문서화, 리서치 요약)를 몇 번 시키면 에이전트가 스스로 스킬 파일로 정리해 다음부터 더 빠르고 안정적으로 재사용
  2. 저사양 VPS부터 GPU 클러스터까지 자유롭게 배포 가능해 개인 프로젝트의 상시 구동 비서로 활용
  3. agentskills.io 호환 마크다운 스킬 포맷이라 Claude Code 등 다른 에이전트 하네스와 스킬을 상호 공유 가능
* 왜 볼만한가: 출시 5개월 만에 GitHub 스타 22만 개를 넘기며 2026년 가장 빠르게 성장한 에이전트 프레임워크로 꼽히고, Hacker News 등에서 "실제로 더 빠르고 꼼꼼한 문서 작성자"라는 실사용 호평을 받음. 초기 감사에서 컨테이너 환경 승인 우회 등 치명적 보안 이슈가 지적됐으나 v0.19.0에서 기본 스마트 승인 체계로 개선되며 현재 공개된 미해결 보안 권고는 없음. 같은 기간 나온 Microsoft Agent Framework Harness는 이미 소개한 Microsoft Agent Framework의 연장선 업데이트라 제외했고, "스스로 학습해 스킬을 축적한다"는 차별화된 실용성을 보고 Hermes Agent를 선정
* 링크: https://github.com/NousResearch/hermes-agent
