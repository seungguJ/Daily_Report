1. On-device AI 논문

* 제목: Bridging the Gap Between Promise and Performance for Microscaling FP4 Quantization
* 학회/게재시점: ICLR 2026 (2026년 4월, Poster)
* 다루는 문제: MXFP4/NVFP4 같은 신형 4비트 부동소수점 포맷은 이론상 메모리·연산을 크게 줄여주지만, 실제로는 NVFP4의 작은 그룹 크기가 기존 아웃라이어 완화 기법을 무력화하고 2의 거듭제곱 스케일 제약까지 겹쳐 약속된 성능이 나오지 않는 문제
* 핵심 Contribution: 성능 미달의 두 원인(그룹 크기, 스케일 표현 방식)을 규명하고, FP4 구조에 맞춘 블록 단위 아다마르 회전 기반 양자화 알고리즘 MR-GPTQ(Micro-Rotated-GPTQ)를 제안. 정확도 손실 없이 레이어 단위 최대 3.6배, 엔드투엔드 최대 2.2배 추론 가속(NVIDIA B200 기준) 달성
* 인사이트:
  1. 초저비트 포맷은 하드웨어가 지원한다고 자동으로 빨라지는 게 아니라, 포맷별 구조적 한계를 이해한 알고리즘 설계가 있어야 실제 이득으로 이어짐
  2. 기존 아웃라이어 완화 기법을 그대로 이식하면 그룹 크기가 작은 포맷에서 오히려 무력화될 수 있어, 포맷 맞춤 전략이 필요함을 실증
  3. 데이터센터 GPU(B200) 실험이지만 엣지 NPU도 점차 FP4급 저비트 연산을 지원하는 추세라, 이 최적화 원리는 향후 모바일·온디바이스 추론 파이프라인 설계에도 그대로 참고할 수 있음
* 왜 볼만한가: 온디바이스 LLM의 핵심 병목인 메모리·연산량을 줄이는 초저비트 양자화가 "왜 기대만큼 안 나오는지"와 "어떻게 고치는지"를 함께 보여주는 논문
* 링크: https://iclr.cc/virtual/2026/poster/10006478

2. AI Agent 활용 아이템

* 이름: Microsoft Agent Framework 1.0
* 공개/출시시점: 2026년 4월 3일 GA(정식) 릴리스 - AutoGen과 Semantic Kernel을 통합한 후속 프레임워크
* 핵심 기능: 순차/동시/handoff/group chat/Magentic-One 등 멀티에이전트 오케스트레이션 패턴 지원, Azure OpenAI·OpenAI·Anthropic Claude·Bedrock·Gemini·Ollama 등 멀티 프로바이더 연동, A2A·MCP 프로토콜 상호운용, 프롬프트 수정 없이 동작을 가로채는 미들웨어 훅, 버전관리 가능한 YAML 선언형 워크플로 정의
* 활용 아이디어:
  1. 기존 AutoGen·Semantic Kernel 프로젝트를 공식 마이그레이션 가이드를 따라 단일 지원 프레임워크로 통합해 유지보수 부담 축소
  2. YAML 선언형 워크플로 + 미들웨어 훅으로 프롬프트 변경 없이 OpenTelemetry 관측성, 체크포인트, human-in-the-loop 승인 단계 추가
  3. MCP·A2A 지원을 활용해 Claude·Gemini 등 타사 모델 기반 에이전트와도 상호운용되는 멀티에이전트 시스템 구성
* 왜 볼만한가: GA(4월) 이후에도 최신 릴리스가 python-1.12.0(7월 21일)일 만큼 활발히 관리되고 있고, Hacker News에서도 "오랫동안 기다려온 통합"이라는 긍정적 반응이 나옴. GitHub 스타는 1.2만 개대로 OpenManus(5.7만 개) 등 더 높은 후보도 있었지만, OpenManus의 최근 릴리스는 실질 기능 추가 없이 사소한 수정에 그쳐 "최근 12개월 내 의미 있는 업데이트" 기준을 충족하지 못해 제외했고, Microsoft 공식 후속 프레임워크로서 엔터프라이즈 채택 신호와 지속적 릴리스 케이던스가 뚜렷해 이번에 선정
* 링크: https://github.com/microsoft/agent-framework
