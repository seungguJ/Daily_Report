[AI Morning Brief - 2026-10-14]

1. On-device AI 논문

* 제목: STAR-KV: Low-Rank KV Cache Compression via Soft Thresholding for Adaptive Rank Control
* 학회/게재시점: ICML 2026 (Spotlight), PMLR Vol. 306 / 2026-07 (ICML 2026 개최 기간 7/6~7/11)
* 다루는 문제: 긴 컨텍스트 추론에서 KV 캐시가 메모리를 대부분 차지함. 기존 low-rank 압축은 rank를 고정하거나 휴리스틱으로 정해 정확도 손실이 큼.
* 핵심 Contribution: 미분 가능한 soft thresholding으로 attention head·블록별 rank를 자동 결정하고, Key/Value 민감도에 맞춘 하이브리드 분해와 low-rank 인지형 혼합 정밀도 양자화를 결합.
* 인사이트:
  1. low-rank만으로 KV 캐시 최대 75% 절감, 양자화 결합 시 최대 20배 절감 (논문 보고 수치).
  2. rank를 레이어/헤드마다 학습으로 정해서 "일괄 압축"보다 정확도 손실을 줄임.
  3. 커스텀 Triton 커널로 attention 최대 6.9배, 생성 처리량 최대 3.1배 향상. 단, 측정은 GPU 환경이라 모바일 실측은 별도 확인 필요.
* 왜 볼만한가: 온디바이스는 메모리 상한이 가장 큰 제약이라 KV 캐시 절감이 곧 긴 문맥 로컬 추론의 가능 여부를 좌우함. 코드도 공개돼 있어 바로 실험해 볼 수 있음.
* 링크: https://proceedings.mlr.press/v306/bhatnagar26a.html

2. AI Agent 활용 아이템

* 이름: code-review-graph (v2.3.9)
* 공개/출시시점: v2.3.9 릴리스 2026-09-18 (저장소는 2026-02경 생성, 2차 자료 기준)
* 핵심 기능: Tree-sitter로 코드베이스를 구조 그래프로 만들어 로컬에 저장하고, MCP로 AI 코딩 도구에 변경 영향 범위(blast radius)만 읽게 해 주는 local-first 코드 지식 그래프. 증분 업데이트 지원.
* 활용 아이디어:
  1. PR 리뷰 시 변경된 파일과 연관 코드만 컨텍스트로 넘겨 토큰과 리뷰 시간을 줄이기.
  2. 큰 모노레포에서 리팩터링 전에 호출 관계와 영향 범위를 먼저 확인하기.
  3. 여러 저장소를 등록해 cross-repo 검색으로 서비스 간 의존성 추적하기.
* 왜 볼만한가: GitHub 스타 약 3.2만, 포크 약 2.9k로 이번 후보 중 채택 신호가 가장 큼. 설치는 `pip install code-review-graph` 후 `code-review-graph install` 두 단계로 끝나고, 여러 AI 코딩 도구를 자동 감지해 설정함. 최근 릴리스도 활발함. 다만 열린 이슈 102건·PR 82건으로 백로그가 있고, 토큰 절감 수치(6.8배~93배)는 자체 보고라 편차가 커서 우리 코드베이스에서 직접 검증 필요. 같은 기간 후보였던 Grok Build(공식, 스타 약 2.7만, 2026-05 공개)보다 스타·범용성(툴 무관 MCP)에서 앞서 선정.
* 링크: https://github.com/tirth8205/code-review-graph
